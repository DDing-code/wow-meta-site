# warlock-affliction
- 판정: 고침 (지옥소환사 광역 일부 보류)
- 고친 것:
  - 영혼 수확자 오프닝(2부 오프닝 rail·영웅 탭): 출몰 → 고통 → 부패 → 불안정한 고통 ×2 → 암흑의 수확 → 암흑시선 → 불안정한 고통 ×2 → 재앙의 손아귀 를 출몰 → 고통 → 부패 → **암흑시선** → 불안정한 고통 ×2 → 암흑의 수확 → 불안정한 고통 ×2 → **어둠의 화살** 로 바꿨습니다.
    - 근거: 상위 레이드 로그 6개 중 4개가 암흑시선을 수확보다 먼저 씀(3개는 부패 바로 뒤). 재앙의 손아귀는 6개 모두 첫 22회에 없고 레이드 반복에서도 분당 0회(다른 시전 번호로도 안 찍힘). 어둠의 화살은 6개 모두 첫 12회 안. 예: https://www.warcraftlogs.com/reports/D8p476PHTxCNRgqd#fight=63&source=710
    - APL: `SH_st … summon_darkglare,if=cooldown.dark_harvest.remains`(수확 뒤). 9월 19일 수정이라 12.1.5 전 자료여서 로그를 따랐고, 본문에 이 차이를 적었습니다.
  - 영혼 수확자 단일 우선순위(영웅 탭)와 2부 단일 반복 rail 위쪽 가지: 암흑의 수확 → 암흑시선 을 암흑시선 → 암흑의 수확 으로 바꿨습니다(오프닝과 같은 순서). 재앙의 손아귀 행과 rail note에는 "골랐을 때만"을 적었습니다.
  - 영혼 수확자 광역(영웅 탭·2부 광역 rail): 출몰 → 씨앗 → 수확 → 씨앗 → 고통 → 암흑시선 … 을 **고통 → 씨앗 → 출몰 → 암흑시선 → 수확** → 씨앗 … 으로 바꿨습니다.
    - 근거: 쐐기 광역 풀 시작 7개 모두 고통을 1~7번 먼저 건 뒤 씨앗을 씀. 출몰은 6개 중 4개가 첫 씨앗 뒤. 암흑시선·수확이 함께 나온 풀 3개 중 2개가 암흑시선 먼저. 고통 분당 시전은 레이드의 1.4배.
    - APL: `SH_aoe=haunt → seed_of_corruption → dark_harvest → … agony` 는 고통이 뒤쪽이지만 로그를 따랐습니다.
  - 지옥소환사 오프닝·단일·광역(영웅 탭)과 2부 오프닝 rail: 암흑의 수확 → 적개심 → 암흑시선 을 **적개심 → 암흑시선 → 암흑의 수확** 으로 바꿨습니다(광역은 적개심 → 수확).
    - 근거: 레이드 반복 구간에서 적개심 뒤 1~2회 안에 수확이 18번, 반대 순서는 2번(6명 중 5명이 이 순서). 오프닝에서도 6개 중 4개는 수확을 적개심·암흑시선 앞에 두지 않음. 예: https://www.warcraftlogs.com/reports/MgfdXTN3RYB482J1#fight=32&source=279
    - APL: `HC_st … dark_harvest → malevolence → summon_darkglare` 는 수확이 앞이지만 12.1.5 전 자료입니다.
  - 같은 순서로 맞춘 문장: 2부 단일·오프닝·광역 장의 한 줄 원리·본문·요점, 3부 쐐기 한 판 장의 한 줄 원리·본문·예시, 4부 지옥소환사 장 본문·요점, 영웅 탭 요약(summary). 지옥소환사 장의 "이번 로그 대조에 나오지 않았다"는 "10월 8일 대조에는"으로 날짜를 밝혔습니다(이번 12.1.5 로그에는 6개가 있음).
- 그대로 둔 것과 이유:
  - 지옥소환사 오프닝의 적개심·암흑시선 앞뒤: 로그가 3:3으로 갈려서 그대로 두고 note에 적었습니다.
  - 지옥소환사 오프닝의 재앙의 손아귀: 6개 중 2개가 썼고 대안(어둠의 화살 3개, 영혼 흡수 1개)도 과반이 아니어서 그대로 두었습니다. "고르지 않았다면 어둠의 화살·영혼 흡수"를 note에 적었습니다.
  - 지옥소환사 광역의 출몰 → 씨앗 → 고통 앞뒤: 쐐기 로그가 0개라 APL(`HC_aoe`) 순서를 유지했습니다(적개심 → 수확만 레이드 근거로 바꿈).
  - 영혼 수확자 단일 반복 흐름의 기본 줄: 레이드는 님리사 쫄 때문에 씨앗이 섞여 있고, 순수 단일 판단에는 APL과 맞아서 바꾸지 않았습니다.
  - 불타는 돌진(분당 1.5회): 이동 기술이라 딜사이클에 넣지 않았습니다.

- 보류·사용자 확인 필요:
  - 지옥소환사 광역의 고통 위치: 레이드 쫄 구간에서는 지옥소환사도 고통을 여러 번 먼저 거는 모습이 보였지만, 쐐기 로그가 없어 보류했습니다.
  - 영혼 수확자 특성 견본에 재앙의 손아귀가 들어 있는지는 이번 범위(견본) 밖이라 확인하지 않았습니다. 상위 레이드 영혼 수확자 로그는 이 특성을 쓰지 않았습니다.
