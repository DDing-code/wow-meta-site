# evoker-preservation
- 판정: 고침(일부 보류)
- 고친 것:
  - 불꽃형성자 오프닝 rail(2부): 정지장[앞선 피해에서 저장] → 꿈의 숨결[1단계 · 축복 확정] → 시간 변칙 → 메아리 → 미풍 → 메리스라의 축복 → 에메랄드 꽃 → 흑요석 비늘 ⇒ 정지장[풀 직후 저장 시작] → 꿈의 숨결[1단계 · 레이드는 두 번] → 시간 변칙 → 메아리(위: 미풍) → 메리스라의 축복 → 에메랄드 꽃(위: 흑요석 비늘). 정지장 메모를 "꿈의 숨결·시간 변칙·메리스라의 축복 저장"에서 레이드는 꿈의 숨결 두 번 + 시간 변칙, 쐐기는 꿈의 숨결·시간 변칙 + 축복이나 꽃으로 고침. 근거: 레이드 8개 중 7개가 0~3초에 정지장 → 꿈의 숨결 → 꿈의 숨결 → 시간 변칙(나머지 1개는 풀 전에 저장하고 11.4초에 방출). 미풍·흑요석 비늘은 8개 모두 첫 22번 안에 0회. 예: https://www.warcraftlogs.com/reports/bL4mArhFVqxXPTpB#fight=2&source=17 (0.0 정지장 → 0.5 꿈의 숨결 → 1.6 꿈의 숨결 → 2.8 시간 변칙).
  - 불꽃형성자 영웅 탭 오프닝: 같은 내용으로 정지장(풀 직후)·꿈의 숨결(레이드는 두 번)·시간 변칙(정지장에 함께 저장)·에메랄드 꽃 설명과 요약을 고치고, 미풍을 5번 → 7번(배정됐을 때만)으로 옮김.
  - 광역 흐름(2부 rail·불꽃형성자 영웅 탭 광역): 꿈의 숨결 → 메리스라의 축복 → 에메랄드 꽃 → 되감기 → 시간 변칙 → … ⇒ 꿈의 숨결 → 시간 변칙 → 메리스라의 축복 → 에메랄드 꽃 → 되감기 → …. 근거: 꿈의 숨결 다음 버튼 1위가 시간 변칙(레이드 121번 중 48번, 쐐기 655번 중 281번), 쐐기에서 시간 변칙 다음 1위는 메리스라의 축복(223번). 1부 "꿈의 숨결 → 시간 변칙과 메아리 → 축복" 원칙과도 같음.
  - 같은 순서를 말하는 문장 맞춤: 오프닝 장 본문(풀 직후 정지장, 레이드 두 충전, 다시 찬 충전), 광역 장 한 줄 원리·본문·실수("정지장에 저장할 때가 아닌데 두 충전을 연달아"), 4부 정지장 장 본문 한 문장.
- 그대로 둔 것과 이유:
  - 한 명 치유 반복 rail(꿈의 숨결 → 시간 변칙 → 메아리 → 축복 → 꽃): 레이드 다음 버튼(꿈의 숨결 → 시간 변칙, 시간 변칙 → 메아리, 축복 → 꽃)과 같음.
  - 시간 변칙 뒤 메아리와 에메랄드 꽃 중 무엇이 먼저인지: 레이드 오프닝은 꽃 먼저 8개 중 5개, 레이드 전체는 메아리 77번·꽃 63번으로 갈려 메모("정수 폭발이 먼저 뜨면 메아리 사이에 꽃")만 적음.
  - 한 명 급락 탭의 자연화·구출: 레이드 0회지만 조건부 기술이고 자연화는 쐐기 분당 0.8회.
  - 신록의 품(분당 약 1.6회)은 광역 흐름에 넣지 않음. 레이드는 74번 중 71번이 자신 대상(4세트 정수 폭발용, 3부 공격대 장 요점에 이미 있음), 쐐기는 다른 아군 대상이 대부분이지만 풀 시작 순서에 꾸준히 나오지 않음.
  - 시간 감시자 전체: 12.1.5 이후 상위 로그 0개.
