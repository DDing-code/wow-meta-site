# shaman-restoration
- 판정: 고침(일부 보류)
- 고친 것:
  - 토템술사 광역 흐름(2부 rail·영웅 탭 광역): 폭풍의 흐름 토템 → 성난 해일 → 자연의 신속함 → 쇄도하는 토템 → 치유의 토템 → 연쇄 치유 ⇒ 쇄도하는 토템 → 치유의 토템 → 성난 해일 → 자연의 신속함 → 폭풍의 흐름 토템 → 연쇄 치유. 근거: 쐐기 광역 풀 83개에서 쇄도하는 토템이 자연의 신속함보다 먼저 68개 중 61개, 치유의 토템이 먼저 66개 중 45개, 자연의 신속함 → 폭풍의 흐름 토템 66개 중 60개. 레이드에서도 자연의 신속함 43번 중 36번이 세 번 안에 폭풍의 흐름 토템. 예: https://www.warcraftlogs.com/reports/1XDbg4PvKjkRy7ML#fight=15&source=66 (10.0 치유의 토템 → 11.3 자연의 신속함 → 11.7 연쇄 치유 → 12.7 폭풍의 흐름 토템). 사용권 2중첩일 때 신속함 전에 하나를 먼저 쓰는 원칙은 메모·설명에 남김.
  - 토템술사 오프닝(2부 rail·영웅 탭): … 쇄도하는 토템 → 자연의 신속함 → 폭풍의 흐름 토템 → 치유의 토템 → 연쇄 치유 ⇒ … 쇄도하는 토템 → 치유의 토템 → 자연의 신속함 → 폭풍의 흐름 토템 → 연쇄 치유. 근거: 레이드 오프닝에서 치유의 토템이 자연의 신속함보다 먼저 6개 중 5개, 폭풍의 흐름 토템이 자연의 신속함 뒤 5개 중 5개. 예: https://www.warcraftlogs.com/reports/VmTzBjPrfhAqpcvy#fight=3&source=2 (13.2 자연의 신속함 → 13.5 연쇄 치유 → 14.4 폭풍의 흐름 토템). 물의 보호막·대지의 보호막은 풀 전 준비라 그대로 둠.
  - 한 명 치유 반복 rail·영웅 탭 단일: 맨 끝 대지의 보호막을 뺌. 근거: 대지의 보호막 시전이 레이드 8개 합계 1번, 쐐기 8개 합계 17번. 견본 3개 모두 테라제인의 탄력이라 충전이 줄지 않음. 메모에 "전투 전에 걸어 둡니다"를 적음.
  - 오프닝 본문·메모·영웅 탭 요약에 "첫 피해 전 비는 글쿨에 화염 충격 → 용암 폭발"을 적음. 근거: 레이드 8개 중 6개가 첫 22번 안에 화염 충격(5개는 처음 세 번 안). 순서 칸에는 넣지 못함(아래 KB 추가 필요).
  - 같은 순서를 말하는 문장 맞춤: 오프닝 장 본문·확인 문제, 광역 장 첫 문단, 영웅 탭 오프닝·단일·광역 요약과 바뀐 행 설명.
- 그대로 둔 것과 이유:
  - 오프닝의 성난 해일 → 쇄도하는 토템: 레이드 8개가 4:4로 갈림(쇄도하는 토템을 늦게 쓴 4개는 풀 전에 깔았을 가능성도 있음).
  - 한 명 치유의 자연의 신속함 → 치유의 물결: 쐐기에서 자연의 신속함 다음 치유의 물결 191번 중 67번. 레이드는 대부분 연쇄 치유지만 한 명 위기 상황은 로그로 구분할 수 없음.
  - 선견자 전체: 12.1.5 이후 상위 로그 0개.
  - 토템 재배치(쐐기 분당 1.2회)·늑대 정령은 이동 기술이라 순서에 넣지 않음.
- KB 추가 필요:
  - 화염 충격(188389)·용암 폭발(51505): KB 노트의 사용 전문화가 정기만으로 되어 있어, 복원 순서 칸(타임라인·영웅 탭)에 넣으면 툴팁 검사가 막습니다. 복원도 쓰는 주문이니 사용 전문화에 복원을 더해야 합니다. 이유: 레이드 8개 중 6개가 풀 직후 화염 충격, 레이드 분당 화염 충격 2.2회·용암 폭발 1.4회. 추가되면 오프닝 rail 쇄도하는 토템 뒤에 "화염 충격(위: 용암 폭발) · 피해 전 여유 글쿨"을, 한 명 치유 rail 끝에 "화염 충격 · 파티가 안전할 때"를 넣는 것을 권합니다.
