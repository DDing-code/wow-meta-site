# warrior-fury
- 판정: 고침 (일부 그대로 — 공통 rail·산왕 오프닝)

## 고친 것
1. 학살자 오프닝 (2부 오프닝 타임라인 "학살자 오프닝" + 영웅 탭 학살자 opener)
   - 전: 돌진 → 오딘의 격노 → 무모한 희생 → 광란 → 칼날폭풍 → 마무리 일격 → 광란
   - 후: 돌진 → 오딘의 격노 → 무모한 희생 → 광란 → 칼날폭풍 → 광란 → 분쇄의 타격 → 광란 (급살 마무리 일격은 광란 사이에 끼운다고 note에)
   - 근거: 레이드 8개 중 8개가 칼날폭풍 바로 다음(칼날폭풍 중 자동으로 나가는 피범벅 제외) 광란, 6개가 그다음 분쇄의 타격. 마무리 일격은 5개에서 그 뒤 광란 사이에 나옴.
   - 예: https://www.warcraftlogs.com/reports/grLRwJZ1TxvXDdQA#fight=2&source=10
   - APL slayer: `rampage,if=buff.recklessness.up&cooldown.bladestorm.ready` → `bladestorm` → `execute,if=…sudden_death` → `rampage,if=…!buff.hack_and_slash.up` → `crushing_blow`. APL(8월 11일)은 마무리 일격을 광란 위에 두지만 로그가 이김.
   - 오딘의 격노 단계 note: "무모한 희생 앞뒤, 로그마다 다름"(오프닝에 쓴 5개 중 앞 2·같은 순간 1·뒤 2). 영웅 탭 요점 1줄도 같은 뜻으로 고침.
2. 2부 단일 "영웅 특성별로 끼워 넣는 것" rail: 학살자 칼날폭풍 → 마무리 일격 → 광란 을 칼날폭풍 → 광란 → 마무리 일격 으로.
3. 2부 단일 연습 본문 2문단: "산왕도 분노의 강타 충전을 먼저 본다" → 영웅 특성별로 나눔. 무모한 희생 밖 광란 뒤 첫 생성기: 학살자 분노의 강타 270회·피의 갈증 30회, 산왕 피의 갈증 144회·분노의 강타 76회.
4. 산왕 단일 우선순위 (영웅 탭)
   - 전: … 광란 → 분노의 강타 → 피의 갈증 → 천둥벼락
   - 후: … 광란 → 피의 갈증 → 분노의 강타 → 천둥벼락
   - 근거: 위 144:76. KB 상 피의 갈증이 우레 작렬을 줌. APL thane 의 `bloodthirst` 가 조건 없는 `raging_blow` 위.
   - 예: https://www.warcraftlogs.com/reports/b4LRwk2AcqtxQGBa#fight=30&source=77
5. 산왕 광역 우선순위 (영웅 탭)
   - 전: 광란 → 우레 작렬 → 천둥벼락 → 피범벅 → 분쇄의 타격 → 광란 → 분노의 강타
   - 후: 천둥벼락(복제가 없을 때) → 광란 → 우레 작렬 → 피범벅 → 분쇄의 타격 → 피의 갈증 → 광란 → 분노의 강타
   - 근거: 산왕 쐐기 풀(적 3명 이상) 14개 중 8개가 첫 광란 전에 천둥벼락, 나머지는 피의 갈증으로 시작. 쐐기 피의 갈증 분당 4.3회. APL thane_aoe `thunder_clap,if=talent.improved_whirlwind&buff.whirlwind.stack=0`. 본문 광역 장 요점("소용돌이(산왕은 천둥벼락) → 광란")·4부 산왕 장과도 맞춤.
   - 예: https://www.warcraftlogs.com/reports/tnQKYv3xHgzbDkX7#fight=1&source=1
6. 2부 광역 "영웅 특성별로 끼워 넣는 것" rail: 산왕 우레 작렬 → 투신 을 투신 → 우레 작렬 로 (쐐기 풀 투신 8회 중 6회가 바로 뒤, 2회가 광란 하나 뒤 우레 작렬. 레이드도 투신 다음 우레 작렬 50%).
7. 학살자 광역 우선순위 (영웅 탭): 분쇄의 타격 다음에 분노의 강타 추가 (쐐기 광역 분당 9.3회, APL slayer_aoe `raging_blow` 가 `bloodthirst` 위).

## 그대로 둔 것과 이유
- 공통 오프닝 뼈대, 공통 단일·광역 반복 rail: 두 영웅 특성 흐름을 섞은 그림이고, 뒤집힘이 꾸준하지 않음(예: "피의 갈증 → 마무리 일격" 대 반대는 절대 횟수로 비슷). 본문 문장으로 영웅별 차이만 보충.
- 산왕 오프닝: 레이드 5개 중 3개가 "무모한 희생 → 투신 → 광란 → 우레 작렬 → 강화 생성기 → 광란"으로 일치. 피범벅과 분쇄의 타격 사이에 광란이 끼는지만 갈려서 note에 "로그마다 다름"으로 적음.
- 학살자 오프닝에서 돌진 직후 피의 갈증: 8개 중 4개(50%)라 넣지 않음.
- 학살자 단일 우선순위: 로그·APL과 맞음(무모한 희생 중 분쇄의 타격 691회 > 피범벅 127회, 피범벅 대부분은 칼날폭풍 자동 시전).
- 무모한 희생·소용돌이·마무리 일격(산왕): 반복 rail에 이미 있어 영웅 탭에 따로 넣지 않음.
