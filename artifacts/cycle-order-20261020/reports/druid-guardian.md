# druid-guardian
- 판정: 고침 (발톱의 드루이드는 일부 보류)
- 근거 범위: 12.1.5 이후 WCL 상위 엘룬의 대행자 레이드 6개(님리사 신화)·쐐기 8개, 심크 APL `druid_guardian.simc`(2026-09-27 수정 — 12.1.5 전이라 로그를 우선함). 발톱의 드루이드는 로그 0개.
- 견본 확인(특성 코드 해독): 레이드·단일 견본 = 붉은 달·액체 형상·야생의 정수 선택, 말살 없음. 쐐기 견본 = 쌍둥이 달빛섬광·말살·태풍·행동 불가의 포효 선택, 붉은 달 없음.

## 고친 것
1. **2부 단일 연습 타임라인 → "레이드 네임드(단일)"**
   - 전: 달빛섬광 → 난타 → 짓이기기 → 야생 수호자 → 후려갈기기 → 난타 → 달빛섬광
   - 후: 난타 → 짓이기기 → 붉은 달 → 짓이기기(붉은 달 대상) → 후려갈기기(무료 발동·영혼 깨우기) → 난타 → 휘둘러치기. 야생 수호자(화신 바로 뒤)·달빛섬광(붉은 달 없는 엘룬)은 끼워 넣기로 옮김.
   - 근거: 레이드 로그 6/6 달빛섬광 0회, 붉은 달 전투당 9~11회(약 30초마다), 휘둘러치기 6/6 사용(분당 6.2). 붉은 달 뒤 3회 안 짓이기기 81%, 짓이기기 → 무쇠가죽 67%. APL `mangle,if=dot.red_moon.ticking` > `red_moon,if=cooldown.mangle.up&!dot.red_moon.ticking` > `mangle` > `thrash` > `moonfire,if=…&!talent.red_moon` > `swipe_bear,if=…(talent.lunation&talent.red_moon)`.
   - 예: https://www.warcraftlogs.com/reports/xBzJtGLmRCkwn7NA#fight=36&source=1681
   - 같은 장 본문 1·2문단, 확인 문제(달빛섬광 → 붉은 달)를 같은 순서로 고침.
2. **엘룬의 대행자 오프닝(2부 오프닝 타임라인·영웅 탭 오프닝)**
   - 전: 곰 변신 → 나무 껍질 → 달빛섬광 → 달 광선 → 화신 → 난타 → 짓이기기 → 무쇠가죽 → 야생 수호자 → 후려갈기기 → 난타 → 짓이기기
   - 후: 곰 변신 → 포효(먼저 잡는 탱커) → 난타 → 달 광선 → 화신 → 야생 수호자 → 난타 → 붉은 달 → 짓이기기 → 후려갈기기 → 무쇠가죽 → 난타 → 짓이기기
   - 근거: 화신 뒤 2초 안 야생 수호자 6/6, 첫 무쇠가죽보다 후려갈기기 먼저 6/6, 첫 1초 안 포효 4/6, 달 광선이 화신보다 먼저 5/6, 붉은 달 사용 6/6, 첫 20초 안 나무 껍질 1/6. 야생 수호자 → 후려갈기기 18번 모두 15초 안(중간값 3초). APL `wild_guardian,if=!buff.answered_calling.up&buff.lunar_beam.up`.
   - 같은 장 한 줄 원리·본문 1·2문단·요점·실수 1개를 새 순서에 맞춤. 1부 야생 수호자 장의 실수 문장도 "생성기 → 후려갈기기" 순서와 어긋나지 않게 다듬음.
3. **엘룬의 대행자 레이드 단일 우선순위(영웅 탭)**: 달빛섬광 두 자리 → 붉은 달(짓이기기 준비 시)·휘둘러치기(빈 글쿨). 붉은 달 대상 짓이기기를 붉은 달 위에, 야생 수호자는 "화신을 쓰면 바로". 근거는 1번과 같음.
4. **2부 광역 연습 타임라인 → "쐐기 풀(광역)"**
   - 전: 난타 → 달빛섬광 → 짓이기기 → 야생 수호자 → 말살(적이 앞에 모였을 때) → 난타 → 달빛섬광
   - 후: 난타 → 달빛섬광 → 짓이기기 → 난타 → 달빛섬광 → 짓이기기(위 가지: 무쇠가죽·광포한 재생력·생존 본능). 화신 → 야생 수호자 → 말살(영혼 깨울 때)은 끼워 넣기.
   - 근거: 쐐기 로그 8개 말살(400254) 0회, 후려갈기기 분당 0.7(8개 중 6개는 화신 횟수와 같음), 무쇠가죽 분당 31, 화신 → 야생 수호자 85%. 같은 장 본문 2문단에 로그 사실 한 문장 추가.
5. **엘룬의 대행자 쐐기 광역 우선순위**: 순서는 그대로, 무쇠가죽·달빛섬광·야생 수호자·말살 설명을 로그에 맞춤(분노 대부분 무쇠가죽, 풀 시작 달빛섬광 연속, 말살은 영혼 깨울 때).
6. **발톱의 드루이드 레이드 단일(APL만)**: 3번 달빛섬광 → 붉은 달(골랐다면), 마지막에 휘둘러치기 추가. 근거: APL의 `moonfire` 줄은 삭망월(엘룬 전용)이 있어야 해 발톱의 드루이드는 달빛섬광을 반복에 쓰지 않고 `swipe_bear`로 채움. 쐐기 광역 말살 설명만 엘룬 로그와 같은 취지로 다듬음.
7. **3부 쐐기 한 판 예시 문장**: 나무 껍질 → 달빛섬광 → 난타 → 화신 → … → 달 광선 ⇒ 달빛섬광 → 난타 → 무쇠가죽 → 나무 껍질 → 달 광선 → 화신 → 야생 수호자. 근거: 큰 풀 17개 중 첫 짓이기기보다 무쇠가죽 먼저 17/17, 나무 껍질이 화신보다 먼저 16/16(풀 시작 뒤 대략 9~16초), 달 광선이 화신보다 먼저 13/16.
8. **탱커 작업**
   - 영웅 탭 탭 이름: 단일 → "레이드 단일", 광역 → "쐐기 광역"(제목도 레이드/쐐기 포함).
   - 탱사이클 4개 새로 작성(talentBuildId raid / mythic-plus).
     - 엘룬 레이드: 포효 → 무쇠가죽 → 나무 껍질 → 화신 → 달 광선 → 생존 본능 → 광포한 재생력 → 난타. (도발 전투당 4~8번, 나무 껍질은 도발 뒤 대략 10~15초가 많음, 화신은 6개 모두 풀 직후·약 2분·약 4분, 생존 본능 0~3번, 광포한 재생력 1~14번)
     - 엘룬 쐐기: 난타 → 달빛섬광 → 무쇠가죽 → 나무 껍질 → 달 광선 → 화신 → 두개골 강타 → 생존 본능 → 광포한 재생력 → 쇄도의 포효. (광포한 재생력 쐐기 ×2.4)
     - 발톱 레이드·쐐기: 엘룬 뼈대에서 달 광선 자리를 찢어발기기(섬뜩한 상처 15%·목숨을 끊는 일격 무쇠가죽 20%)로, 로그 없음을 summary에 적음.
     - 견본 차이: 쐐기 견본에만 태풍·행동 불가의 포효가 있음을 summary·note에 적음.
   - 3부 '쐐기 한 판'에 `kind:'tank'` 쐐기 탱사이클(엘룬·발톱·차단 끼워 넣기), '공격대 네임드'에 레이드 탱사이클(엘룬·발톱, 반복)을 넣음.

## 그대로 둔 것과 이유
- 쐐기 광역의 난타 → 달빛섬광 → 짓이기기 순서: 풀 시작 17개 중 16개가 첫 짓이기기보다 달빛섬광이 먼저라 가이드와 같음.
- 쐐기 광역 채우기를 달빛섬광으로 유지: APL은 4대상 이상이면 휘둘러치기지만, 쐐기 로그 8개 중 6개가 휘둘러치기 0회·달빛섬광 분당 12 → 로그 우선.
- 발톱의 드루이드 오프닝(달빛섬광 단계 포함)·쐐기 광역 순서: 12.1.5 이후 로그 0개라 바꾸지 않음.
- 포효(레이드 분당 1.2)·나무 껍질(1.2): 딜사이클 단일 표에는 넣지 않고 탱사이클·타임라인 위 가지로 넣음. 두개골 강타(쐐기, 대조 자료의 1.6은 두 시전 번호가 겹쳐 2배로 잡힌 값 — 실제 약 0.8)도 탱사이클로.
- 대조 자료의 "달 광선 → 달 광선 50%"는 같은 순간 두 시전 번호(204066·1270292)가 찍힌 것이라 순서 근거로 쓰지 않음(실제 약 40초마다 1번).
- 상단 opener·priority, heroBranches[].priority(예전 필드), 영웅 특성 카드 요점, 견본, 기본 영웅 탭, 현장 팁: 범위 밖. 현장 팁 중 "달빛섬광을 누르기 전에 난타와 짓이기기가 돌아왔는지…"는 쐐기 견본 기준으로 여전히 맞아 충돌 없음.
