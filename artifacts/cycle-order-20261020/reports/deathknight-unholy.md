# deathknight-unholy
- 판정: 고침
- 고친 것:
  - 산레인 영웅 탭 오프닝: 쐐기 하수인 변형(돌발 열병 → 고름 일격 → 부패의 낫 → 사자의 군대 → 어둠의 변신 → 부패 → 흡혈의 일격 → 무덤 → 흡혈의 일격) → 레이드 단일(돌발 열병 → 고름 일격 → 부패의 낫 → 사자의 군대 → 어둠의 변신 → 부패 → 괴저 고리 → 흡혈의 일격 → 영혼 수확자 → 역병내림). 근거: 산레인 레이드 로그 7개 중 6개가 이 순서로 열었고(1개는 돌발 열병 대신 부패), 7개 모두 부패 다음 괴저 고리를 먼저 씀. 무덤은 7개 모두 첫 22회에 없음. 역병내림 → 부패 93%. 예시 https://www.warcraftlogs.com/reports/rMkBYPHyDpLNtbQ1#fight=2&source=4 . APL cooldowns 의 army_of_the_dead(festering_scythe_tt 켜짐), single_target 의 soul_reaper(변신 쿨 38초 미만). 영웅 탭 소개 문장의 "아래 차트는 하수인 변형" 문장도 맞춤. 쐐기 하수인 변형 오프닝은 2부 오프닝 장 둘째 줄에 그대로 있음.
  - 산레인 단일 우선순위(8행 → 13행): 돌발 열병 → 사자의 군대 → 어둠의 변신 → 부패 → 부패의 낫 → 흡혈의 일격 → 괴저 고리 → 영혼 수확자 → 돌발 열병 → 고름 일격 → 부패의 낫 → 흡혈의 일격(정수 만료) → 사자의 군대 → 어둠의 변신 → 부패 → 괴저 고리 → 죽음의 고리 → 영혼 수확자 → 역병내림 → 흡혈의 일격(정수 쌓기) → 스컬지의 일격. 근거: 레이드 분당 죽음의 고리 11.7·스컬지의 일격 8.7·고름 일격 3.6·역병내림 1.3회인데 목록에 없었음, 고름 일격 뒤 89%가 부패의 낫. APL single_target 의 festering_strike(낫 갱신)·death_coil(군대 쿨 5초 초과) > scourge_strike, cooldowns 의 army(낫 효과 조건). 돌발 열병은 산레인 레이드 분당 0.02회라 "오프닝 뒤 거의 안 누름" 설명을 붙임.
  - 종말의 기수 단일 우선순위: 고름 일격·죽음의 고리 추가, 부패의 낫을 군대 앞으로, 스컬지의 일격을 맨 끝으로(같은 APL 근거, 이 영웅 로그 1개는 죽음의 고리 분당 3.8회).
  - 두 영웅 광역 우선순위: 고름 일격(낫 갱신·준비 3중첩 미만)·어둠의 변신 추가, 산레인에 스컬지의 일격 추가. 근거: 쐐기 광역 분당 스컬지의 일격 9.1·고름 일격 3.2·어둠의 변신 1.4회, APL aoe 의 festering_strike 두 줄과 scourge_strike.
  - 2부 단일 연습 본문 우선순위 문장에 "낫 효과 유지(고름 일격 → 부패의 낫)"와 "(산레인) 흡혈의 일격으로 정수 쌓기", "변신이 끝나기 전 역병내림"을 넣어 영웅 탭과 같은 순서로 맞춤.
- 그대로 둔 것과 이유:
  - 2부 연습 장 타임라인(단일 반복·오프닝 세 줄·광역): 레이드 오프닝 줄은 로그 7개와 일치, 반복 줄의 이웃 쌍도 꾸준히 뒤집힌 곳이 없어 그대로 둠.
  - 종말의 기수 오프닝: 레이드 로그 1개(KR #39, 부패의 낫을 거의 안 쓰는 빌드)뿐이라 바꾸지 않음. 쐐기 로그 0개.
