# priest-shadow
- 판정: 고침 (일부 보류)
- 셈 방법: 대조 자료의 Shadowy Apparition(341263, 분당 약 41회)은 저절로 나가는 원혼이라 빼고, 보호막·소실·깃털 같은 생존·이동 기술도 빼고 다음 스킬을 다시 셌습니다.

## 고친 것
1. 집정관 단일 오프닝 (영웅 탭 opener, 2부 오프닝 타임라인 "오프닝 — 집정관", 같은 장 본문 둘째 문단)
   - 전: 정신 분열 → 촉수 격돌 → 고통 → 후광 → 세트 공허 연사 → 공허의 형상 → 마력 주입 → 광기
   - 후: 정신 분열 → 촉수 격돌 → 고통 → 세트 공허 연사 → 후광 → 공허의 형상 → 마력 주입 → 광기 (8행 유지)
   - 근거: 집정관 레이드 로그 8개 중 7개가 후광보다 먼저 공허 연사를 씀(촉수 격돌 뒤 2~4번째 시전). 후광과 형상을 오프닝에 쓴 6개 중 5개가 연사 → 후광 → 형상(예외 Utell 1개). 고통은 깨어난 악몽 로그 2개 모두 연사 앞. 예: https://www.warcraftlogs.com/reports/fpmhYJX9gTtVDx4Z#fight=10&source=7
   - APL: cds 목록은 halo 가 voidform 앞이라 후광 → 연사 쪽이지만, 파일이 9월 27일(12.1.5 전) 수정이라 로그를 따랐습니다.
   - 같이 바꾼 것: 검사기가 "상단 opener = 집정관 opener" 를 요구해서(validate-guide-manuscripts.js 'Default Shadow flow must match Archon') 상단 opener 도 같은 값으로 맞췄습니다. 지시서의 "상단 필드는 건드리지 않는다"와 어긋나는 유일한 곳입니다.
2. 공허술사 광역 — 깨어난 악몽이면 고통 직접 적용 추가 (영웅 탭 aoe 3번째 행, 광역 요약, 2부 "광역 시작 — 공허술사" 첫 칸 손길 위 가지, 같은 장 첫 문단 한 문장)
   - 전: 촉수 격돌 → 손길 → 광기 → … (고통 없음)
   - 후: 촉수 격돌 → 손길 → (깨어난 악몽이면) 고통 → 광기 → …
   - 근거: 공허술사 쐐기 로그 6개 중 4개가 풀 시작에 고통을 여러 적에게 직접 검(로그별 분당 4.7~6.3회: Robenlly·Cahraela·Shuckmanp·暗中灯). 나머지 2개는 불행. 예: https://www.warcraftlogs.com/reports/1aFhMgxAbVdKL2XN#fight=39&source=16
   - APL: `shadow_word_pain,target_if=max:(refreshable*100000+…),if=talent.invoked_nightmare&refreshable&target.time_to_die>12&(dot.vampiric_touch.ticking|action.tentacle_slam.in_flight)`
3. 집정관 광역 시작 줄 note 에 "쐐기 풀에서는 후광과 4세트 연사의 앞뒤가 로그마다 다릅니다. 둘 다 형상 전에 끝내면 됩니다." 추가 (순서는 그대로)
   - 근거: 집정관 쐐기 로그 8개 큰 풀 21개에서 후광 먼저 10개, 연사 먼저 11개로 갈림.

## 그대로 둔 것과 이유
- 집정관 단일 반복 줄·영웅 탭 단일 우선순위: 로그는 촉수 격돌 → 공허 연사(49%), 생성기 → 광기(정신의 채찍 뒤 광기 32%, 연사 뒤 29%)로 지금 줄과 맞고, 꾸준히 뒤집힌 쌍이 없습니다.
- 집정관 광역 시작 순서(손길 → 격돌 → 후광 → 연사 → 형상): 위 3번처럼 로그가 반반이라 순서는 두고 note 만 달았습니다.
- 공허술사 단일 오프닝: 레이드 로그가 1개(Surania, 공허의 형상부터 시작)뿐이라 바꾸지 않았습니다. 쐐기 풀 6개는 세트 연사 → 형상 → 주입 → 광기 → 격류로 지금 순서와 맞습니다.
- 공허술사 단일 우선순위: 레이드 1개·쐐기 6개에서 광기 → 격류(41%), 격류 → 공허의 폭발(40%)로 지금 설명과 맞습니다. 단일의 "고통 확인" 행은 그 레이드 로그가 불행이라 0회였지만 깨어난 악몽 조건 행이라 둡니다.
- 신의 권능: 보호막(분당 1.9~2.4회)·소실(1.0~1.4회)은 분당 1회를 넘지만 생존·위협 관리 기술이라 딜사이클에 넣지 않았습니다.
