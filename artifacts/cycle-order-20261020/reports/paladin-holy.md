# paladin-holy
- 판정: 일부 보류 (태양의 사자 고침 · 빛의 대장장이 보류)

- 고친 것:
  1. 태양의 사자 오프닝 — 2부 "쿨기와 오프닝" 타임라인 + 영웅 탭 "피해 준비"
     - 전: 빛의 봉화 → 신성 충격 → 응징의 격노 → 고결의 봉화 → 천상의 종 → 영원의 불꽃 → 신성 충격(위: 빛의 섬광) → 영원의 불꽃
     - 후: 빛의 봉화 → 신성 충격 → 심판 → 응징의 격노 → 고결의 봉화 → 천상의 종 → 영원의 불꽃 → 영원의 불꽃 → 신성 충격(위: 빛의 섬광)
     - 근거: 레이드 천상의 종 71회 중 첫 소비와 두 번째 소비 사이에 신성 충격을 넣은 경우 1회, 소비기 2~3번을 바로 이은 경우 60회 이상(영원의 불꽃 ×3 11회, 영원의 불꽃 ×2 → 빛의 섬광 10회, 여명의 빛 ×2 → 빛의 섬광 8회 …). 심판은 레이드 오프닝 첫 12번 안에 8개 중 7개. 응징의 격노 → 고결의 봉화(격노 뒤 3초 안 10회, 앞 3초 안 6회) → 천상의 종 순서는 로그와 맞아 유지. 예: https://www.warcraftlogs.com/reports/DWZGtkCmKyLrQV1a#fight=18&source=4
  2. 2부 "첫 연습" 반복 흐름(두 영웅 공통)
     - 전: 신성 충격 → 영원의 불꽃 → 심판 → 신성화 → 신성 충격 → 정의의 방패
     - 후: 신성 충격 → 영원의 불꽃 → 신성 충격 → 심판(위: 신성화, 적이 오래 머물 때만) → 정의의 방패
     - 근거: 영원의 불꽃 다음 버튼 신성 충격 32%(레이드)·46%(쐐기), 심판은 10~11%. 심판 다음 신성 충격 35~38%, 쐐기는 정의의 방패 26%. 정의의 방패 다음 신성 충격 47%. 신성화는 레이드 분당 0.4회(8개 합 25회), 쐐기 0.15회 미만이라 고정 단계에서 조건부 끼워 넣기로 옮김.
  3. 문장: 2부 첫 연습 본문(신성화), 2부 오프닝 본문(심판 추가, 두 소비 바로 이어 쓰기), 3부 "태양의 사자" 장 본문("첫 소비기, 신성 충격 같은 생성기, 두 번째 소비기" → 두 소비기를 바로 잇고 자원이 모자랄 때만 생성기), 영웅 탭 summary, rail note.

- 그대로 둔 것과 이유:
  - 빛의 대장장이(오프닝·한 명 급락·광역): 상위 로그(레이드 1·쐐기 8)가 이 가이드와 다른 특성 구성입니다. 정의의 방패 분당 10.5(쐐기)·20.8(레이드), 천벌의 망치 1.4~3.6, 응징의 격노·응징의 성전사 뒤 정의의 방패 연타가 중심이고, 고결의 봉화·천상의 종·신성화·여명의 빛은 거의 0회입니다. 이 가이드의 빛의 대장장이 흐름은 태양의 사자 견본 특성(고결의 봉화·천상의 종)에서 영웅 특성만 바꾼 운용이라 순서만 고칠 수 없습니다.
  - 2부 광역 흐름의 오라 숙련 → 고결의 봉화: 로그 13회 중 고결의 봉화 먼저 8회·뒤 5회로 갈림.
  - 한 명 급락 rail·탭: 응급 대응 순서라 로그로 판단 불가.
  - 영원의 불꽃 시전 번호: 가이드는 461432(특성), 로그는 156322(실제 버튼, KB에 있음). 같은 버튼이라 바꾸지 않음.
  - 성스러운 계시(로그의 Reclamation 415388)는 신성 충격·천상의 종·성전사의 일격 뒤에 자동으로 찍히는 효과라 순서 판단에서 뺐습니다.
