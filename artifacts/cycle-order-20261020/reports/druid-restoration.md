# druid-restoration
- 판정: 고침(일부 보류)
- 고친 것:
  - 광역 흐름 맨 앞에 피어나는 생명 추가. 2부 광역 rail: 회복 → 신속한 치유 → 급속 성장 → 재생 → 재생 → 꽃피우기 → 회복 ⇒ 피어나는 생명[풀 시작 · 3중첩 확인](위: 꽃피우기) → 회복 → 신속한 치유 → 급속 성장 → 재생 → 재생 → 회복. 영웅 탭 광역(야생추적자·숲의 수호자) 1번에 피어나는 생명을 넣고 요약도 고침. 근거: 쐐기 광역 풀 64개 중 48개가 처음 세 번 안에 피어나는 생명을 씀(야생추적자 53개 중 38개, 숲의 수호자 11개 중 10개). 예: https://www.warcraftlogs.com/reports/2c9yCJzXFmhHtM1W#fight=54&source=366 (풀마다 피어나는 생명 → 회복 → 신속한 치유 → 급속 성장). APL은 딜 위주(healing 목록은 재생만)라 근거로 쓰지 않음.
  - 꽃피우기를 누르는 순서에서 빼고 조건부 끼워 넣기로 옮김. 한 명 치유 반복 rail: 피어나는 생명 → 신속한 치유 → 회복 → 재생 → 꽃피우기 → 천벌 ⇒ 피어나는 생명(위: 꽃피우기 "꽃 밖에 모였을 때만") → 신속한 치유 → 회복 → 재생 → 천벌. 광역 rail도 같은 방식. 영웅 탭 야생추적자 광역은 7번 → 맨 끝(조건부)으로. 근거: 레이드 8개와 쐐기 10개 모두 꽃피우기 직접 시전 0회이고, Efflorescence 이름의 다른 시전 번호도 없음. 특성 견본 3개를 풀어 보니 모두 생명의 바느질을 골랐음(피어나는 생명 대상 발밑에 꽃피우기가 저절로 자람).
  - 3부 쐐기 한 판 본문·예시: "급속 성장을 쓰고 신속한 치유로" ⇒ "신속한 치유로 … 이어서 급속 성장". 근거: 쐐기 풀 61개 중 36개가 신속한 치유 먼저. 2부 광역 rail과 같은 순서로 맞춤.
  - 오프닝은 순서를 그대로 두고 야생추적자 rail 메모에 "로그마다 다름"을 적음.
  - 같은 순서를 말하는 문장 맞춤: 한 명 치유 장 본문, 광역 장 한 줄 원리·본문, 두 rail 메모.
- 그대로 둔 것과 이유:
  - 야생추적자 레이드 오프닝 순서: 신속한 치유 → 급속 성장(8개 중 5개), 급속 성장 → 영혼 소집(5개 중 5개), 재생 → 신속한 치유(8개 중 5개)로 가이드와 같음. 회복 5개와 재생·신속한 치유 중 무엇을 먼저 쓰는지는 4:2로 갈려 메모만 적음.
  - 영혼 소집 앞뒤의 자연의 신속함-재생: 첫 25초 안에 영혼 소집을 쓴 5개 중 4개가 붙였지만 전체로는 8개 중 4개라 메모로만 적음.
  - 한 명 급락 rail과 영웅 탭 단일 위기: 위기 상황은 로그로 구분할 수 없음. 자연의 치유력은 레이드 0회지만 쐐기에서 분당 0.7~0.9회라 그대로 둠.
  - 숲의 수호자 오프닝·단일: 레이드 로그 0개.
  - 쐐기의 표범 공격(갈퀴 발톱 분당 2.5회 등)은 1~2명 기록에 몰려 있어 넣지 않음. 평온 분당 3.2회는 채널 틱이 시전으로 찍힌 것(평온 다음 평온 87%).
