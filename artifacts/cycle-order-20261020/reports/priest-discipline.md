# priest-discipline
- 판정: 고침 (공허술사 오프닝) · 예언자는 변경 없음(note만 보강)

- 고친 것:
  1. 공허술사 오프닝 — 2부 "쿨기와 오프닝" 타임라인 + 영웅 탭 "피해 준비"
     - 전: 어둠의 권능: 고통 → 신의 권능: 보호막 → 순간 치유(위: 어둠의 치유) → 사도 → 신의 권능: 광휘 → 정신 분열 → 회개 → 공허의 보호막 → 공허의 폭발
     - 후: 어둠의 권능: 고통(위: 탱커가 먼저 맞으면 신의 권능: 보호막) → 마력 주입 → 정신 분열 → 회개 → 공허의 보호막 → 공허의 폭발 → 사도 → 신의 권능: 광휘 1~2회 → 정신 분열
     - 근거: 공허술사 레이드 로그 8개 중 7개가 풀 5초 안에 첫 정신 분열(나머지 1개만 보호막·순간 치유·광휘 뒤 10초). 첫 정신 분열보다 사도를 먼저 쓴 로그 0개 — 사도는 3개가 풀 6~11초(정신 분열 뒤), 5개가 풀 40초 전후 첫 큰 피해. 마력 주입은 8개 모두 첫 22번 안(6개는 풀 2.5초 안). 순간 치유를 오프닝에 쓴 로그 2개. 예: https://www.warcraftlogs.com/reports/t9rwj74aPhmM1XCb#fight=1&source=10
     - 큰 피해 앞 순서(사도 → 광휘 → 정신 분열)는 유지: 레이드 사도 27회 중 14회가 2~5초 안 정신 분열로 이어지고, 정신 분열 직후 사도는 8회.
     - APL: 치유 전문화라 없음.
  2. 같은 장 한 줄 원리·본문 1문단·요점 1·확인 문제, 3부 "공허술사" 장 본문 2문단·요점 1(레이드 기본 흐름)·실수 2, 실전 꿀팁 1번을 "풀 직후 첫 균열 / 큰 피해 앞은 사도·광휘 뒤 정신 분열"로 맞춤.
  3. note 보강(순서는 그대로):
     - 2부 첫 연습 반복 흐름 note: 예언자는 정신 분열 뒤 공허의 보호막을 바로 쓰는 경우도 많음(정신 분열 다음 버튼 1위가 레이드 5개 중 4개, 쐐기 8개 중 4개에서 공허의 보호막).
     - 예언자 오프닝 rail note: 정신 분열·회개 선후는 로그마다 갈림(쐐기 4명 이상 풀 47개, 첫 14번 기준 회개 먼저 28·정신 분열 먼저 19).

- 그대로 둔 것과 이유:
  - 예언자 오프닝(보호막 → 고통 → 정신 분열 → 회개 → 공허의 보호막 → 어둠의 치유 → 성스러운 일격): 쐐기 풀 시작이 보호막·고통으로 여는 경우가 많고, 회개·정신 분열 선후는 플레이어마다 갈림. 사도는 47풀 중 21풀에서만 첫 14번 안(90초 쿨기)이라 고정 단계로 넣지 않음.
  - 2부 반복 흐름(고통 → 정신 분열 → 회개 → 공허의 보호막 → 성스러운 일격 → 정신 분열): 공허술사 정신 분열 다음 회개 29%, 회개 다음 공허의 폭발 37%·공허의 보호막 26%로 대체로 맞음.
  - 광역 흐름·영웅 탭 광역: 사도 → 광휘 → 정신 분열 → 회개/공허의 보호막 → 공허의 폭발이 큰 피해 구간 로그와 맞음.
  - 한 명 급락 rail·탭: 응급 대응 순서라 로그 순서로 판단할 수 없음. 정화·어둠의 치유가 레이드 0회인 것은 네임드(해제 없음)와 견본 차이(레이드는 순간 치유, 쐐기는 어둠의 치유 분당 3.7~5.0) 때문.
  - 상단 opener·priority(예전 필드)와 출처 기록은 손대지 않음.
