# deathknight-frost
- 판정: 고침 (죽음의 인도자만. 종말의 기수는 12.1.5 이후 상위 로그 0개라 그대로)

## 고친 것
1. 죽음의 인도자 숨결 오프닝 (2부 오프닝 타임라인 "오프닝 — 죽음의 인도자 · 숨결 단일")
   - 전: 룬 무기 강화 → 절멸 → 사신의 징표 → 얼음 기둥 → 신드라고사의 숨결 → 서리고룡의 격노 → 절멸 → 냉기의 일격 → 울부짖는 한파 → 서리고룡의 격노
   - 후: 룬 무기 강화 → 사신의 징표 → 얼음 기둥 → 절멸(룬 마력 60이 모자랄 때만) → 신드라고사의 숨결 → 서리고룡의 격노 → 절멸 → 룬 무기 강화 → 절멸 → 서리고룡의 격노(같은 기둥 회수)
   - 근거(레이드 6개, 몰살 자동 피해 제외): 룬 무기 강화로 시작 6/6, 징표가 기둥 앞 4/6, 준비용 절멸이 징표 앞 1/6·기둥과 숨결 사이 3/6·없음 2/6, 숨결 바로 뒤 서리고룡 4/6, 첫 서리고룡 무렵 절멸 → 룬 무기 강화 → 절멸 6/6, 첫 22회 안에 두 번째 서리고룡 4/6.
   - 예: https://www.warcraftlogs.com/reports/Dx4Y7r6H2kdtXRJw#fight=82&source=1565
   - APL(9월 1일) cooldowns 는 기둥 → 숨결 → 징표 → 서리고룡 순이지만 12.1.5 전 파일이라 로그를 따름.
2. 죽음의 인도자 영웅 탭 오프닝
   - 전: "숨결 없는 광역 변형"(룬 무기 강화 → 사신의 징표 → 얼음 기둥 → 서리고룡 → 서리낫 → 냉기의 일격 → 빙하 진군)
   - 후: 위 1번과 같은 숨결 단일 흐름(10단계)
   - 근거: 레이드 6개·쐐기 8개 모두 신드라고사의 숨결 사용(전투당 3~18회). 숨결 없이 서리낫·빙하 진군으로 여는 기록 0개. 냉기파멸 변형은 2부 오프닝 장 세 번째 줄에 그대로 남김.
   - 함께 고침: 영웅 탭 소개 문장("아래 가지 오프닝 차트는 …")과 요점 "오프닝:" 줄.
3. 2부 단일 반복 rail
   - 전: 절멸 → 울부짖는 한파 → 냉기의 일격 → 절멸 → 냉기의 일격 → 울부짖는 한파 → 룬 무기 강화
   - 후: 절멸 → 냉기의 일격 → 울부짖는 한파 → 절멸 → 냉기의 일격 → 울부짖는 한파 → 룬 무기 강화 (위쪽 가지는 같은 스킬에 그대로)
   - 근거: 레이드 3연속 "절멸 > 냉기의 일격 > 울부짖는 한파" 98회 대 "절멸 > 울부짖는 한파 > 냉기의 일격" 41회. KB 단단한 얼음(59057)은 냉기의 일격·빙하 진군에서 발동. note에 "우선순위는 도살기 → 단단한 얼음 → 룬 마력, 손이 가는 순서는 절멸 → 냉기의 일격 → 한파"로 적음. APL single_target 의 우선순위(rime > frost_strike)와는 순서표로서 충돌하지 않음.
4. 2부 광역 반복 rail(숨결 빌드 공통)
   - 전: 서리낫 → 울부짖는 한파 → 빙하 진군 → 서리낫 → 빙하 진군 → 울부짖는 한파
   - 후: 서리낫 → 빙하 진군 → 울부짖는 한파 → 서리낫 → 빙하 진군 → 울부짖는 한파
   - 근거: 쐐기 3연속 "서리낫 > 빙하 진군 > 울부짖는 한파" 320회, "울부짖는 한파 > 서리낫 > 빙하 진군" 355회, 반대 순서는 상위 20 밖.
   - 예: https://www.warcraftlogs.com/reports/aBGWAfDgHy9QdPx7#fight=17&source=1
5. 죽음의 인도자 단일 우선순위(영웅 탭): 사신의 징표 다음에 얼음 기둥 추가(레이드 분당 1.3회, APL pillar_of_frost), 서리고룡 행 설명을 기록의 회수 시점으로.
6. 4부 "심화: 서리고룡 회수 시점" 장: 공개 가이드 두 권장(Icy Veins 약 12초 뒤, Method 몰살 뒤)은 그대로 두고, 상위 기록 14개의 회수 158번 중 143번이 첫 서리고룡 뒤 5초 안(가운데값 약 2.6초, 가장 늦어도 약 11초, 12초 넘게 기다린 경우 없음)이었다는 사실을 더함. 기본 연습 문장을 "같은 기둥 초반 회수"로 맞춤.
7. 2부 오프닝 장 본문 1~3문단·요점 1줄: 준비용 절멸 위치(기둥 뒤, 모자랄 때만)와 첫 서리고룡 뒤 흐름을 위 순서와 맞춤.

## 그대로 둔 것과 이유
- 종말의 기수 오프닝·단일·광역·끼워 넣기: 12.1.5 이후 상위 로그 0개. 단일 우선순위의 "가속 12초 종료 뒤 회수" 설명도 근거 없이 바꾸지 않음.
- 냉기파멸 광역 변형 오프닝·반복 rail: 로그에 이 빌드가 없어 판단 근거 없음.
- 죽음의 인도자 단일·광역 우선순위의 나머지 순서: 우선순위 표로서 APL과 맞음(도살기 → 단단한 얼음 → 룬 마력).
- 죽음의 진군·죽음의 손아귀·대마법 보호막: 이동·제어·생존기.
