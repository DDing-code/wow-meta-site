# warlock-destruction
- 판정: 고침 (두 영웅 특성 오프닝만)
- 고친 것:
  - 지옥소환사 오프닝(2부 오프닝 rail·영웅 탭): … 혼돈의 화살 → 어둠의 연소 → 소각 → 혼돈의 화살 을 … 혼돈의 화살 → **소각 → 점화** → 혼돈의 화살 로 바꿨습니다. 적개심 캡션은 "정령 직후 · 쇠퇴 대상에"로 바꿨습니다.
    - 근거: 상위 레이드 로그 7개 중 6개가 두 번째 혼돈의 화살 뒤 소각을 썼고, 어둠의 연소는 첫 22회 안에 2개에만 나옴. 정령 → 적개심은 7개 모두 바로 이어짐. 예: https://www.warcraftlogs.com/reports/TQ9HVvbP4rRa2ztL#fight=5&source=9
    - APL: 기본 목록 `conflagrate,if=soul_shard<=4.2&buff.backdraft.stack<1` → `summon_infernal` → `malevolence` → … `chaos_bolt` → `incinerate` (9월 10일 수정).
  - 악마학자 오프닝(2부 오프닝 rail·영웅 탭): 영혼의 불꽃 → 점화 → 정령 → 혼돈의 화살 → 점화 → 혼돈의 화살 → 지옥불 화살 → 어둠의 연소 → 황폐 → 소각 을 **제물** → 점화 → 정령 → 혼돈의 화살 → 점화 → 혼돈의 화살 → **소각 → 소각 → 점화 → 혼돈의 화살** 로 바꿨습니다. rail 이름은 "(제물 시작 · 단일)"로 바꿨습니다.
    - 근거: 상위 레이드 로그 4개 중 3개가 제물로 시작(1개는 대재앙). 영혼의 불꽃은 1개만 5초 뒤 사용. 지옥불 화살·어둠의 연소·황폐는 4개 모두 첫 22회에 없음. 예: https://www.warcraftlogs.com/reports/j2m9CMwJBAt4rfH1#fight=47&source=471
    - APL: `precombat … soul_fire`(특성이 있을 때만), 기본 목록의 `conflagrate → chaos_bolt(악마술) → … incinerate` 흐름과 맞습니다.
  - 같은 순서로 맞춘 문장: 2부 오프닝 장의 한 줄 원리, 본문 두 단락(악마학자 제물 시작, 첫 소비 뒤 소각 → 점화 → 혼돈의 화살, 발동은 뜰 때만), 실수 문장, 두 영웅 탭 오프닝 요약.
- 그대로 둔 것과 이유:
  - 지옥소환사 첫 점화의 자리: 정령 앞 3개, 적개심 뒤 4개(57%)라 60%에 못 미쳐 그대로 두고 note에 "로그마다 다름"을 적었습니다.
  - 악마학자 정령·점화 앞뒤: 정령이 있는 로그 3개가 2:1로 갈려 그대로 두었습니다.
  - 단일·광역 우선순위와 2부 단일·광역 반복 rail: 레이드 반복이 점화 → 혼돈의 화살(41%) → 소각 반복이고 쇠퇴 → 점화(45%)라 가이드와 맞습니다.
  - 악마학자 광역의 대재앙·제물 앞뒤: 쐐기 풀을 직접 뽑아 보니 대재앙 먼저와 제물 먼저가 풀마다 갈려(대재앙 재사용에 따라 다름) 그대로 두었습니다.
  - 불의 호수(분당 3~11회로 찍힘): KB에서 특성(대재앙이 남기는 장판)이라 누르는 버튼이 아닙니다. 대혼란·대재앙·불의 비(레이드 분당 1회 안팎)는 님리사 쫄 구간 기술이라 광역 쪽에 이미 있습니다.
  - 어둠의 연소(지옥소환사 레이드 분당 12회): 전투 마지막 20%에 몰려 있고(마무리 구간) 그 밖에는 무료 발동 사용이라 단일 우선순위의 기존 조건과 맞습니다.
