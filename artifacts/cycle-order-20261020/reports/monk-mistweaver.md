# monk-mistweaver
- 판정: 고침

- 고친 것:
  1. 천신의 대변자 오프닝 — 2부 "쿨기와 오프닝" 타임라인 + 영웅 탭 "피해 준비"
     - 전: 소생의 안개 → 집중의 천둥 차 → 질풍차기 → 생기 충전 → 천신합일 → 질풍차기 → 소생의 안개 → 생기 충전
     - 후: 소생의 안개 → 질풍차기 → 집중의 천둥 차 → 소생의 안개 → 생기 충전 → 천신합일 → 질풍차기 → 소생의 안개 → 생기 충전
     - 근거: 레이드 집중의 천둥 차 119회의 다음 버튼 소생의 안개 84%(질풍차기 7%), 바로 앞 버튼 질풍차기 41%. 풀 직후에도 8개 중 6개가 차 → 소생의 안개. 원래 탭 note도 "차 뒤 소생의 안개로 보강"이라 적혀 있어 행 순서만 어긋나 있었음. 예: https://www.warcraftlogs.com/reports/tZPXha6kfjrbDB4N#fight=38&source=1055
  2. 조화의 종사 오프닝 — 2부 타임라인 + 영웅 탭 "피해 준비"
     - 전: 소생의 안개 → 질풍차기 → 생기 충전 → 집중의 천둥 차 → 포용의 안개 → 생기 충전 → 기의 고치 → 마나 차
     - 후: 소생의 안개 → 질풍차기 → 생기 충전 → 집중의 천둥 차 → 질풍차기 → 셰이룬의 선물 → 포용의 안개 → 기의 고치 → 마나 차
     - 근거: 레이드 차 68회의 다음 버튼 질풍차기 90%, 질풍차기 다음 셰이룬의 선물 47%. 로그 5개 중 4개가 차 뒤 질풍차기·셰이룬의 선물을 번갈아 씀(나머지 1개는 생기 충전). 예: https://www.warcraftlogs.com/reports/AaGPxMCWmRgqjbtf#fight=1&source=4
  3. 조화의 종사 광역 — 2부 "광역 치유 흐름" 타임라인 + 영웅 탭 "파티·공대 피해": 차 → 생기 충전 → 셰이룬의 선물 ⇒ 차 → 질풍차기 → 셰이룬의 선물 → … → 생기 충전 (같은 근거)
  4. 2부 "첫 연습" 반복 흐름: 차의 끼워 넣기 조건 "질풍차기·소생을 비운 뒤" ⇒ "질풍차기 직후 · 다음 주문 강화"(천신 레이드는 차 뒤 소생의 안개를 바로 써서 "소생을 비운 뒤"와 어긋남). note에 영웅·빌드별 차 다음 버튼을 적음(천신 레이드 소생의 안개 84%, 조화 질풍차기 90%, 쐐기 해오름차기 빌드 해오름차기 83%).
  5. 문장: 2부 오프닝 장 본문 1·2문단, 광역 장 본문 3문단, 영웅 탭 summary, 천신 오프닝 rail note(풀 직후 기의 고치 — 레이드 오프닝 첫 12번 안 8개 중 5개).

- 그대로 둔 것과 이유:
  - 천신합일 앞뒤(앞: 질풍차기 32%·생기 충전 21%, 뒤: 질풍차기 43%·생기 충전 21%)와 천신의 대변자 광역 흐름: 로그와 맞음.
  - 2부 첫 연습 반복 흐름의 순서(소생의 안개 → 질풍차기 36%, 질풍차기 → 생기 충전 38% 등): 맞음.
  - 한 명 급락 rail·탭: 응급 대응 순서라 로그로 판단 불가.
  - 쐐기: 이 가이드에 쐐기 전용 오프닝 rail이 없고, 3부 쐐기 장의 해오름차기 중심 설명은 4명 이상 풀의 분당 해오름차기 13.5·회전 학다리차기 11.8과 크게 어긋나지 않아 그대로 둠.
