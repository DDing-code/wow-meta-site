# shaman-elemental
- 판정: 고침 (폭풍인도자 일부 보류)
- 로그: 12.1.5 이후 상위 레이드 7개·쐐기 8개, 모두 선견자. 폭풍인도자 로그는 없습니다.
- 지난 라운드에 고친 단일 반복 줄(전격의 불길·화염 충격 설명)은 그대로 두었습니다.

## 고친 것
1. 선견자 단일 오프닝 (영웅 탭 opener·요약, 2부 오프닝 타임라인·note, 같은 장 한 줄 원리·본문 세 문단·실수 하나)
   - 전: 폭풍수호자 → 용암 폭발(사전 시전) → 선조의 신속함 → 용암 폭발 → 전격의 불길 → 승천 → 강화 번개 화살 → 정기 작렬
   - 후: 폭풍수호자 → 강화 번개 화살 → 강화 번개 화살 → 선조의 신속함 → 승천 → 용암 폭발 → 정기 작렬 → 용암 폭발
   - 근거: 레이드 로그 7개 중 5개가 강화 번개 화살을 승천 전에 씀. 사전 시전 용암 폭발은 1개, 승천 전 전격의 불길은 2개뿐. 승천 뒤 용암 폭발·정기 작렬 교대는 5개. 선조의 신속함은 오프닝에 쓴 6개 중 4개가 승천 바로 앞(또는 같은 순간). 예: https://www.warcraftlogs.com/reports/nRWZVA2J3NKHxqPw#fight=35&source=3
   - APL: single_target `lightning_bolt,if=set_bonus.mid2_4pc&buff.stormkeeper.up&cooldown.ascendance.remains<2*gcd&…` (주석 "Prespend SK charges before going into Ascendance"), flame_shock·voltaic_blaze 의 `cooldown.ascendance.remains>5`, precombat 은 stormkeeper 만. 승천이 시작할 때 화염 충격을 걸어 준다는 KB 설명과도 맞습니다.
2. 선견자 광역 진입과 광역 우선순위 (2부 "광역 진입 — 선견자", 영웅 탭 aoe·요약, 같은 장 첫 문단, 3부 "쐐기 한 판" 첫 문단·예시)
   - 진입 전: 폭풍수호자 → 선조의 신속함 → 전격의 불길 → 승천 → 용암 폭발 → 강화 연쇄 번개
   - 진입 후: 전격의 불길 → 폭풍수호자 → 강화 연쇄 번개(두 번) → 선조의 신속함 → 승천 → 지진 → 용암 폭발
   - 우선순위 전: 폭풍수호자 → 선조 → 전격 → 승천 → 지진 → 정기 작렬 → 용암 폭발 → 연쇄 번개
   - 우선순위 후: 전격 → 폭풍수호자 → 강화 연쇄 번개 → 선조 → 승천 → 용암 폭발(정화의 불길) → 지진(선조가 있으면 먼저) → 정기 작렬 → 연쇄 번개
   - 근거: 쐐기 광역 풀 15개 중 13개가 전격의 불길을 폭풍수호자보다 먼저 씀. 폭풍수호자·승천을 쓴 풀 10개 중 7개가 강화 연쇄 번개 두 번을 승천 전에 씀. 승천 다음은 지진 10개 중 8개. 전격의 불길 1,275회 중 바로 다음이 용암 폭발 58%, 지진 7%.
   - APL: aoe 의 `chain_lightning,if=buff.stormkeeper.up&…&talent.call_of_the_ancestors&set_bonus.mid2_4pc` 가 ascendance 위, `earthquake,if=buff.call_of_the_ancestors.up|…` ("[FS] EQ with ancestors").
3. 광역 반복 줄
   - 전: 연쇄 번개(위 전격의 불길) → 지진 → 연쇄 번개 → 용암 폭발 → 연쇄 번개 → 지진
   - 후: 전격의 불길 → 용암 폭발 → 지진(위 4세트 무료 지진) → 연쇄 번개(위 선조) → 연쇄 번개(위 폭풍수호자) → 지진
   - 근거: 위 58% 숫자, 용암 폭발 다음 지진 25%, 지진 다음 연쇄 번개 40%. 같은 장 둘째 문단이 이미 "전격의 불길 다음 용암 폭발"이라고 말하고 있어 줄을 문장에 맞췄습니다.
4. 선견자 단일 우선순위·단일 반복 줄: 순서는 그대로, 승천 설명만 "폭풍수호자 강화 두 번을 쓴 뒤"로 맞춤.
5. 폭풍인도자 오프닝: 강화 번개 화살을 승천 뒤에서 폭풍수호자 바로 뒤로 옮김(단일 우선순위 승천 설명도 맞춤). 로그는 없고, APL 주석이 "SB in both 1t and 2t" 로 폭풍인도자도 같은 처리를 적고 있어서 이 한 칸만 옮겼습니다.

## 그대로 둔 것과 이유
- 선견자 단일 반복 줄과 단일 우선순위 순서: 정기 작렬 앞은 용암 폭발 80%, 번개 화살 다음은 용암 폭발로 지금 줄과 맞습니다.
- 단일의 화염 충격/전격의 불길: 로그 15개 모두 화염 충격 0회, 전격의 불길 분당 4.9~6.6회(사실상 쿨마다, 레이드에서 바로 다음 용암 폭발 71%)입니다. 지난 라운드가 "견본은 전격의 불길 없음"으로 정리한 부분이라 뒤집지 않았습니다.
- 레이드에서 분당 1회를 넘는 연쇄 번개·지진은 님리사 쫄 때문이라 단일 우선순위에 넣지 않았습니다. 쐐기의 늑대 정령·날카로운 바람은 이동·차단이라 넣지 않았습니다. 지진 462620은 같은 지진의 다른 번호입니다.
- 폭풍인도자 단일·광역 우선순위: 로그가 없어 그대로 둡니다.
- 상단 opener·priority 는 지시대로 건드리지 않았습니다(정기는 검사기가 같기를 요구하지 않음). 그래서 지금 상단 opener 는 바뀌기 전 선견자 오프닝입니다.
