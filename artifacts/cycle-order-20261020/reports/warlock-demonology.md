# warlock-demonology
- 판정: 고침 (악마학자 오프닝 뒷부분만, 영혼 수확자 보류)
- 고친 것:
  - 악마학자 오프닝(2부 오프닝 rail·영웅 탭): … 폭군 → 굴단의 손 → 굴단의 손 → 악마 화살 → 굴단의 손 → 파열 을 … 폭군 → 굴단의 손 → 굴단의 손 → **어둠의 화살 → 파열 → 굴단의 손** 으로 바꿨습니다.
    - 근거: 상위 레이드 로그 8개 중 7개가 두 번째 굴단의 손 뒤 어둠의 화살 1~2번(1개는 지옥불 화살)을 쓰고 바로 파열을 썼습니다. 두 번째 악마 화살은 첫 12회 안에 3개에만 나옴. 예: https://www.warcraftlogs.com/reports/F8DM36ZXTrxfhvbA#fight=28&source=20
    - APL: `diabolist … implosion,if=buff.wild_imps.stack>=6&(active_enemies>2|talent.to_hell_and_back.enabled)` 가 `hand_of_guldan` 보다 위라 같은 흐름입니다(APL 8월 30일 수정).
  - 같은 순서로 맞춘 문장: 2부 오프닝 장 본문에 로그 근거 한 문장, 요점에 "폭군 뒤 굴단의 손 두 번 → 어둠의 화살 → 파열", rail note에 "흑마법서와 공포사냥개의 앞뒤는 로그마다 다름".
- 그대로 둔 것과 이유:
  - 악마학자 오프닝의 흑마법서·공포사냥개 앞뒤: 로그가 3:3(2개는 첫 22회에 사냥개 없음)이라 그대로 두었습니다.
  - 단일·광역 우선순위와 2부 단일·광역 반복 rail: 레이드 반복은 굴단의 손 ↔ 악마 화살이 번갈아 나오고(악마 화살 → 굴단의 손 3회 안 90%), 쐐기 풀 시작(직접 뽑은 풀 24개)도 공포사냥개 → (흑마법서) → 어둠의 화살 → 폭군 → 굴단의 손 ×2 → 파열로 가이드·APL과 맞습니다.
  - 파멸수호병 소환 행: 상위 로그에서 0회지만 "고른 빌드" 조건이 붙은 행이라 그대로 두었습니다.
  - 영혼 수확자 전체: 12.1.5 이후 상위 로그가 0개라 바꾸지 않았습니다.
