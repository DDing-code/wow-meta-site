# mage-frost
- 판정: 일부 보류 (고친 것과 보류한 것이 함께 있음)

## 고친 것
- **주문술사 광역 진입(2부 광역 rail·영웅 탭 광역 흐름)**: 눈보라(미리) → 진눈깨비 → 구슬 → 광선 → 얼음창 → 눈보라
  → **구슬 → 눈보라(빗발치는 냉기로 즉시) → 진눈깨비 → 얼음창 → 광선 → 얼음창**
  - 근거: 주문술사 쐐기에서 대상이 3명 이상인 풀 14개 중 10개가 구슬을 눈보라보다 먼저 썼습니다. 8개는 구슬 → 눈보라 → 진눈깨비 순서로 시작했습니다. 풀 직전에 눈보라를 미리 깐 기록은 0개였습니다. 예시는 https://www.warcraftlogs.com/reports/GQwfqKCYktgBDpZ2#fight=2&source=1 의 23초·201초 풀입니다.
  - APL: spellslinger 에서 `blizzard,if=…&buff.freezing_rain.up` 이 `frozen_orb` 아래에 있습니다.
- **서리불꽃 광역 진입(2부 광역 rail·영웅 탭 광역 흐름)**: 눈보라(미리) → 광선 → 진눈깨비 → 구슬 → 강화 화살 → 혜성 폭풍
  → **광선 → 진눈깨비 → 구슬(위쪽 가지: 빗발치는 냉기를 골랐다면 눈보라) → 강화 화살 → 혹한의 쐐기 → 혜성 폭풍**
  - 근거: 서리불꽃 쐐기 로그 8개 중 6개는 눈보라를 한 번도 쓰지 않았습니다. 대상 3명 이상 풀 17개 중 눈보라로 시작한 풀은 0개였고, 광선으로 시작한 풀이 6개였습니다. 예시는 https://www.warcraftlogs.com/reports/9QWDBMwcKn6gdbft#fight=18&source=7 입니다.
  - APL: frostfire 에서 `comet_storm,if=…prev_gcd.2.glacial_spike` 이므로 광역에서는 쐐기 뒤에 혜성을 씁니다.
- **서리불꽃 오프닝 5~6칸(2부 오프닝 rail·영웅 탭)**: 혜성 폭풍 → 얼음창 → **얼음창 → 혹한의 쐐기 → 혜성 폭풍**
  - 근거: 레이드 5개 중 4개가 첫 혹한의 쐐기(9~18초)를 쓴 뒤 27~33초에 첫 혜성 폭풍을 썼습니다. 오프닝 안에서 혜성을 쓴 것은 1개(Rafusmagus)뿐입니다. 예시는 https://www.warcraftlogs.com/reports/HWMbwmfpXJg4KNB3#fight=4&source=22 입니다.
- **주문술사 단일 반복 rail**: 위쪽 가지인 얼어붙은 구슬을 4번 칸(얼음 화살)에서 6번 칸(진눈깨비) 앞으로 옮겼습니다.
  - 근거: 레이드 구슬 67회 중 바로 앞이 얼음창인 경우가 48%였습니다. 바로 뒤는 진눈깨비 57%, 얼음창 18%였습니다. 겨울해일 때문에 구슬이 두뇌 빙결을 줍니다.
- **같은 순서를 말하는 문장도 맞춤**: 오프닝 장 본문(서리불꽃 혜성 시점)·요점("사전 눈보라" 표현)·타임라인 안내 문구, 광역 장 본문, 영웅 탭 광역 흐름 요약 두 개

## 그대로 둔 것과 이유
- **주문술사 오프닝(화살 → 진눈깨비 → 구슬 → 광선 → 얼음창 → 쐐기)**: 레이드 6개 중 3개가 정확히 이 순서였고, 나머지는 서로 달랐습니다. APL cds 순서와도 같습니다.
- **두 영웅의 단일·광역 우선순위**: APL과 크게 다르지 않고, 로그에 꾸준히 거꾸로 나타나는 쌍이 없었습니다.
- **얼음 보호막·일렁임·마법 차단**: 생존기·이동기·차단이라 딜사이클 대상이 아닙니다.

## 보류·사용자 확인 필요
- **서리불꽃 오프닝 첫 네 칸** (사용자 결정 필요)
  - 레이드 5개 중 4개가 사전 시전 얼음불꽃 화살 바로 뒤에 **진눈깨비를 광선보다 먼저** 썼습니다(화살 → 진눈깨비 → 광선 → 구슬).
  - 하지만 검사기(`validate-guide-manuscripts.js`)가 서리불꽃 오프닝 첫 네 칸을 `431044,205021,44614,84714`(화살 → 광선 → 진눈깨비 → 구슬)로 고정하고 있어 바꾸지 않았습니다.
  - 오프닝 장의 실수 문장 "서리불꽃 오프닝을 주문술사 순서로 써서 광선보다 진눈깨비와 구슬을 먼저 씁니다"도 로그와 어긋납니다. 伊岚翠는 정확히 주문술사 순서로 썼습니다.
  - 고치려면 검사기 규칙을 함께 바꿔야 합니다.
- **서리불꽃 혜성 폭풍 시점(단일 우선순위 2번 "준비되면 사용")**
  - 광선 뒤 6초 안에 쓴 비율은 레이드 37%, 쐐기 42%였습니다. 나머지는 다음 구슬 무렵까지 들고 가는 등 사람마다 달랐습니다(Rafusmagus는 늘 바로, 伊岚翠는 대부분 30초 넘게 뒤).
  - 로그가 갈려서 우선순위는 바꾸지 않았습니다.
- **쐐기 서리불꽃 견본에 빗발치는 냉기가 들어 있는지**는 특성 견본 범위라 확인하지 않았습니다. 상위 서리불꽃 대부분은 눈보라를 쓰지 않았습니다.
- 2026-10-20 t1 후속: 서리불꽃 오프닝 첫 네 칸 보류 건은 상위 로그 우선 원칙에 따라 화살 → 진눈깨비 → 광선 → 구슬로 고치고 검사기 고정값도 바꿨다(patches/mage-frost.cjs 끝부분).
