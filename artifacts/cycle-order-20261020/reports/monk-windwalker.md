# monk-windwalker
- 판정: 고침
- 고친 것:
  - 음영파 오프닝(2부 rail·영웅 탭): 해오름차기 → 분노의 주먹(초기화됐을 때만) → 소용돌이 용의 주먹 → 해오름차기 → 소용돌이 용의 주먹 → 분노의 주먹(다시 준비되면). 근거: 음영파 레이드 로그 7개 모두 첫 해오름차기 뒤 두 번째 분노의 주먹보다 소용돌이 용의 주먹이 먼저. 예시 https://www.warcraftlogs.com/reports/twMfRJcChWF9A3kn#fight=28&source=49 . APL default_st 첫 줄 whirling_dragon_punch(분노·해오름 쿨). 같은 장 첫 문단·rail note·영웅 탭 소개에 로그 문장 추가.
  - 천신의 대변자 오프닝(2부 rail ②·영웅 탭): 분노의 주먹(초기화됐을 때만) → 소용돌이 용의 주먹 → 정점의 발구르기 → 천신합일 → 분노의 주먹 → 소용돌이 용의 주먹 → 분노의 주먹(다시 준비되면) → 회전 학다리차기 → 해오름차기 → 천신합일 → 분노의 주먹. 근거: 천신 레이드 로그 8개 중 6개가 첫 해오름차기 바로 뒤 소용돌이 용의 주먹(1개는 바람의 군주의 일격), 정점의 발구르기는 8개 모두 0회(레이드 분당 0회·쐐기 1.5회, 같은 번호를 음영파는 분당 1.4회 사용), 천신합일은 전투 11~14초에 해오름차기 등 뒤, 6개가 천신합일 → 분노의 주먹. 예시 https://www.warcraftlogs.com/reports/QhwxjpvWZ6HGcMtL#fight=6&source=2 . 같은 장 둘째 문단의 발구르기 문장을 "호안주 마지막 노드를 골랐다면"으로.
  - 두 영웅 단일 우선순위 맨 위에 등선 추가(음영파 레이드 분당 1.06회, APL zenith 목록이 default_st 앞). 2부 단일 연습 본문의 음영파 우선순위 문장에도 등선을 앞에 넣음.
  - 천신의 대변자 단일 우선순위의 정점의 발구르기 행 설명을 "호안주 마지막 노드를 골랐을 때만(쐐기 견본), 레이드 상위 로그는 쓰지 않음"으로 바꿈(행은 유지).
  - 검사기 특수 규칙 확인: 영웅마다 오프닝 8·12단계, 단일 13행, 광역 12행, 모든 행 atomic-skill·설명 25자 초과, 음영파 쪽 123904·443028 없음.
- 그대로 둔 것과 이유:
  - 2부 단일 반복 rail: 이웃 쌍 비율이 한쪽으로 꾸준히 뒤집힌 곳이 없음(범의 장풍→분노의 주먹 33%/반대 70%는 반복 고리의 시작점이라 둠).
  - 광역 rail·우선순위: 천신 쐐기 풀 시작 3개가 등선 → 분노의 주먹 → 회전 학다리차기 → 해오름차기로 rail 과 같고, 쐐기에서는 정점의 발구르기를 씀(분당 1.5회).
  - 바람의 군주의 일격 시작(4부): 로그 1개(焰诗: 분노의 주먹 → 해오름차기 → 바람의 군주의 일격)뿐이라 판단 보류.
  - 구르기(분당 2회)는 이동기라 넣지 않음. APL 은 8월 26일판(12.1.5 전)이라 조건 설명에만 씀.
