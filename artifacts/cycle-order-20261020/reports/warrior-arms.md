# warrior-arms
- 판정: 고침 (학살자만. 거신은 12.1.5 이후 상위 로그 0개라 그대로)

## 고친 것
1. 학살자 오프닝 (2부 오프닝 타임라인 "학살자 오프닝" + 영웅 탭 학살자 opener)
   - 전: 돌진 → 필사의 일격 → 분쇄 → 투신 → 거인의 강타 → 칼날폭풍 → 마무리 일격
   - 후: 돌진 → 회전베기 → 투신 → 거인의 강타 → 마무리 일격(급살) → 칼날폭풍 → 필사의 일격
   - 근거: 레이드 7개 중 7개가 이 순서(회전베기로 시작, 거인의 강타 뒤 급살 마무리 일격 → 칼날폭풍 → 첫 필사의 일격). 분쇄를 직접 쓴 기록 0개. 투신과 거인의 강타의 앞뒤는 로그마다 다름(거인의 강타 먼저 4, 투신 먼저 2, 같은 순간 1) → note에 적음.
   - 예: https://www.warcraftlogs.com/reports/6z4mfhLwMTyvWCKx#fight=10&source=10
   - APL slayer_st: `cleave,if=dot.rend_dot.remains<=gcd…` → `avatar` → `execute,if=…cooldown.bladestorm.ready&buff.imminent_demise.stack<1` → `colossus_smash` → `bladestorm,if=debuff.colossus_smash.up…`
   - KB 근거로 이유를 적음: 전술적 우위(거인의 강타가 급살 1회), 임박한 파멸(급살 소비 → 다음 칼날폭풍 공격 +1), 불안정한 정신(칼날폭풍 중 필사의 일격 자동), 잔혹한 마무리(칼날폭풍 뒤 필사의 일격 50%).
2. 학살자 단일 우선순위 (영웅 탭)
   - 전: 분쇄 → 투신 → 거인의 강타 → 마무리 일격 → 칼날폭풍 → 필사의 일격 → 제압
   - 후: 회전베기(분쇄 갱신) → 투신 → 거인의 강타 → 급살 마무리 일격 → 칼날폭풍 → 필사의 일격 → 제압 → 영웅의 일격 → 격돌
   - 근거: 레이드 분당 분쇄 0회·회전베기 4.2회·영웅의 일격 5.8회·격돌 3.6회. APL slayer_st 의 cleave / heroic_strike / slam.
3. 학살자 광역 우선순위 (영웅 탭)
   - 전: … 거인의 강타 → 칼날폭풍 → 마무리 일격 → 필사의 일격 → 제압
   - 후: … 거인의 강타 → 마무리 일격 → 칼날폭풍 → 제압 → 필사의 일격
   - 근거: 쐐기 광역 풀(적 3명 이상) 칼날폭풍 6회 중 4회가 거인의 강타 뒤 급살 마무리 일격 다음. 쐐기 제압 분당 10.7회(레이드의 1.9배), 손으로 쓴 필사의 일격은 그보다 적음(칼날폭풍 자동 시전 포함 11.4회). APL slayer_aoe 의 `overpower,if=talent.dreadnaught` 가 `mortal_strike` 위.
   - 예: https://www.warcraftlogs.com/reports/w4yAWnmzVBLtb8CX#fight=4&source=181
4. 2부 단일·광역 "영웅 특성별로 끼워 넣는 것" rail: 학살자 마무리 일격을 칼날폭풍 앞으로(위 1·3번과 같은 근거).
5. 같은 순서를 말하는 문장 정리: 오프닝 장 한 줄 원리·본문 1·2문단, 단일 연습 본문 2문단, 3부 학살자 장 3문단에 한 문장, 3부 쐐기 한 판 1문단과 예시(회전베기 → 거인의 강타 순서. 쐐기 풀(적 3명 이상) 10개 모두 회전베기를 거인의 강타보다 먼저 씀).

## 그대로 둔 것과 이유
- 단일 반복 rail: 지난 라운드에 고친 것이 로그와 맞음(회전베기 → 필사의 일격 66%, 영웅의 일격 → 필사의 일격 75%). 다시 뒤집지 않음.
- 광역 공통 반복 rail: 두 영웅 특성 공통이고, 거신(로그 없음)은 APL colossus_aoe 에서 필사의 일격이 제압 위라 공통 줄은 그대로. 학살자 제압 상향은 끼워 넣기 rail과 영웅 탭에만 반영.
- 거신 오프닝·단일·광역 전부: 12.1.5 이후 상위 로그 0개. APL colossus_st(필사의 일격 → 분쇄/회전베기 → 투신 → 거인의 강타 → 쇄파)와도 지금 순서가 크게 어긋나지 않음.
- 돌진(분당 2.6회)·주문 반사·전투의 외침 등: 이동·생존·버프라 딜사이클 표에 넣지 않음.

## 보류·사용자 확인 필요
- 영웅의 일격 위치: APL은 영웅의 일격을 필사의 일격 위에 두지만, 본문 공통 우선순위(필사의 일격 → … → 제압 → 영웅의 일격 → 격돌)와 4부 심화 장("필사의 일격을 늦추면서까지 맞출 대상은 아님")에 맞춰 영웅 탭에서도 제압 다음에 둠. 로그의 다음 스킬 표만으로는 확정하기 어려움.
- 학살자 광역 제압 행은 "일격무쌍을 골랐다면"으로 적음. 쐐기 견본에 일격무쌍이 실제로 있는지는 견본 코드를 풀어 보지 않았음.
- 2부 단일 연습 본문의 "공통 우선순위" 줄(필사의 일격 → 거인의 강타 → …)과 영웅 탭(거인의 강타가 필사의 일격 위)의 차이는 이번 라운드 전부터 있던 것으로, 이번 범위에서 손대지 않음.
