# mage-arcane
- 판정: 고침 (성난태양만. 주문술사는 로그가 없어 그대로)

## 고친 것
- **성난태양 평시 반복(2부 단일 rail)**: 화살 → 탄막 → 오색 화살 → 화살 → 탄막(25) → 보주 → 작렬 → **화살 → 오색 화살 → 탄막** → 화살 → 탄막(25) → 보주 → 작렬
  - 근거: 레이드 8개 모두에서 오색 화살(241회) 다음 버튼은 탄막이 78%였습니다. 탄막 뒤 3회 안에 오색 화살이 온 경우는 34%뿐입니다. 탄막과 탄막 사이 흐름은 [화살 오색] 96회, [화살 화살 오색] 58회였고 [오색 화살]은 14회였습니다. 쐐기 8개에서도 오색 화살 다음은 탄막이 82%였습니다.
  - APL: sunfury 목록에서 탄막은 충전물 4개를 요구하고(`arcane_barrage,if=(buff.arcane_charge.stack=4&…)`), 오색 화살이 충전물 4개를 채웁니다.
- **성난태양 비전의 영혼(2부 단일 rail)**: 화살 → 탄막 → 화살 → 탄막 → 오색 화살 → 탄막(반복) → **화살(12 미만이면) → 탄막 4번 연속 → 화살(평시로)**. 이 구간은 한 번만 지나가는 구간이라 반복 표시를 뺐습니다.
  - 근거: 레이드 8개의 쇄도 31번 중 29번에서 쇄도 18~21초 뒤에 탄막이 4번 이상 이어졌고(대개 5번), 그 사이에 화살이 없었습니다. 예시는 https://www.warcraftlogs.com/reports/78hvzrVRXKn6NYMa#fight=28&source=3 의 113~117초 구간입니다.
  - APL: `arcane_barrage,if=…|buff.arcane_soul.up`
- **성난태양 오프닝(2부 오프닝 rail·영웅 탭)**: … 여파 → 오색 화살 → 화살 → 탄막 → … **여파 → 화살(번뜩임이 남으면 한 번 더) → 오색 화살 → 탄막**
  - 근거: 레이드 8개 중 7개가 여파 뒤에 오색 화살보다 화살을 먼저 썼고, 그중 5개는 화살을 두 번 썼습니다. 예시는 https://www.warcraftlogs.com/reports/hrQKRBjACbvqHdMG#fight=50&source=7 입니다.
  - APL: sunfury 1번째 줄인 `arcane_missiles,if=buff.clearcasting.react&buff.arcane_salvo.stack<12`
- **성난태양 광역 반복(2부 광역 rail)**: 화살 → 탄막 → 보주 → 오색 화살 → … **화살 → 오색 화살 → 탄막 → 보주** → 화살 → 탄막 → 작렬
  - 근거: 쐐기 보주 154회 중 60%는 바로 앞이 탄막이었고, 보주 바로 뒤에 오색 화살이 온 경우는 0%였습니다. 쐐기 오색 화살 다음은 탄막이 82%였습니다.
- **같은 순서를 말하는 문장도 맞춤**: 오프닝 장 본문 한 문장과 "연결 단계" 요점, 성난태양 장 본문(영혼 중 탄막 연속)과 실수 문장("연사 12 미만인데도 탄막만 연타"), 각 rail note

## 그대로 둔 것과 이유
- **영웅 탭 단일·광역 우선순위**: APL sunfury 순서와 같습니다. 오색 화살이 일반 탄막보다 위에 있어서 로그의 "오색 화살 → 탄막"과도 맞습니다.
- **오프닝 앞부분(보주 준비 → 쇄도 → 화살 → 탄막 → 여파)**: 쇄도 뒤 화살을 탄막보다 먼저 쓴 로그가 5개, 쇄도 바로 뒤 탄막을 쓴 로그가 2개였습니다. 과반이 가이드와 같아 그대로 뒀습니다.
- **주문술사 전체**: 12.1.5 이후 상위 로그가 0개입니다.
- **대조 자료가 표시한 일렁임·오색 방벽·신비한 폭발**: 일렁임은 이동기, 오색 방벽은 생존기라 딜사이클 대상이 아닙니다. 신비한 폭발(쐐기 분당 1.7회)은 근접한 무리에 충전물을 채울 때 가끔 3~4번 이어 쓰는 정도입니다. APL에도 없어서 "기본 광역에서 반복하지 않는다"는 문장은 그대로 뒀습니다.
