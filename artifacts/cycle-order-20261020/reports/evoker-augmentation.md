# evoker-augmentation
- 판정: 고침 (시간 감시자만, 비늘사령관 보류)
- 고친 것:
  - 시간 감시자 오프닝(2부 오프닝 rail·영웅 탭): … 지각 변동 → 시간 건너뛰기 → 분출 을 … 지각 변동 → 시간 건너뛰기 → **불의 숨결 → 지각 변동** → 분출 로 바꿨습니다(11 → 13단계).
    - 근거: 상위 레이드 로그 6개 모두 시간 건너뛰기 뒤 돌아온 불의 숨결 → 지각 변동을 한 번 더 쓰고, 그 앞뒤에 예지 두 번·칠흑의 힘을 넣은 다음 분출을 시작했습니다(예지·칠흑의 힘 자리는 로그마다 달라 note에만 적음). 예: https://www.warcraftlogs.com/reports/8bg9JVBD1dXTCfQK#fight=4&source=16
    - APL: `fire_breath`·`upheaval` 이 `time_skip`·`eruption` 보다 위라, 건너뛰기로 재사용이 돌아오면 다시 먼저 씁니다(9월 19일 수정). KB 시간 건너뛰기 설명(재사용 회복 1000%)과도 맞습니다.
  - 시간 감시자 광역 진입(2부 광역 rail): 예지 → 영겁의 숨결 → 칠흑의 힘 을 예지 → **칠흑의 힘 → 영겁의 숨결** 로 바꿨습니다.
    - 근거: 상위 쐐기 시간 감시자 로그의 광역 풀 시작 6개 중 5개(서로 다른 5명)가 칠흑의 힘을 먼저 걸었습니다. APL도 `ebon_might` 가 `breath_of_eons` 보다 위입니다. 3부 쐐기 한 판 본문("칠흑의 힘과 예지로 준비하고 … 영겁의 숨결")과도 맞습니다.
  - 같은 순서로 맞춘 문장: 2부 오프닝 장의 한 줄 원리·본문·요점·확인 문제(엮인 실타래 빌드는 두 번째 강화도 건너뜀), 광역 장 본문과 rail note(쐐기 풀은 레이드 오프닝과 달리 칠흑의 힘 먼저), 쐐기 한 판 예시(칠흑의 힘을 착지 뒤가 아니라 모으는 동안 준비), 4부 시간 건너뛰기 심화 장 본문, 영웅 탭 오프닝 요약.
- 그대로 둔 것과 이유:
  - 레이드 오프닝의 영겁의 숨결 → 칠흑의 힘: 6개 중 4개가 이 순서라 유지했습니다(검사기도 이 순서를 지킵니다).
  - 끓어오르는 비늘: 로그 첫 22회에 없지만 풀 5초 전 사전 준비라 지우지 않았습니다.
  - 단일 반복 흐름·영웅 탭 단일·광역 우선순위: 분출·시간의 불꽃·예지가 버프 시간에 따라 섞여 꾸준한 역순이 없습니다(지각 변동 → 분출 82%는 가이드와 같음).
  - 부양(레이드 분당 3.2회)·진압(쐐기 분당 1회): 이동·차단 기술이라 딜사이클에 넣지 않았습니다.
  - 하늘빛 일격(시간 감시자 레이드 분당 0.03회): 이동 구간 대안으로 조건이 붙은 행이라 그대로 두었습니다(쐐기에서는 분당 0.6회).
- KB 추가 필요: 없음
- 보류·사용자 확인 필요:
  - 비늘사령관: 12.1.5 이후 레이드 로그가 0개이고, 쐐기 광역 풀 7개 중 5개가 한 사람(Bambuevo) 기록이라 보류했습니다. 그 기록들은 예지 → (살아있는 불꽃 여러 번) → 칠흑의 힘 → 불의 숨결 → 지각 변동 순서로, 가이드의 "칠흑의 힘 → 예지 → 영겁의 숨결" 진입과 다릅니다. 다른 사람의 로그가 더 모이면 다시 볼 만합니다.
