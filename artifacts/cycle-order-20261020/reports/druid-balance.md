# druid-balance
- 판정: 고침
- 고친 것:
  - 엘룬의 대행자 오프닝 (2부 오프닝 장 "오프닝 — 엘룬의 대행자" 줄, 영웅 탭 오프닝): … 엘룬의 분노 → 화신(A)/일월식 (달)(B) → 별빛쇄도 → … ⇒ … 엘룬의 분노 → 화신(A)/일월식 (달)(B) → 별빛섬광(구간 첫 즉시 시전) → 별빛쇄도 → ….
    - 근거: 레이드 오프닝 5개 모두 구간을 연 직후 별빛섬광을 먼저 썼습니다(화신 4개, 일월식 (달) 1개). 예시: https://www.warcraftlogs.com/reports/j369qgtaYZQBv2AK#fight=51&source=3 . KB 승천자의 일월식에 "일월식 활성화 시 다음 천벌 또는 별빛섬광이 즉시 시전"이 있습니다.
    - 함께 고친 곳: rail note, 영웅 탭 summary, 2부 오프닝 장 3번째 문단.
  - 숲의 수호자 오프닝 (2부 오프닝 장 "오프닝 — 숲의 수호자" 줄, 영웅 탭 오프닝): 천벌 → 달빛섬광 → 태양섬광 → 자연의 군대 → 화신(A)/일월식 (태양)(B) → 천벌 → 별빛쇄도 ⇒ 천벌 → 달빛섬광 → 태양섬광 → 일월식 (태양) → 천벌(천공의 힘 모으기) → 자연의 군대 → 화신 → 천벌(꿈의 폭발) → 별빛쇄도.
    - 근거: 레이드 오프닝 8개 모두 첫 도트 무렵에 일월식을 열었습니다(7개 태양·1개 달, 7개는 도트 직후·1개는 첫 천벌과 함께). 자연의 군대와 화신은 8개 모두 첫 22회 안에 없었고, 첫 쫄 무리 무렵(로그 기준 22~37초)에 함께 썼습니다. 예시: https://www.warcraftlogs.com/reports/t78VfT1FLayjG3Cm#fight=7&source=4
    - APL: `opener` 목록이 moonfire → sunfire → eclipse → wrath(천공의 힘 80 미만) → force_of_nature → celestial_alignment 순서입니다.
    - 함께 고친 곳: rail note(님리사 상위 로그의 쫄 맞춤 사용을 적음), 영웅 탭 summary와 단계 note, 2부 오프닝 장 요점, 2부 단일 장 문단, 4부 숲의 수호자 장 문단("전투 시작은 예외"). 반복 구간의 "자연의 군대 → 다음 글쿨 일월식·화신" 묶음은 로그(자연의 군대 → 화신, 또는 → 일월식 (태양))와 APL `mini`·`cooldowns` 목록에 맞아 유지했습니다.
  - 숲의 수호자 야생 버섯 (영웅 탭 단일 우선순위, 2부 단일 장 끼워 넣기 줄, 2부 움직임 장 문단): 천벌 → 야생 버섯(이동 글쿨) ⇒ 야생 버섯(일월식·화신 구간) → 천벌.
    - 근거: 야생 버섯을 쓴 레이드 로그 7개에서 87회 중 80회가 일월식이나 화신 구간 안이었습니다. APL `kotg_st`의 `wild_mushroom,if=buff.eclipse.up|cooldown.wild_mushroom.full_recharge_time<cooldown.ca_inc.remains`가 wrath보다 위에 있습니다.
- 그대로 둔 것과 이유:
  - 엘룬의 대행자 오프닝의 엘룬의 분노 → 화신 인접은 맞아서 그대로 두었습니다. 화신을 오프닝에 쓴 4개 모두 같았습니다. 화신과 일월식 중 하나만 쓰는 A/B 구조도 그대로입니다(5개 중 3개는 화신만, 1개는 일월식만, 1개는 둘 다).
  - 엘룬의 대행자 단일 반복 rail과 우선순위는 그대로 두었습니다. 도트 갱신 → 엘룬의 분노 → 일월식/화신 순서가 로그와 같습니다. 반복 구간에서 일월식 뒤 첫 소비는 별빛섬광·별빛쇄도·별똥별로 갈려 rail을 바꾸지 않았습니다.
  - 엘룬의 대행자 광역은 그대로 두었습니다. 쐐기 풀 시작 7개가 달빛섬광(여러 번) → 태양섬광 → 엘룬의 분노/일월식 → 별똥별·별빛섬광으로 가이드와 같습니다. 엘룬의 분노와 일월식의 앞뒤는 2:2로 갈렸습니다.
  - 숲의 수호자 광역은 쐐기 로그가 없어 바꾸지 않았습니다.
  - 레이드 단일에 없는 별똥별(엘룬의 대행자 8.6/분, 숲의 수호자 12.7/분)과 숲의 수호자 별빛섬광(4.3/분)은 님리사 쫄 구간에서 쓴 것이라 단일 우선순위에 넣지 않았습니다.
- KB 추가 필요:
  - 일월식 시전 ID 분리 기록: 로그에서 일월식 (달)은 1233272(Lunar Eclipse), 일월식 (태양)은 1233346(Solar Eclipse)로 찍힙니다. KB 노트 48518·48517에는 이 시전 ID가 없어 대조 자료가 "분당 0회"로 잘못 표시됩니다. Wowhead 규칙대로 시전 ID를 따로 적어 두면 좋겠습니다.
- 보류·사용자 확인 필요:
  - 숲의 수호자의 자연의 군대·화신 지연은 님리사(쫄이 나오는 네임드) 한 곳의 로그에서만 봤습니다. 쫄이 없는 네임드라면 APL처럼 천공의 힘을 모은 뒤 바로 쓰는 것으로 적었습니다. 다른 네임드 로그로 다시 확인할 필요가 있습니다.
  - 숲의 수호자 오프닝은 첫 일월식 뒤 화신을 씁니다. 원고의 "일반 일월식 도중 화신을 쓰면 남은 효과가 사라진다"와 부딪히지 않도록 화신 note에 "첫 일월식이 거의 끝났을 때 여는 편이 손실이 적다"를 적었습니다. APL은 이 손실을 감수하고 더 일찍 씁니다.
