# demonhunter-vengeance
- 판정: 고침 / 일부 보류 (알드라치 두 강화 순서, 알드라치 쐐기 탱사이클)

참고: 대조 자료(digest)의 균열·지옥칼·글레이브 투척 분당 수치와 "다음 스킬" 표는 시전 번호 2~3개를 한 스킬로 묶어서 2~3배로 잡혀 있었습니다(예: 균열 51/분 → 실제 약 17/분). 0.4초 안 중복을 지우고 다시 세서 판단했습니다.

## 고친 것
- 궤멸자 오프닝(영웅 탭·2부 오프닝 두 줄): 악마 쐐기 → 불지옥 일격 → 불꽃의 인장 → 불타는 낙인 → 제물의 오라 → 균열 → 영혼 폭탄 → 균열 → 탈태 → 균열 → 영혼 폭탄 → 영혼 베어내기 → 영혼 저미기 → 지옥 황폐 → (후) 악마 쐐기 → 불꽃의 인장 → 불타는 낙인 → 제물의 오라 → 균열 → 원한의 인장 → 지옥 황폐 → 영혼 폭탄 → 탈태 → 균열 → 영혼 폭탄 → 영혼 베어내기.
  근거: 불지옥 일격 레이드 8개 모두 0회. 영혼 저미기는 레이드·쐐기 견본에 없고 0회. 원한의 인장 8개 중 7개가 첫 6초 안. 지옥 황폐를 일찍 쓴 5개 중 4개가 첫 폭탄 전. 탈태를 일찍 연 6개 중 4개가 폭탄 직후 바로 탈태(사이 균열 없음). 첫 불꽃의 인장이 30초 무렵인 로그가 많아(8개 중 5개) 전투 전 사용으로 보고 그대로 둠. 예시 https://www.warcraftlogs.com/reports/1nWG9c7t4qHLDmYy#fight=65&source=19 . APL `anni_meta_entry`(spirit_bomb → sigil_of_spite → metamorphosis,if=cooldown.spirit_bomb.remains>gcd.max*3), `anni_pre_meta_spb`(fel_devastation), precombat `sigil_of_flame`. 2부 오프닝 본문·요점도 맞춤.
- 알드라치 오프닝: … 제물의 오라 → 균열 → 원한의 인장 → 글레이브 → 균열 → 영혼 베어내기 → 영혼 폭탄 → 영혼 저미기 → 지옥 황폐 → (후) … 제물의 오라 → 원한의 인장 → 파괴자의 글레이브 → 균열 → 영혼 베어내기 → 탈태 → 영혼 폭탄 → 지옥 황폐.
  근거: 5개 모두 원한의 인장 → 글레이브(원한의 인장 앞 균열은 1개뿐). 탈태 3개가 첫 6초 안. 영혼 저미기 0회. 예시 https://www.warcraftlogs.com/reports/aN8WAYMvCL6ZqJc9#fight=23&source=677 . APL `aldrachi_reaver metamorphosis`(쿨마다), `sigil_of_spite`.
- 쐐기 광역(2부 광역 줄·본문·확인 문제, 궤멸자 영웅 탭 광역, 3부 쐐기 예시, 4부 세트 장 문장, 상단 쐐기 운용 카드): 불꽃의 인장 → 제물의 오라 를 제물의 오라(닿자마자) → … → 불꽃의 인장(다 모인 뒤) → 원한의 인장 으로 바꿈. 지옥 황폐는 첫 폭탄·탈태 앞(13/21, 12/15), 탈태 → 영혼 폭탄(13/19).
  근거: 큰 풀 29개 중 오라가 인장보다 먼저 23/24, 인장 → 원한의 인장 12/14. 예시 https://www.warcraftlogs.com/reports/c1VgC2R3HAXBa6y9#fight=8&source=239 . APL `annihilator immolation_aura,if=talent.fallout&variable.aoe`가 spirit_bomb 위. 4세트 "인장 먼저" 줄은 원한의 인장 기준으로 고침(인장 바로 뒤 원한의 인장은 무작위보다 약 5배 잦고, 오라는 인장 뒤에 몰리지 않음).
- 알드라치 영웅 탭 단일·광역: 제물의 오라를 10번째에서 불꽃의 인장 바로 아래로 올림(APL aldrachi_reaver 두 번째 `immolation_aura`, 레이드 분당 4.5회). 탈태 설명에 쿨마다 사용을 넣음.
- 4부 알드라치 장의 "읽은 SimC 복수 파일이 4월 수정본" 문장을 고침. 10월 5일 APL의 번갈아 쓰기 조건(`prio_slashes`: 징표가 넉넉하면 균열 먼저, 곧 끝나면 영혼 베어내기 먼저, 광역은 균열 먼저)과 로그 결과(반반)를 적음. 영웅 탭 알드라치 설명 줄에도 한 문장 추가.
- 탱커 작업: 탭 이름 레이드 단일·쐐기 광역, 2부 타임라인 제목 레이드 네임드(단일)·쐐기 풀(광역). 영웅마다 tankRaid·tankMythic 새로 작성, 3부 쐐기·공격대 장에 kind tank 타임라인 추가.
  - 레이드: 도발 간격 대략 45~65초. 넘겨받은 뒤 첫 방어기는 궤멸자가 불타는 낙인(40번 중 24번), 알드라치는 탈태(33번 중 20번). 교대 앞뒤 영혼 폭탄(영혼 방벽)은 73번 중 33번. 예시 https://www.warcraftlogs.com/reports/WjpL94bA6yzMvq3f#fight=31&source=7
  - 쐐기(궤멸자): 글레이브 투척 → 악마 쐐기·제물의 오라 → 불타는 낙인 → 지옥 황폐 → 탈태 → 영혼 폭탄 → 불꽃의 인장 → 원한의 인장 → 분열.
  - 견본 차이: 레이드 견본에는 악마의 먹이가 없음. 쐐기 견본에만 악마의 먹이·고통 인도자·침묵의 인장·혼돈의 회오리·마법 삼키기·최후의 수단이 있음(코드 해독으로 확인).

## 그대로 둔 것과 이유
- 알드라치 두 강화 순서(글레이브 → 균열 → 영혼 베어내기): 로그 67:67로 갈림. 사람별로는 균열 먼저 2명(Mmp 26:1, Yisk 19:5), 영혼 베어내기 먼저 2명(Kynamit 7:21, Azíja 2:25), 번갈아 쓴 1명(Riemi). 검사기도 이 순서를 고정하고 있어 순서는 두고 설명만 고침.
- 2부 단일 반복 줄 본체: 균열 → 영혼 폭탄(폭탄 앞 51% 균열) → 영혼 베어내기(폭탄 뒤 47%) 흐름이 로그와 같음.
- 궤멸자 레이드 단일 우선순위의 순서: 어긋나는 쌍이 없음(4세트 줄 설명만 고침).
