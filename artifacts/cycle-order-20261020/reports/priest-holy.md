# priest-holy
- 판정: 고침 (예언자) · 집정관은 변경 없음(상위 로그 없음)

- 고친 것:
  1. 2부 "첫 연습" 반복 흐름
     - 전: 평온 → 회복의 기원 → 축도 → 순간 치유 → 신성한 폭발 → 신성한 불꽃(위: 빛의 권능: 응징) → 성스러운 일격
     - 후: 평온 → 축도 → 회복의 기원 → 순간 치유 → 신성한 폭발 → 빛의 권능: 응징 → 신성한 불꽃 → 성스러운 일격
     - 근거: 평온 바로 다음 버튼이 레이드 8개 모두 축도 1위(로그별 62~85%, 전체 70% · 회복의 기원 18%). 회복의 기원 충전이 남아 있었다고 추정되는 때에도 축도를 먼저 쓴 경우가 많음(평온 346회 중 101회). 쐐기도 축도 47% · 회복의 기원 28%(8개 중 6개가 축도 1위 또는 동률). 응징 567회 중 63%가 바로 신성한 불꽃, 신성한 불꽃 → 응징은 5%. 예: https://www.warcraftlogs.com/reports/1XKC836NyahVp4fL#fight=67&source=3
  2. 2부 "광역 치유 흐름" 반복 흐름 + 예언자 탭 "파티·공대 피해": 평온 → 회복의 기원 → 축도 ⇒ 평온 → 축도 → 회복의 기원 (같은 근거)
  3. 예언자 오프닝(쐐기 풀 진입) — 2부 타임라인 + 영웅 탭 "피해 준비"
     - 전: 회복의 기원 → 회복의 기원 → 영혼의 절규 → 평온 → 축도 → 순간 치유 → 수호 영혼 → 정화 → 신성한 불꽃
     - 후(타임라인): 회복의 기원 → 평온(위: 수호 영혼) → 축도 → 회복의 기원 → 순간 치유(위: 정화) → 빛의 권능: 응징(위: 영혼의 절규) → 신성한 불꽃
     - 후(영웅 탭): 회복의 기원 → 평온 → 축도 → 회복의 기원 → 순간 치유 → 영혼의 절규 → 수호 영혼 → 정화 → 빛의 권능: 응징 → 신성한 불꽃 (조건 행은 trigger로 표시)
     - 근거: 쐐기 4명 이상 풀 43개 중 첫 버튼(이동기 제외) 회복의 기원 26개, 두 번째 회복의 기원이 평온보다 먼저인 풀 17개, 영혼의 절규가 첫 8번 안에 나온 풀 1개, 수호 영혼 0개, 정화 2개, 응징이 첫 14번 안에 나온 풀 28개. 예: https://www.warcraftlogs.com/reports/8y14PQpvDYj6NWgz#fight=40&source=1040
  4. 같은 순서를 말하는 문장: 1부 평온 장(흐름 문장), 축도 장(공개 가이드 우선순위와 상위 로그 순서가 다르다는 설명 추가), 4장 한 줄 원리·공격 순서 문장, 2부 세 장의 한 줄 원리·본문·확인 문제·rail note, 3부 쐐기 장 본문·요점, 책 머리말, 실전 꿀팁 13번, 플레이 요약 2개.

- 그대로 둔 것과 이유:
  - 집정관 전부: 12.1.5 이후 상위 로그 0개.
  - 한 명 급락 rail·탭: 응급 대응 순서라 로그로 판단 불가(예언자 탭은 이미 평온 → 축도 → 회복의 기원 순서였음).
  - 마력 주입: 레이드 오프닝 8개 중 7개가 풀 직후 사용하지만 이 가이드에는 예언자 레이드 오프닝 rail이 없고, 쐐기는 2분 쿨기라 풀 43개 중 18개에서만 첫 10번 안 → 쐐기 오프닝에 고정 단계로 넣지 않음.
  - 공개 가이드 우선순위를 적은 예전 evidence 기록(10월 12일·19일)은 기록이라 그대로 두고, 새 evidence에 로그 근거를 남김.
