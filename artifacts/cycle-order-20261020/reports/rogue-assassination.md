# rogue-assassination
- 판정: 고침
- 고친 것:
  - 운명결속 오프닝 (2부 오프닝 장 "오프닝 — 운명결속" 줄, 영웅 탭 오프닝, 상단 opener): 목조르기 → 절단 → 파열 → 목조르기(강화 적용 시간 안) → 절단 → 독살 → 죽음표식 → 왕의 파멸 → 독살 ⇒ 목조르기 → 절단 → 파열 → 절단 → 독살 → 죽음표식 → 왕의 파멸 → 독살 → 소멸 → 목조르기(강화 출혈).
    - 근거: 레이드 오프닝 7개 중 5개가 소멸 → 강화 목조르기를 썼습니다. 그중 4개는 죽음표식 → 왕의 파멸 → 독살 뒤였고 1개는 죽음표식 앞이었습니다. 소멸 없이 파열 뒤 목조르기를 다시 쓴 로그는 2개입니다. 독살 → 죽음표식은 7개 중 6개였습니다. 예시: https://www.warcraftlogs.com/reports/FZdJWm3GTL1RBAxj#fight=26&source=56
    - APL: `vanish,if=variable.single_target&talent.improved_garrote&dot.garrote.pmultiplier<=1&(dot.deathmark.ticking|…)`, `deathmark,if=…buff.envenom.remains>2…`
    - 소수 방식(소멸 없이 파열 뒤 바로 다시 바르기, 2개 로그)은 절단 위 가지 "소멸 없이 · 강화 시간 안"과 note로 남겼습니다.
    - 상단 opener: 검사기 규칙("Default Assassination opener must match Fatebound") 때문에 영웅 탭과 같게 맞췄습니다.
    - 같은 장의 한 줄 원리·2·3번째 문단·확인 문제 1번을 운명결속(죽음표식 뒤 소멸)과 죽음추적자(파열 뒤 강화 시간 안) 기준으로 나눠 고쳤습니다.
  - 단일 반복 rail (두 영웅 공통): 죽음표식 가지를 파열 뒤 절단 위에서 첫 독살 뒤 절단 위로, 왕의 파멸 가지를 마지막 독살 위로 옮겼습니다. 맨 앞 목조르기 위에는 소멸(죽음표식에 맞춰)을 더했습니다.
    - 근거: 레이드 다음 스킬 표에서 죽음표식 → 왕의 파멸 79%, 왕의 파멸 → 독살 90%, 소멸 → 목조르기 93%였습니다. 운명결속 레이드 소멸 19회 중 18회가 죽음표식 앞뒤 6초 안이었고, 18회가 곧바로 목조르기로 이어졌습니다(뒤 11회, 앞 7회). APL deathmark 조건은 독살 효과가 켜져 있을 때입니다.
  - 운명결속 단일 우선순위 (영웅 탭): 왕의 파멸 다음에 "소멸 · 죽음표식에 맞춰" 행을 넣고, 목조르기 행 note에 "소멸 직후에는 강화 목조르기를 다시 바름"을 적었습니다. 2부 단일 장 우선순위 문단도 맞췄습니다.
  - 죽음추적자 광역 (영웅 탭 원본 목조르기 행 note, 2부 광역 장 끼워 넣기 줄): "은신 목조르기로 풀을 열었다면 강화 적용 시간 안(보통 첫 파열 무렵)에 다른 오래 살 적에게 목조르기를 한 번 더"를 적었습니다.
    - 근거: 죽음추적자 쐐기 광역 풀 시작 33개 중 22개가 첫 10회 안에 목조르기를 두 번 썼습니다(16개는 파열 뒤, 6개는 파열 앞). 대표 순서는 목조르기 → 칼날 부채 → 파열 → 목조르기 → 혈폭풍입니다. 예시: https://www.warcraftlogs.com/reports/wbR9tDc7v8y21gp6#fight=5&source=5
- 그대로 둔 것과 이유:
  - 죽음추적자 레이드 오프닝은 바꾸지 않았습니다. 로그가 1개뿐이고, 그 로그도 파열 뒤 바로 목조르기를 다시 써서 가이드와 같습니다.
  - 운명결속 광역은 바꾸지 않았습니다. 쐐기 로그가 2개(풀 9개)라 적고, 목조르기 → 파열 → 칼날 부채 → 혈폭풍 → 죽음표식 → 왕의 파멸로 가이드와 어긋나지 않습니다.
  - 광역 반복 rail의 혈폭풍 → 칼날 부채 → 독살 칸은 바꾸지 않았습니다. 죽음추적자 로그는 풀 초반에 혈폭풍 → 독살을 반복하지만, 가이드 조건("보조 대상 출혈 부족 시")과 APL crimson_tempest 조건이 같아서입니다.
  - 매복(8676) 행은 그대로 두었습니다. 상위 로그에서 거의 누르지 않고(레이드 1회·쐐기 1회) 다른 시전 번호도 없습니다. 사각 지대를 고르지 않은 빌드로 보입니다. 원고에서는 "사각 지대 조건부"라 지우지 않았습니다.
  - 레이드 단일에 없는 칼날 부채·혈폭풍(님리사 쫄)과 그림자 밟기(이동)는 넣지 않았습니다.
