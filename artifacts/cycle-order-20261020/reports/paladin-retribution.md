## 그대로 둔 것과 이유
- 태양의 사자 오프닝(심판의 칼날 → 응징의 격노 → 사형 선고 → 파멸의 재 → 최후의 선고 → 최후의 선고 → 천상의 종): 레이드 8개 중 4개가 그대로(1개는 천상의 종 전에 최후의 선고 한 번 더), 나머지 4개도 한두 칸 차이(사형 선고가 최후의 선고 뒤 1, 응징의 격노가 파멸의 재 뒤 1, 천상의 종 전에 천상의 폭풍 한 번 2). 차이가 한 방향으로 모이지 않아 60% 넘게 다른 순서로 보지 않음.
  - 예: https://www.warcraftlogs.com/reports/H3ZkGC1qhfTxrDa4#fight=11&source=16
- 기사단 오프닝(… → 파멸의 재 → 빛의 망치 → 천상의 종 → 최후의 선고): 레이드 5개 모두 같음(최고천의 망치·신성한 성전·천상의 망치는 자동 발동).
- 단일 반복: "파멸의 재 → 최후의 선고 (×1~2) → 천상의 종 → 최후의 선고"가 반복 구간에서도 그대로 나옴. 소비기 사이 생성기는 0~1개가 대부분(1175번 중 바로 이어 소비 432·생성기 하나 546)이라 우선순위 표의 "3개 이상이면 소비"와 맞음. 영웅 탭 순서는 APL generators/finishers 순서(5개면 소비 → 파멸의 재 → 천상의 종 → 2중첩 칼날 → 2충전 망치 → 소비 → 망치 → 칼날 → 심판)와 같음.
- 광역: 쐐기 천상의 폭풍 분당 21.6회(레이드의 1.9배), 최후의 선고 6.8회(0.4배). 쐐기 풀 시작은 심판 → 심판의 칼날 → 천상의 폭풍이 많고, 날개가 돌아온 풀은 응징의 격노 → 사형 선고 → 파멸의 재 → 천상의 종 → 최후의 선고(최고천의 유산) 순서라 광역 rail·영웅 탭과 맞음.
- 자동 대조에서 "빠짐"으로 나온 성전의 강타(분당 40회)는 KB상 성전사의 일격을 바꾼 자동 공격, 천상의 군마는 이동기, 기사단의 최고천의 망치·천상의 망치·신성한 성전은 자동 발동이라 딜사이클에 넣지 않음.
- 기본 영웅 탭·견본은 범위 밖(로그 다수가 태양의 사자인 것은 이미 반영돼 있음).
