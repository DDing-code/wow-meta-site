# warrior-protection

- 판정: 고침 (일부 보류)
- 근거 자료: 12.1.5 이후 WCL 상위 레이드 12개(산왕 7·거신 5, 님리사 신화)·쐐기 8개(모두 산왕), 원본 이벤트(`events/warrior-protection-*`)로 도발 앞뒤 시각을 직접 집계, 심크 APL `apl/warrior_protection.simc`(2026-10-04 수정 → 12.1.5 전이라 로그를 앞에 둠)
- 시전 번호 확인: 로그의 Thunder Blast(435222)가 우레 작렬(KB 435607)이고 분당 8회 넘게 씁니다. 대조 자료의 "우레 작렬 0/분"은 번호가 달라서 생긴 착시입니다. Charge(126664)와 Shield Charge(385954)는 같은 돌진에서 한 번 더 찍힌 기록이라, 돌진은 실제로 분당 1회 안팎입니다.

## 고친 것

1. **산왕 오프닝** (2부 오프닝 rail과 영웅 탭 opener.steps)
   - 전: 돌진 → 방패 올리기 → 천둥벼락 → 방패 밀쳐내기 → 투신 → 우레 작렬 → 고통 감내 → 사기의 외침
   - 후: 돌진(위 가지: 도발) → 투신 → 우레 작렬 → 방패 올리기 → 사기의 외침 → 방패 밀쳐내기 → 방패 돌격 → 고통 감내 → 천둥벼락
   - 근거: 산왕 레이드 7개 모두 풀 4초 안에 투신을 썼습니다. 6/7은 투신 직후 두 번 안에 우레 작렬, 6/7은 방패 올리기보다 투신이 먼저, 7/7은 사기의 외침이 고통 감내보다 먼저였습니다. 6/7은 첫 13번 안에 방패 돌격을 썼습니다. 예: https://www.warcraftlogs.com/reports/aKARQ1MPrx2bkqNC#fight=63&source=3
   - APL: `avatar,if=buff.thunder_blast.down|buff.thunder_blast.stack<=2`(사실상 조건 없음), `thunder_blast,if=...stack=2&talent.snap_induction` → `demoralizing_shout,if=talent.booming_voice`, `shield_charge`
2. **거신 오프닝** (같은 두 곳)
   - 전: 돌진 → 방패 올리기 → 방패 밀쳐내기 → 천둥벼락 → 복수 → 고통 감내 → 쇄파
   - 후: 돌진(위 가지: 도발) → 방패 밀쳐내기 → 투신 → 천둥벼락 → 사기의 외침 → 방패 올리기(위 가지: 방패 돌격) → 복수 → 쇄파 → 고통 감내
   - 근거: 거신 레이드 5개 모두 풀 5초 안에 투신과 사기의 외침을 썼고, 쇄파를 쓴 4개는 모두 그 뒤에 썼습니다. 쇄파 전에 고통 감내를 쓴 기록은 0개입니다. 방패 밀쳐내기가 방패 올리기보다 먼저인 기록 3/5, 사기의 외침이 방패 올리기보다 먼저인 기록 4/5입니다. 예: https://www.warcraftlogs.com/reports/m9Dqr2KQnwFfAxHk#fight=7&source=14
3. **2부 단일 반복 rail** (산왕·거신 공통)
   - 전: 방패 올리기 → 방패 밀쳐내기 → 고통 감내 → 천둥벼락 → 방패 밀쳐내기 → 복수 → 마무리 일격
   - 후: 방패 올리기 → 방패 밀쳐내기(위: 방패 돌격) → 천둥벼락(위: 투신) → 복수(위: 사기의 외침) → 고통 감내(위: 주문 반사) → 방패 밀쳐내기 → 마무리 일격
   - 근거: 산왕 레이드에서 "바로 다음에 누른 스킬" 1위가 차례대로 방패 올리기→방패 밀쳐내기 32%, 천둥벼락→복수 31%, 복수→고통 감내 22%, 고통 감내→방패 밀쳐내기 42%입니다. 반대로 방패 밀쳐내기→고통 감내는 상위 3위 안에 없습니다. APL에서도 `ignore_pain`이 `rage.deficit<=15&cooldown.shield_slam.ready`처럼 방패 밀쳐내기 직전 분노 비우기 조건입니다.
4. **영웅 탭 레이드 단일·쐐기 광역 우선순위** (산왕·거신 4곳): 투신, 사기의 외침, 방패 돌격을 추가했습니다.
   - 근거: 레이드에서 분당 투신 1.0~1.1회, 사기의 외침 1.4~1.8회, 방패 돌격 1.1~1.4회를 썼고, 쐐기 광역에서는 투신 1.1회, 사기의 외침 2.2회, 방패 돌격 1.3회를 썼습니다.
   - APL: 맨 위 목록의 `avatar`, `demoralizing_shout,if=talent.booming_voice`, `shield_charge`. 레이드·쐐기 견본 모두 우렁찬 음성과 방패 돌격을 고릅니다(견본 코드를 풀어 확인).
   - 고통 감내 설명에 "분노가 차면 방패 밀쳐내기 직전"을 넣었습니다. 쐐기 광역 천둥벼락 설명에는 "풀에 들어가는 순간엔 이것부터"를 넣었습니다.
5. **2부 쐐기 광역 rail과 3부 쐐기 장**
   - 전: 방패 올리기 → 천둥벼락
   - 후: 천둥벼락 → 방패 올리기
   - 근거: 산왕 쐐기 큰 풀(대상 4명 이상) 6개 모두 천둥벼락이 먼저였습니다. 큰 풀 3개 모두 시작 30초 안팎에 방패의 벽·투신·사기의 외침을 썼습니다. 예: https://www.warcraftlogs.com/reports/hWRn3c48DtHKz2qP#fight=3&source=75
6. **탱커 추가 작업**
   - 탭 이름: singleTarget '레이드 단일', aoe '쐐기 광역'으로 바꾸고 제목에도 레이드·쐐기를 넣었습니다.
   - 2부 타임라인 제목: '레이드 네임드(단일) …', '쐐기 풀(광역) …'
   - tankRaid·tankMythic을 영웅 특성마다 다르게 새로 넣었습니다.
     - 산왕 레이드: 고통 감내 → 방패 올리기 → 도발 → 사기의 외침 → 방패 돌격 → 주문 반사 → 방패의 벽 → 방패 밀쳐내기
     - 산왕 쐐기: 돌진 → 천둥벼락 → 방패 올리기 → 도발 → 방패의 벽 → 투신 → 사기의 외침 → 주문 반사 → 고통 감내 → 예견된 승리
     - 거신 레이드: 고통 감내 → 방패 올리기 → 도발 → 주문 반사 → 방패의 벽 → 쇄파 → 예견된 승리
     - 거신 쐐기: 돌진 → 천둥벼락 → 방패 밀쳐내기 → 방패 올리기 → 훼방의 외침 → 방패의 벽 → 쇄파 → 예견된 승리
   - 3부 '쐐기 한 판' 장과 '공격대 네임드' 장에 kind:'tank' 타임라인을 넣었습니다.
   - 레이드 근거(도발 70번 앞뒤 집계)
     - 도발 8초 전 안 고통 감내: 산왕 30/37, 거신 20/33
     - 도발 앞뒤 방패 올리기: 산왕 34/37, 거신 25/33
     - 도발 앞뒤 사기의 외침: 산왕 17/37
     - 도발 앞뒤 20초 안 방패 돌격: 산왕 23/37
     - 넘겨받고 5~22초 사이 주문 반사나 방패의 벽: 53/70
     - 도발 간격: 약 45초와 65초가 번갈아 나옴
   - 쐐기 근거: 큰 풀 첫 90초의 방패의 벽·투신·사기의 외침·도발 시각, 그리고 "도발 → 영웅의 도약 → 도발" 묶음
   - 견본 차이는 요약에 적었습니다. 레이드 견본만 재집결의 함성·가로막기·폭풍 방패·일격 유도를 고르고, 쐐기 견본만 훼방의 외침·폭풍망치·대지 뒤흔들기·역전의 용사·백절불굴·번뜩이는 하늘을 고릅니다.
7. **바뀐 순서에 맞춘 문장**
   - 2부 오프닝 장: 한 줄 원리, 본문 3단락, 요점, 실수("방패 올리기보다 투신을 먼저 눌러…" → "투신을 켜고 나서 방패 올리기를 잊어…")
   - 2부 단일 장: 본문 1·3단락
   - 2부 광역 장: 한 줄 원리, 요점 1줄 추가
   - 3부 쐐기 장: 본문, 요점, 예시
   - 실전 꿀팁: "방패 올리기가 비어 있는 상태에서 투신만 먼저 누르지 않습니다" 1개를 고쳤습니다.
   - 산왕 첫 흐름 메모(bullets[0])를 고쳤습니다.

## 그대로 둔 것과 이유
- 마무리 일격 위치(단일 맨 끝): APL `thane_st`·`colossus_st`는 execute를 무료 복수·천둥벼락 위에 둡니다. 그러나 로그로는 급살과 처형 구간을 가릴 수 없어 판단하지 못했습니다. 보류합니다.
- 거신 단일에서 방패 밀쳐내기 → 쇄파 순서: APL `demolish,if=buff.colossal_might.stack>=5`와 가이드 설명(중첩 쌓고 쇄파)이 맞습니다.
- 2부 단일·광역 rail의 영웅 특성 끼워 넣기(우레 작렬·쇄파 등): 로그와 어긋나지 않습니다.
- 돌진: 중복 집계를 빼면 분당 1회 안팎인 이동기라 우선순위에 넣지 않았습니다.
- 거신 쐐기: 12.1.5 이후 상위 쐐기에 거신 로그가 없습니다. 쐐기 광역 우선순위는 APL로 투신·사기의 외침·방패 돌격만 더했습니다. tankMythic은 산왕 쐐기 흐름에 쇄파를 얹은 예시라고 요약에 밝혔습니다.

## KB 추가 필요
- 없음(원고는 KB에 있는 번호만 씁니다).
- 선택 사항: 우레 작렬의 실제 시전 번호 435222(Thunder Blast)는 KB에 없습니다. 특성 번호 435607만 있습니다. "스킬 ID와 실제 시전 ID가 다르면 분리해 기록" 규칙에 맞추려면 우레 작렬 노트에 435222를 시전 ID로 적어 두면 좋습니다. 원고 표시에는 지장이 없습니다.

## 보류·사용자 확인 필요
- 사기의 외침을 상위 레이드에서 6.6분에 14번(약 30초 간격)까지 썼습니다. KB의 쿨다운은 45초입니다. 쿨다운을 줄이는 특성이나 효과가 있는지 KB 확인이 필요합니다. 원고에는 초 단위 대신 "쿨이 돌 때마다"라고만 적었습니다.
- 투신과 방패 올리기를 글쿨 없이 쓰는지는 KB에 없어 원고에 적지 않았습니다. "풀 직후 투신을 켜도 첫 근접 공격 전엔 방패 올리기"로만 썼습니다.
- 레이드 근거는 모두 님리사 신화 한 네임드입니다. 그래서 탱사이클의 초 단위(교대 45·65초, 넘겨받고 10~20초)는 "님리사 신화 기준"과 "내 공략표에 맞춘다"를 함께 적었습니다.
- 마무리 일격 우선순위(위 보류)
