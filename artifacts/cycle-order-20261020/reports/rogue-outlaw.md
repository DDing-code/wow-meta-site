# rogue-outlaw
- 판정: 고침 (운명결속은 일부 보류)
- 고친 것:
  - 오프닝 (2부 오프닝 장 두 줄, 기만자·운명결속 영웅 탭 오프닝): 아드레날린 촉진 → 뼈주사위 → 난도질 → 도박의 연속 → 폭풍의 칼날 → 질풍 칼날 → 사악한 일격 → 미간 적중 → 권총 사격(부족한 점수만) → 광기의 학살자 ⇒ 아드레날린 촉진 → 난도질 → 뼈주사위 → 도박의 연속 → 폭풍의 칼날 → 질풍 칼날 → 사악한 일격 → 미간 적중 → 광기의 학살자 → 마음가짐 → 아드레날린 촉진(첫 촉진이 끝나면) → 광기의 학살자.
    - 근거(기만자 레이드 오프닝 6개)
      - 6개 중 5개가 미간 적중 → 광기의 학살자 순서였습니다. 그 사이 생성기는 3개가 없었고 2개는 사악한 일격이었습니다. 권총 사격은 0개였습니다. 첫 권총 사격은 5개가 광기의 학살자 뒤, 1개는 미간 적중 앞이었습니다.
      - 6개 모두 전투 10초 안에 마음가짐을 썼고, 첫 촉진이 끝날 무렵(10초 안팎) 아드레날린 촉진 → 광기의 학살자를 다시 썼습니다.
      - 난도질을 쓴 3개는 모두 뼈주사위보다 먼저였습니다. 나머지 3개는 오프닝에 난도질이 없었습니다.
      - 예시: https://www.warcraftlogs.com/reports/vaVzfBrCmj9yHGYn#fight=5&source=31
    - APL: `precombat` adrenaline_rush → slice_and_dice → roll_the_bones, `cds` preparation(=마음가짐),if=cooldown.adrenaline_rush.remains>30&!cooldown.between_the_eyes.ready&!cooldown.killing_spree.ready, `adrenaline_rush,if=!buff.adrenaline_rush.up`, `finish` between_the_eyes → killing_spree.
    - 함께 고친 곳: 같은 장 한 줄 원리·1~3번째 문단, 두 rail note, 두 영웅 탭 summary. "부족한 점수만 채운다"는 광기의 학살자 단계 note로 옮겼습니다.
  - 단일 반복 rail: 아드레날린 촉진 가지를 1번 사악한 일격 위에서 미간 적중 다음 사악한 일격 위로 옮기고, 뼈주사위 가지와 자리를 바꿨습니다. 이제 아드레날린 촉진 바로 뒤에 광기의 학살자가 옵니다. note에 "촉진 연마로 점수가 차면 생성기를 건너뛰고 바로 광기의 학살자"를 더했습니다.
    - 근거: 레이드 다음 스킬 표에서 아드레날린 촉진 → 광기의 학살자 54%, 미간 적중 23%였습니다. 쐐기에서도 아드레날린 촉진 바로 뒤나 미간 적중 하나 뒤에 광기의 학살자를 썼습니다.
  - 광역 반복 rail: 광기의 학살자 가지를 미간 적중 위에서 속결 위로 옮겼습니다("속결보다 먼저").
    - 근거: 쐐기 로그에서 아드레날린 촉진 → 미간 적중 → 광기의 학살자 순서가 다수였고, APL finish 목록도 미간 적중이 광기의 학살자보다 위입니다.
    - 함께 고친 곳: 두 영웅 탭의 단일·광역 광기의 학살자 행 note와 3장 본문을 "미간 적중이 함께 준비됐으면 미간 적중으로 피해 버프를 먼저 깔고 바로 광기의 학살자"로 맞췄습니다.
- 그대로 둔 것과 이유:
  - 단일·광역 우선순위의 행 순서는 바꾸지 않았습니다. 광기의 학살자가 미간 적중보다 위에 있는 문제는 조건 note로 해결했고, 무료 속결·질풍 칼날 순서는 로그로 가릴 수 없었습니다.
  - 폭풍의 칼날·질풍 칼날 오프닝 단계는 조건부라 그대로 두었습니다. 레이드 로그에는 질풍 칼날이 없고, 쐐기에서만 분당 3.2회입니다.
  - 운명결속 고유 조건(5점 속결, 2단계 연장)은 그대로 두었습니다.
  - 화면에 안 나오는 상단 opener는 건드리지 않았습니다(무법은 검사기 규칙이 없음).
