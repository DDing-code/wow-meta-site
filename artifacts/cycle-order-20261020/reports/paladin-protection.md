# paladin-protection

- 판정: 고침 (일부 보류)
- 근거 자료
  - 12.1.5 이후 WCL 상위 레이드 8개(빛의 대장장이 7·기사단 1, 님리사 신화)와 쐐기 8개(모두 빛의 대장장이)를 봤습니다.
  - 원본 이벤트(`events/paladin-protection-*`)로 집행의 손길 앞뒤 시각과 쐐기 풀 21개의 시작 순서를 직접 집계했습니다.
  - 심크 APL `apl/paladin_protection.simc`도 봤습니다. 2026-09-25 수정이라 12.1.5 전 판입니다. 그래서 로그를 먼저 두고 APL은 조건 설명에 썼습니다.

## 고친 것

1. **빛의 대장장이 오프닝** (2부 오프닝 rail과 영웅 탭 opener.steps)
   - 전: … 파수꾼 → 응징의 방패 → 천벌의 망치 → 정의의 방패 → 천상의 종 → 정의의 방패 → …
   - 후: … 파수꾼 → 천상의 종 → 정의의 방패 → 응징의 방패 → 천벌의 망치 → 정의의 방패 → …
   - 전투 전 단계(신성한 보루·축복받은 망치·신성화)와 집행의 손길은 그대로 뒀습니다.
   - 근거(로그): 레이드 7개 중 천상의 종이 첫 정의의 방패보다 먼저인 것이 5/7, 응징의 방패보다 먼저 5/7, 천벌의 망치보다 먼저 6/7입니다. 파수꾼을 쓴 6개 중 5개는 세 번 안에 천상의 종을 썼고, 천상의 종 바로 다음은 정의의 방패가 85%였습니다. 예: https://www.warcraftlogs.com/reports/2MKmqkYwDXH9nTVh#fight=1&source=8
   - 근거(APL): `avenging_wrath` → `divine_toll,if=buff.avenging_wrath.up|!apex.3`
2. **기사단 오프닝** (같은 두 곳)
   - 전: … 파수꾼 → 응징의 방패 → 천벌의 망치 → 정의의 방패 → 천상의 종 → 빛의 망치 → 천벌의 망치 → 정의의 방패
   - 후: … 파수꾼 → 천상의 종 → 빛의 망치 → 정의의 방패 → 응징의 방패 → 천벌의 망치 → 정의의 방패
   - 근거: 기사단 레이드 로그는 1개뿐입니다(https://www.warcraftlogs.com/reports/1xVCPG4vqtwDm72R#fight=64&source=2565). 이 로그의 순서는 심판 → 파수꾼 → 천상의 종 → 빛의 망치였습니다. APL도 `divine_toll` → `hammer_of_light,if=variable.wants_to_hammer` 순서이고, 빛의 대장장이 로그 6/7도 파수꾼 → 천상의 종 흐름이라 이 셋을 함께 근거로 삼았습니다.
   - 로그가 1개라 응징의 방패·천벌의 망치 순서는 그대로 뒀습니다. note에는 "기록마다 다를 수 있다"고 적었습니다.
3. **2부 쐐기 광역 rail** (공통)
   - 전: 신성화 → 천상의 종(위: 파수꾼) → 응징의 방패 → 천벌의 망치 → 심판 → 축복받은 망치 → 영광의 서약
   - 후: 축복받은 망치(위: 천상의 군마) → 심판(위: 집행의 손길) → 응징의 방패(위: 비난) → 신성화(위: 정의의 방패) → 천상의 종(위: 파수꾼) → 천벌의 망치 → 축복받은 망치 → 영광의 서약
   - rail 이름은 "풀 시작부터 반복"으로 바꾸고 안내 문장도 맞췄습니다.
   - 근거: 쐐기 풀 시작 7개 중 6개가 처음 두 번 안에 축복받은 망치를 썼습니다. 풀 21개 중 18개는 심판이 응징의 방패보다 먼저였고, 19개 중 16개는 심판이 신성화보다 먼저였습니다. 파수꾼·천상의 종을 쓴 풀 7개는 모두 응징의 방패가 먼저였습니다. 예: https://www.warcraftlogs.com/reports/ayHG3VYT48CZkMbz#fight=34&source=543
   - 응징의 방패와 신성화 순서는 거의 반반이라 note에 "풀마다 다름"이라고 적었습니다.
4. **영웅 탭**
   - 탭 이름: '레이드 단일'·'쐐기 광역'으로 바꾸고 제목도 맞췄습니다.
   - 쐐기 광역 요약(두 영웅 특성 모두)에 풀 시작 흐름을 넣었습니다. 다 모이기 전에는 축복받은 망치·심판·응징의 방패를 쓰고, 다 모인 뒤 파수꾼·천상의 종을 씁니다.
   - 빛의 대장장이 쐐기 광역의 신성화·파수꾼·천상의 종 설명에 "다 모인 뒤" 조건을 넣었습니다. 우선순위 순서 자체는 그대로 뒀습니다(아래 보류 참고).
5. **탱커 추가 작업**
   - 2부 타임라인 제목: '레이드 네임드(단일) …', '쐐기 풀(광역) …'
   - tankRaid·tankMythic을 영웅 특성마다 다르게 새로 넣었습니다.
     - 빛의 대장장이 레이드: 정의의 방패 → 신성한 보루 → 집행의 손길 → 축복받은 망치 → 파수꾼 → 헌신적인 수호자 → 고대 왕의 수호자 → 영광의 서약
     - 빛의 대장장이 쐐기: 축복받은 망치 → 신성한 보루 → 응징의 방패 → 신성화 → 파수꾼 → 헌신적인 수호자 → 고대 왕의 수호자 → 천상의 보호막 → 영광의 서약
     - 기사단 레이드: 정의의 방패 → 집행의 손길 → 파수꾼 → 천상의 종 → 빛의 망치 → 헌신적인 수호자 → 영광의 서약
     - 기사단 쐐기: 축복받은 망치 → 응징의 방패 → 신성화 → 파수꾼 → 천상의 종 → 빛의 망치 → 헌신적인 수호자 → 영광의 서약
   - 3부 '쐐기 한 판' 장과 '공격대 네임드' 장에 kind:'tank' 타임라인을 넣었습니다.
   - 레이드 근거
     - 집행의 손길 직전 3초 안 정의의 방패: 33/41
     - 집행의 손길 직후 3초 안 축복받은 망치: 32/41
     - 넘겨받고 8~22초 사이 헌신적인 수호자·고대 왕의 수호자·주문 수호의 축복·천상의 보호막 중 하나: 33/48
     - 집행의 손길 간격: 약 45초와 65초가 번갈아 나옴
     - 파수꾼: 약 60초마다(정의로운 수호자)
   - 쐐기 근거: 큰 풀 4개 모두 파수꾼 → 헌신적인 수호자 순서였고, 그 뒤 고대 왕의 수호자 3/4, 천상의 보호막 3/4입니다.
   - 견본 차이는 요약에 적었습니다. 레이드 견본만 재결·성역·마력 깃든 방패를 고르고, 쐐기 견본만 마지막 저항·독소 정화를 고릅니다(견본 코드를 풀어 확인).
6. **바뀐 순서에 맞춘 문장**
   - 2부 오프닝 장
     - 본문 3단락을 바꿨습니다.
     - 요점: "천상의 종 직전: 정의의 방패로 자원을 비워…" → "자원이 많으면 먼저 비우고, 적으면 파수꾼 바로 뒤"
     - 실수: "방어 없이 날개와 천상의 종부터…" → "만든 신성한 힘을 들고만 있다가…"
   - 2부 광역 장: 요점 1줄을 추가했습니다.
   - 2부 이동 장 예시: "다음 풀에 닿으면 멈출 자리에 신성화부터" → "심판으로 대상을 잡고, 모이면 신성화"
   - 3부 쐐기 장: 요점 첫 줄과 예시를 바꿨습니다.

## 그대로 둔 것과 이유
- 레이드 단일 반복 rail과 두 영웅 특성의 레이드 단일 우선순위: 로그 반복 구간의 심판 ↔ 축복받은 망치 흐름, 응징의 방패 → 정의의 방패 54%와 맞습니다. APL 순서와도 크게 어긋나지 않습니다.
- 축복받은 망치[충전 넘치기 전] → 일반 응징의 방패 순서: APL은 `avengers_shield`를 `blessed_hammer` 위에 둡니다. 로그의 "3회 안 이웃 비율"(응징→축망 57%, 축망→응징 23%)은 두 스킬의 사용 빈도 차이(분당 6회 대 15회) 때문에 생긴 값일 수 있어 판단하지 못했습니다. 가이드의 "충전 넘치기 전" 조건도 말이 되므로 보류합니다.
- 신성한 무기 위치: APL은 날개 직전(`holy_armaments,if=cooldown.avenging_wrath.remains<=gcd|charges=2`)에 둡니다. 로그에서 파수꾼 앞뒤 1초 안에 무장을 쓴 것은 3/7뿐이라 바꾸지 않았습니다.
- 오프닝 전투 전 준비(축복받은 망치·신성화·신성한 보루): 로그 창 밖이라 "없음"을 근거로 지우지 않았습니다. APL precombat에도 consecration·holy_armaments가 있습니다.
- 기사단 오프닝의 심판 선행(기사단 로그 1개만 심판 → 파수꾼, 빛의 대장장이는 2/7): 과반이 아니라 넣지 않았습니다.
- 마지막 저항(204077)이 쐐기 광역에서 분당 2.1회 찍힙니다. 이는 천상의 보호막 중 자동 도발 효과라 우선순위에 넣지 않았고, 탱사이클 설명에만 적었습니다.

## 보류·사용자 확인 필요
- 쐐기 광역 탭의 우선순위표는 조건부 순위라 그대로 뒀습니다. 파수꾼·천상의 종이 응징의 방패·심판보다 위에 있습니다. 반면 2부 타임라인은 풀 시작 시간 순서(심판·응징의 방패 → 파수꾼·천상의 종)로 고쳤습니다. 둘이 어긋나 보이지 않도록 "다 모인 뒤" 조건을 설명에 넣었습니다. 우선순위표 자체도 풀 시작 순서로 바꿀지는 사용자가 판단해 주세요.
- 기사단: 레이드 로그 1개, 쐐기 로그 0개입니다. 탱사이클 두 개는 빛의 대장장이 흐름에 기사단 스킬(천상의 종·빛의 망치·신성한 성전)을 얹은 예시라고 요약에 밝혔습니다.
- 범위 밖 발견: 원고 안에서 서로 어긋나는 문장이 있습니다. 4부 기사단 장 본문은 "위쪽 차트의 첫 예시는 기사단", 기사단 탭 요약은 "이 가이드 차트의 첫 예시"라고 하지만, 3부 빛의 대장장이 장은 "위쪽 차트도 빛의 대장장이 탭이 먼저 열립니다"라고 합니다(defaultHeroBranchIndex=1). 이번 작업 범위가 아니라 고치지 않았습니다.
- 레이드 근거는 모두 님리사 신화 한 네임드입니다. 탱사이클의 초 단위는 "님리사 신화 기준"과 "내 공략표에 맞춘다"를 함께 적었습니다.
- 2026-10-20 t1 후속: '차트 첫 예시는 기사단'이라 쓴 두 문장을 실제 기본 탭(빛의 대장장이)에 맞게 고쳤다.
