# mage-fire
- 판정: 고침 (성난태양만. 서리불꽃은 로그가 없어 그대로)

## 고친 것
- **성난태양 오프닝(2부 오프닝 rail·영웅 탭)**: … → 진입 A 불덩이 작렬 → 진입 B 불태우기 → 발화 → 유성 → 불덩이 작렬
  → … → **유성 → 진입 A 불덩이 작렬 → 진입 B 불태우기 → 발화** → 불덩이 작렬
  - 근거: 레이드 5개 중 4개가 첫 발화 1.5~1.9초 전에 유성을 썼습니다. 그 뒤 불덩이 작렬·불기둥 직접 시전을 시작하고, 그 시전 중에 발화를 켰습니다. 예시는 https://www.warcraftlogs.com/reports/T3VrzW2LFBdf6Aat#fight=1&source=14 의 14.3 유성 → 15.2 불덩이 작렬 → 16.2 발화입니다. 레이드 전체로 보면 발화 26번 중 18번에서 직전 4회 안에 유성이 있었습니다.
  - APL: sf_combustion 에서 `meteor,if=buff.combustion.down&talent.sunfury_execution` 이 진입 주문보다 위에 있습니다. combustion 은 진입 시전이 끝나기 직전이나 유성 착탄 0.3초 전에 씁니다.
- **성난태양 발화 10초(2부 단일 rail)**: 발화 → 유성 → 불덩이 작렬 → … → **유성 → 불덩이 작렬(화염 파열 진입, 위쪽 가지: 불태우기) → 발화 → 화염 작렬 → 불덩이 작렬** → 불태우기 → 불덩이 작렬
  - 근거: 위와 같습니다. 발화 다음 버튼은 화염 작렬이 77%였습니다.
- **성난태양 평시 rail 위쪽 가지의 유성 조건**: "발화 안 착탄이 가능하면" → "중간 유성 · 쿨이 돌면"
  - 근거: 레이드 5개 모두 발화와 발화 사이 약 30초 지점에 유성을 한 번씩 썼습니다. 1부 본문의 "중간 유성을 제때"와도 맞습니다.
  - APL: `sf_filler=meteor,if=talent.blast_zone&time>variable.combustion_delay`
- **성난태양 광역 진입(2부 광역 rail·영웅 탭 광역 흐름)**: 불태우기 → 화염 작렬 → 발화 → 유성 → 불기둥 → 화염 작렬
  → **유성 → 불기둥(화염 파열 직접 시전, 위쪽 가지: 불태우기) → 발화 → 화염 작렬 → 불기둥 → 화염 작렬**
  - 근거: 쐐기 발화 156번 중 92번은 유성을 먼저 썼고, 유성을 나중에 쓴 경우는 23번이었습니다. 7명 중 4명이 대부분 유성을 먼저 썼습니다. 진입 주문은 불기둥 직접 시전이 가장 흔했습니다.
  - APL: `flamestrike,if=buff.combustion.down&!buff.hot_streak.react&buff.pyroclasm.up`
- **영웅 탭 성난태양 단일·광역 우선순위**: 1번 발화 → 2번 유성을 **1번 유성 → 2번 발화**로 바꾸고 설명도 맞췄습니다.
- **공통 광역 반복 rail(두 영웅 공통)**: 위쪽 가지를 유성(1번 칸) → 발화(2번 칸) 순서로 옮겼습니다. 서리불꽃 유성(발화 후반 착탄)은 상황별 끼워 넣기에 따로 적었습니다.
- **같은 순서를 말하는 문장도 맞춤**: 1부 발화·유성 장(영웅별 유성 시점), 단일 연습 본문의 우선순위 요약, 오프닝 장 한 줄 원리·본문, 성난태양 장 본문, 쐐기 한 판 본문·예시

## 그대로 둔 것과 이유
- **오프닝 앞부분(풀 직접 불덩이 작렬 → 화염구 → 화염 작렬 → 불덩이 작렬)**: 레이드 5개 모두 같은 순서였습니다.
- **진입 B 불태우기**: 레이드 1명(来个灌注)이 이 방식으로 진입해 남겼습니다.
- **평시 반복 순서(화염구 → 화염 작렬 → 불덩이 작렬)**: 로그와 같습니다(화염구 다음 화염 작렬 82%).
- **서리불꽃 전체**: 12.1.5 이후 상위 로그가 0개입니다.

## 보류·사용자 확인 필요
- **화염 레이드 로그는 5개뿐입니다.** 유성 순서는 5명 중 4명에 APL까지 같은 방향이라 고쳤지만, 来个灌注는 불태우기 → 발화 → 유성 순서로 꾸준히 썼습니다.
- **쐐기에서도 유성을 나중에 쓰는 플레이어가 있습니다.** 쟝삼풍(KR)은 발화 25번 중 13번에서 유성을 발화 뒤에 썼습니다(진입은 주로 불태우기).
