# monk-brewmaster
- 판정: 고침
- 근거 범위: 12.1.5 이후 WCL 상위 님리사 신화 레이드 16개(음영파 8·조화의 종사 8), 쐐기 11개(조화의 종사 8·음영파 3), 심크 APL `monk_brewmaster.simc`(2026-08-20 수정 — 12.1.5 전이라 로그를 우선함).
- 견본 확인(특성 코드 해독): 레이드·단일 견본 = 조화의 종사(흑우주 없음, 해독 없음), 쐐기 견본 = 음영파(흑우주·해독 있음). 두 견본 모두 천신의 주입·살살라빔의 힘·의식 상실 연계 선택. 기본 영웅 탭·견본은 지시대로 바꾸지 않음.

## 고친 것
1. **2부 단일 연습 타임라인 → "레이드 네임드(단일)"**
   - 전: 후려차기 → 범의 장풍 → 맥주통 → 불의 숨결 → 후려차기 → 맥주통 → 범의 장풍
   - 후: 후려차기 → 범의 장풍 → 맥주통 → 불의 숨결 → 후려차기 → 범의 장풍 → 맥주통 → 불의 숨결(반복)
   - 근거: 레이드 16개 다음 스킬 표 — 후려차기 → 범의 장풍 55~68%, 범의 장풍 → 맥주통 34~46%, 맥주통 → 불의 숨결 42~46%(맥주통 → 범의 장풍은 상위 3에 없음). 3회 안 비율 범의 장풍 → 맥주통 77~81% / 반대 38~46%. 두 영웅 특성·니우짜오 안팎 모두 같은 4단 반복. APL `tiger_palm,if=buff.blackout_combo.up` > `breath_of_fire` > `keg_smash` + 살살라빔의 힘(맥주통이 불의 숨결 초기화).
   - 예: https://www.warcraftlogs.com/reports/w2TpWxnkfv6bJMQm#fight=18&source=2
   - 같은 장 본문 1문단(실제 손 순서 문장 추가, 천신주 → 천신의 주입), 3문단(정화주·천신의 주입·강화주)을 맞춤.
2. **2부 광역 연습 타임라인 → "쐐기 풀(광역)"**
   - 전: 맥주통 → 불의 숨결 → 후려차기 → 범의 장풍 → 맥주통 → 폭발하는 맥주통 → 맥주통 → 범의 장풍
   - 후: 맥주통 → 불의 숨결 → 후려차기 → 범의 장풍 두 바퀴(반복). 폭발하는 맥주통은 끼워 넣기(골랐다면 · 평타가 몰릴 때), 흑우주를 위 가지(천신의 주입을 쓴 뒤)로.
   - 근거: 쐐기 11개 같은 4단 반복(조화 쐐기: 맥주통 → 불의 숨결 56%, 불의 숨결 → 후려차기 47%, 후려차기 → 범의 장풍 69%, 범의 장풍 → 맥주통 47%). 풀 첫 후려차기 중간값 9~11초(그전엔 맥주통·불의 숨결만). 조화의 종사 쐐기 8개는 폭발하는 맥주통 0회. 흑우주는 천신의 주입 뒤 14/15·5/6.
3. **음영파 오프닝(2부 타임라인·영웅 탭)**
   - 전: 불의 숨결(세트) → 기의 파동(사전) → 맥주통 → 후려차기 → 불의 숨결 → 범의 장풍 → 폭발하는 맥주통 → 맥주통 → 후려차기 → 니우짜오
   - 후: 불의 숨결(세트) → 맥주통(조롱) → 니우짜오 → 불의 숨결 → 후려차기 → 범의 장풍 → 폭발하는 맥주통 → 맥주통 → 불의 숨결 → 후려차기
   - 근거: 첫 3초 안 니우짜오 7/8, 기의 파동 사전 시전 2/8, 폭발하는 맥주통 4~7초 안 5/8. 예: https://www.warcraftlogs.com/reports/417Yk32TfrCXHxhc#fight=2&source=10
4. **조화의 종사 오프닝(2부 타임라인·영웅 탭)**
   - 전: 불의 숨결 → 기의 파동 → 맥주통 → 후려차기 → 불의 숨결 → 범의 장풍 → 폭발하는 맥주통 → 맥주통 → 후려차기 → 니우짜오 → 천신의 주입 → 범의 장풍
   - 후: 불의 숨결 → 니우짜오 → 맥주통 → 불의 숨결 → 후려차기 → 범의 장풍 → 천신의 주입 → 맥주통(빈 통) → 불의 숨결 → 후려차기 → 범의 장풍 → 폭발하는 맥주통(충전이 빌 때)
   - 근거: 첫 4번 안 니우짜오 7/8, 첫 10초 안 천신의 주입 6/8, 천신의 주입 → 맥주통 63%, 기의 파동 사전 1/8. APL `exploding_keg,if=cooldown.keg_smash.charges_fractional<1`.
   - 2부 오프닝 장 본문 1·2문단과 요점 1개를 새 순서에 맞춤.
5. **천신주(322507) → 천신의 주입(1241059)**: 음영파 레이드 단일 4번·쐐기 광역 7번, 2부 단일·광역·음영파 오프닝의 위 가지. 근거: 로그 27개 모두 천신주 0회·천신의 주입 분당 1.2~2.6, 두 견본 모두 천신의 주입 선택(선택 노드).
6. **음영파 레이드 단일 불의 숨결 설명**: 순서는 그대로 두고 "맥주통 바로 뒤"(살살라빔의 힘 초기화)를 보탬. 조화의 종사 쐐기 광역 폭발하는 맥주통 설명에 "조화 쐐기 로그 8개는 쓰지 않음"을 보탬.
7. **탱커 작업**
   - 영웅 탭 탭 이름: 단일 → "레이드 단일", 광역 → "쐐기 광역"(제목도 레이드/쐐기 포함).
   - 탱사이클 4개 새로 작성(talentBuildId raid / mythic-plus).
     - 음영파 레이드: 조롱 → 정화주 → 천신의 주입 → 흑우주 → 니우짜오(약 95초, 전투당 3~5번) → 강화주(0~3번) → 해악 축출 → 맥주통.
     - 조화 레이드: 조롱 → 천신의 주입(도발 뒤 15초 안 47개 교대 중 23개) → 범의 장풍(잠재된 기운) → 정화주 → 흑우주(→ 천신의 주입 47%) → 니우짜오(2~4번) → 강화주 → 맥주통.
     - 음영파 쐐기: 맥주통 → 불의 숨결 → 정화주 → 천신의 주입 → 니우짜오 → 손날 찌르기 → 폭발하는 맥주통 → 흑우주 → 강화주 → 팽이 차기(첫 큰 풀 3개 모두 천신의 주입 → 니우짜오).
     - 조화 쐐기: 맥주통 → 불의 숨결 → 천신의 주입 → 니우짜오 → 범의 장풍 → 정화주 → 손날 찌르기 → 흑우주 → 강화주 → 팽이 차기(천신의 주입이 니우짜오보다 먼저 12/15, 흑우주는 천신의 주입 뒤 14/15).
     - 견본 차이: 쐐기 견본에만 해독·흑우주, 레이드 견본에는 흑우주 없음을 summary에 적음.
   - 3부 '쐐기 한 판'에 `kind:'tank'` 쐐기 탱사이클(음영파·조화), '공격대 네임드'에 레이드 탱사이클(음영파·조화, 반복)을 넣음.

## 그대로 둔 것과 이유
- 영웅 탭 단일·광역 우선순위 순서(후려차기 > 범의 장풍 > 맥주통 > 불의 숨결 …): 우선순위로 읽으면 로그 4단 반복과 맞음. APL은 불의 숨결을 맥주통 위에 두지만 살살라빔의 힘 초기화 때문에 실제로는 맥주통 바로 뒤라 설명만 보탬.
- 음영파 "니우짜오 중 불의 숨결·맥주통 먼저"(광역 4·5번, 3부 음영파 장, 현장 팁): 레이드 로그에서 니우짜오 중 맥주통·불의 숨결 비중 20%(밖 17~18%), 불의 숨결 → 맥주통 25%(밖 15%)로 방향이 맞아 유지.
- 3부 쐐기 장 예시(흡수 맥주로 첫 몇 초 → 니우짜오): 쐐기 로그 순서(천신의 주입 → 니우짜오)와 같아 유지.
- 구르기(분당 1.7~2.1): 이동기라 딜사이클에 넣지 않음. 조롱·해악 축출은 탱사이클로.
- 상단 opener(예전 필드)에 남은 "기의 파동 1초 전"·"니우짜오를 먼저 써야 하는 풀" 문장: 화면에 안 나오는 예전 필드라 지시대로 건드리지 않음.
- 기본 영웅 탭·특성 견본·현장 팁·출처: 범위 밖.

## 보류·사용자 확인 필요
1. **견본과 로그 다수 영웅의 엇갈림**: 레이드 견본은 조화의 종사인데 레이드 상위 로그 다수는 음영파, 쐐기 견본은 음영파인데 쐐기 로그 다수는 조화의 종사. 검사기 규칙상 탱사이클은 raid/mythic-plus 견본에 연결돼 음영파 레이드 탭이 조화 견본을, 조화 쐐기 탭이 음영파 견본을 가리킴 → summary에 "영웅 특성만 바꿔 읽습니다"·견본 차이를 적음. 견본을 바꿀지는 사용자 결정 필요.
2. **흑우주**: 레이드 견본에 없지만 레이드 상위 로그 16개 모두, 조화 쐐기 8개 모두 흑우주를 고름. 탱사이클 문장에만 반영했고 견본·조화 우선순위표에는 넣지 않음.
3. **음영파 쐐기 로그 3개뿐**: 조화 쐐기 8개와 같은 뼈대인지 함께 확인하고 단정 표현을 피함. 로그가 늘면 재확인 권장.
4. **기의 파동 사전 시전 단계 삭제**: 레이드 로그 16개 중 3개만 전투 전에 사용해 오프닝 그림에서 뺌(요점에 "골랐다면 전투 중에 씁니다"). 원래 이 단계를 권한 공개 가이드 출처가 있다면 그 문장과 차이가 남음.
