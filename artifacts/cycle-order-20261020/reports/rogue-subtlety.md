# rogue-subtlety
- 판정: 고침
- 고친 것:
  - 기만자 오프닝(2부 오프닝 rail, 영웅 탭 기만자 opener, 흐름 아이콘): 그림자 일격 → 피아귀의 이빨 → 어둠의 춤 → 어둠의 칼날 → 은밀한 기술 → 그림자 일격(점수 모자랄 때만) → 절개 → **그림자 일격 → 절개 → 소멸 → 그림자 일격 → 피아귀의 이빨(직후도 됨) → 어둠의 칼날 → 어둠의 춤 → 은밀한 기술 → 그림자 일격(무형검 발동) → 절개(최후의 일격)**.
    - 근거: 기만자 레이드 8개 중 8개가 첫 춤 전에 절개 → 소멸을 씀. 6개는 소멸 뒤 바로 그림자 일격. 7개가 칼날을 춤보다 먼저 씀(대부분 같은 순간). 6개가 은밀한 기술 바로 뒤에 그림자 일격을 씀. 예: https://www.warcraftlogs.com/reports/wQLPRC9hMWaFVkr4#fight=21&source=3
    - APL: cds `vanish,if=!variable.stealth&energy>=50&!buff.subterfuge.up&combo_points<=2`, `shadow_blades`가 `shadow_dance`보다 위에 있음.
    - "죽음추적자처럼 소멸·절개를 반복할 필요가 없습니다"라는 기존 행 설명은 지웠습니다.
  - 죽음추적자 오프닝(2부 오프닝 rail, 영웅 탭 죽음추적자 opener, 흐름 아이콘): … 소멸 → 그림자 일격 → 피아귀의 이빨 → 준비 절개 → 칼날 → 춤 → 표창 폭풍 → 절개(위: 은밀한 기술) → **… 소멸 → 그림자 일격 → 준비 절개 → 칼날 → 춤 → 피아귀의 이빨(춤 첫 행동) → 은밀한 기술(위: 강화 절개가 켜졌으면 먼저) → 그림자 일격 → 어둡고 어두운 밤 절개**.
    - 근거: 죽음추적자 레이드 6개 중 5개가 피아귀의 이빨을 춤 뒤에 씀. 6개 모두 춤 첫 소비가 은밀한 기술. 첫 춤의 표창 폭풍은 0개. 5개가 은밀한 기술 뒤 그림자 일격 → 절개를 씀. 예: https://www.warcraftlogs.com/reports/417Yk32TfrCXHxhc#fight=2&source=7
    - APL: cds `goremaws_bite,if=buff.shadow_dance.up&!buff.ancient_arts.up`, 죽음추적자 `shadow_dance` 조건(어둡고 어두운 밤 또는 은밀한 기술 준비·징표 1중첩 이하), finish `eviscerate,if=buff.darkest_night.up`이 맨 위.
  - 단일 반복 rail(2부 단일 연습, 두 영웅 공통): 춤 → 은밀한 기술 → 절개(점수가 돌아왔으면) → 그림자 일격 → 절개 → **춤 → 은밀한 기술 → 그림자 일격 → 절개 → 절개(점수가 돌아왔으면)**.
    - 근거: 레이드 반복 구간에서 은밀한 기술 다음 버튼은 그림자 일격이 기만자 47%(113회)·죽음추적자 43%(131회)이고, 절개는 9%·34%. 춤 구간 예시마다 그림자 일격 → 절개 → 절개가 되풀이됨.
    - APL: `build_at_max_for_apex`(고대의 기술 3노드) 줄로 생성 뒤 다음 마무리 일격이 점수를 다시 채움.
  - 쐐기 광역 rail note: "쐐기 풀은 은신 그림자 일격으로 붙어 시작"을 덧붙임. 근거: 대조 자료의 쐐기 광역 풀 시작 11곳 중 9곳.

    - 피아귀의 이빨 장 한 줄 원리·본문·요점 두 개(춤 직전이나 춤 첫 행동)
