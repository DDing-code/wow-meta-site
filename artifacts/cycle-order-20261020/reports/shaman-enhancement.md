# shaman-enhancement
- 판정: 고침 (토템술사 변경 없음)
- 로그: 12.1.5 이후 상위 레이드 8개·쐐기 8개, 모두 폭풍인도자. 토템술사 로그는 없습니다.
- 셈 방법: 대조 자료의 "파멸의 바람" 분당 9.2회는 Doom Winds(469270)가 승천 중 1초마다 저절로 찍힌 것이라 뺐습니다. 바람의 일격·폭풍의 일격·낙뢰와 같은 시각에 찍힌 번개 화살·연쇄 번개·폭풍은 토림의 기원 자동 시전이라 뺐습니다(verify-enhancement-kb.cjs 의 같은 기준).

## 고친 것
1. 폭풍인도자 오프닝 (영웅 탭 opener, 2부 오프닝 타임라인·note, 같은 장 둘째 문단)
   - 전: 낙뢰(사전) → 전격의 불길 → 세계의 분리(선택) → 용암 채찍(채찍 화염) → 승천 → 다시 준비된 낙뢰 → 바람의 일격
   - 후: 낙뢰(사전) → 전격의 불길 → 세계의 분리(선택) → 용암 채찍(채찍 화염) → 승천 → 바람의 일격 → 다시 준비된 낙뢰
   - 근거: 레이드 로그 8개 모두 승천 바로 다음이 바람의 일격. 전체 승천 직후 바람의 일격은 레이드 27회 중 22회, 쐐기 95회 중 66회. 예: https://www.warcraftlogs.com/reports/jVpbr1RdBzhmF2gv#fight=2&source=22
   - APL(10월 15일, 12.1.5 뒤): single_sb 는 `crash_lightning,if=!buff.crash_lightning.up|talent.storm_unleashed.enabled` 가 windstrike 위라 로그와 다릅니다. 로그를 따랐습니다.
   - 같이 바꾼 것: verify-enhancement-kb.cjs 가 "상단 opener = 폭풍인도자 opener" 를 요구해서 상단 opener 도 같은 값으로 맞췄습니다(상단 priority 는 바뀐 것 없음).
2. 폭풍인도자 광역 우선순위 (영웅 탭 aoe, 2부 광역 줄의 승천 가지 조건)
   - 전: 전격의 불길 → 세계의 분리 → 승천 → 태고의 폭풍 → 낙뢰 → …
   - 후: 전격의 불길 → 세계의 분리 → 낙뢰 → 승천 → 태고의 폭풍 → …
   - 근거: 쐐기에서 처음 12회 안에 승천을 쓴 풀 37개 중 33개가 승천 전에 낙뢰를 씀(그중 27개는 전격의 불길 → 낙뢰). 풀 79개 중 73개가 전격의 불길로 시작(첫째·둘째). 단일 우선순위(전격 → 낙뢰 → 승천)와도 같아졌습니다.
   - APL: aoe 는 `ascendance,if=ti_chain_lightning` 가 crash_lightning 위라 로그와 다릅니다. 로그를 따랐습니다.
3. 폭풍인도자 단일·광역 반복 줄 (2부 단일·광역 타임라인, 단일 장 둘째 문단·확인 문제 답, 1부 "쓰고 나면 타격기가 빨리 돌아옵니다" 둘째 문단 한 문장)
   - 단일 전: 전격의 불길 → 낙뢰 → 폭풍의 일격 → 용암 채찍 → 번개 화살 → 폭풍의 일격 → 용암 채찍(돌아오면 바로) → 번개 화살
   - 단일 후: 전격의 불길 → 낙뢰 → 폭풍의 일격 → 폭풍의 일격(위 용암 채찍: 충전이 없으면) → 번개 화살 → 낙뢰 → 폭풍의 일격 → 번개 화살
   - 광역도 같은 방식(두 번째 용암 채찍 칸 → 폭풍의 일격 + 용암 채찍 가지).
   - 확인 문제 "10중첩 번개 화살 직후 용암 채찍이 돌아와 있으면?" 답: 용암 채찍 → 폭풍의 일격(충전이 있으면), 낙뢰·전격의 불길 먼저, 용암 채찍은 충전이 없을 때.
   - 근거: 번개 화살 바로 다음 용암 채찍 레이드 245회 중 1회, 쐐기 729회 중 6회. 번개 화살 다음은 폭풍의 일격 44~46%, 낙뢰 29~31%. 폭풍의 일격 다음 폭풍의 일격 26~31%. 용암 채찍 분당 1.8회(레이드)·1.1회(쐐기) 대 폭풍의 일격 16.6·14.4회.
   - APL: single_sb 의 `stormstrike,if=charges_fractional>=1.8`·`stormstrike` 줄이 채찍 화염 없는 `lava_lash` 줄보다 위. 영웅 탭 단일 우선순위(폭풍의 일격 → 용암 채찍)는 원래 이 순서라 그대로입니다.

## 그대로 둔 것과 이유
- 오프닝 첫머리 낙뢰(사전) → 전격의 불길: 전투 시작 전 시전은 로그에 안 보입니다. 보이는 것 중 낙뢰가 먼저 2개, 전격의 불길 → 낙뢰 2개, 승천 전 낙뢰 없음 4개라 갈려서 두었습니다(note 를 "사전 낙뢰가 어렵다면 전격의 불길 바로 뒤에" 로만 다듬음).
- 세계의 분리·용암 채찍(채찍 화염)·태고의 폭풍 조건 칸: 상위 로그 16개에서 0회지만 특성 선택에 달린 조건 칸이고, 검사 스크립트가 두 영웅 단일에 태고의 폭풍을 요구합니다.
- 폭풍인도자 단일 우선순위: 로그·APL 과 맞습니다.
- 토템술사 전부: 12.1.5 이후 로그 없음.
