# hunter-survival
- 판정: 고침(일부 보류)
- 고친 것:
  - 2부 단일 반복 rail(두 영웅 공통): 살상 명령 → 폭탄 → 일격 → 휩쓸기 → 살상 명령 → 폭탄 → 일격 → 휩쓸기 → **살상 명령 → 폭탄 → 일격 → 살상 명령 → 휩쓸기 → 일격 → 살상 명령 → 휩쓸기 → 폭탄**. "명령 한 번 → 창끝 공격 두 번 → 다시 명령" 리듬이고, 휩쓸기는 늘 명령 바로 뒤에 와서 창끝을 싣습니다.
    - 근거: 레이드 반복 구간에서 살상 명령 사이 버튼 수가 2회인 경우가 파수꾼 58%(506회)·무리의 지도자 57%(442회), 3회는 19%·18%입니다. 랩터의 일격 다음 살상 명령 45%(휩쓸기 35%), 휩쓸기 다음 살상 명령 49%입니다. 분당 시전 비율(명령 14.1 : 일격 9.9 : 휩쓸기 9.8 : 폭탄 7.7)도 새 rail(3:2:2:2)과 맞습니다. 예: https://www.warcraftlogs.com/reports/cy2L71n8ABZdaRPt#fight=9&source=4
    - APL: sentst 1줄 `kill_command,if=buff.tip_of_the_spear.stack=0&…`(창끝이 비면 명령).
    - 1부 "집중과 창끝" 장의 "명령 한 번 → 강화 공격 두 번 → 다시 명령" 설명과도 이제 맞습니다.
  - 무리의 지도자 오프닝(2부 오프닝 rail, 영웅 탭 opener·요약): … 제압 → 살상 명령 → 폭탄 → 폭탄 → 붐스틱 → **… 제압 → 살상 명령 → 폭탄 → 붐스틱 → 폭탄(붐스틱 뒤 돌아온 충전)**. 제압 다음 살상 명령, 제압 조건 "두 개"는 검사기 요구대로 유지했습니다.
    - 근거: 무리의 지도자 레이드 5개 중 제압 뒤 붐스틱 전에 폭탄을 두 번 쓴 로그는 0개입니다. 살상 명령 뒤 붐스틱까지 0~1손인 로그는 4개입니다. 예: https://www.warcraftlogs.com/reports/MJR2kyNVXdLTc3D8#fight=7&source=61
    - APL: plst `wildfire_bomb,if=buff.tip_of_the_spear.up&(talent.lethal_calibration&full_recharge_time<4+gcd|…)` 다음 `boomstick`.
  - 같은 순서를 말하는 문장 맞춤: 오프닝 장 본문(무리의 지도자 문단), 영웅 탭 무리의 지도자 오프닝 요약·행 설명, 단일 rail note, 단일 장 실수 한 줄.
  - note만 덧붙임:
    - 파수꾼 오프닝: "붐스틱 앞 한두 손은 로그마다 다름"(6개 중 2개는 살상 명령, 2개는 4부 심화 시작처럼 랩터의 일격·휩쓸기).
    - 무리의 지도자 오프닝: "쌍둥이 송곳니면 제압 전 명령 불필요, 상위 로그 5개 중 4개가 제압 전에 명령을 안 씀".
- 그대로 둔 것과 이유:
  - 파수꾼 오프닝 순서(폭탄 → 붐스틱 → 제압 → 폭탄 → 표창): 붐스틱을 제압 전에 쓴 4개 모두 붐스틱 → 제압 순서이고, 제압 다음 폭탄이 6개 중 4개입니다. 붐스틱 앞에 끼는 손만 갈립니다.
  - 영웅 탭 단일·광역 우선순위: APL sentst·plst 순서와 같습니다.
  - 광역 반복 rail: 쐐기 광역 구간에서 붐스틱 직전 살상 명령 43%, 붐스틱 직후 폭탄 45%, 폭탄 다음 살상 명령 49%로 가이드와 같습니다. 명령 사이 2회 55%·3회 22%라 지금 rail(2회·3회 섞임)을 유지했습니다.
  - 재갈 1.3/분(쐐기): 차단이라 딜사이클에 넣지 않았습니다.
- KB 추가 필요: 없음
- 보류·사용자 확인 필요:
  - **무리의 지도자 예시 빌드**: 상위 무리의 지도자 레이드 로그 5개 중 4개가 제압 전에 살상 명령을 쓰지 않았습니다(3개는 풀 직후 바로 제압). 쌍둥이 송곳니를 고른 빌드로 보입니다. 가이드 예시는 "쌍둥이 송곳니 없음"이고 검사기도 그 조건을 요구해, 예시 빌드를 바꿀지 사용자 확인이 필요합니다.
  - 파수꾼 광역 진입(제압 → 붐스틱): 쐐기에서 제압이 끼인 풀 3곳 중 2곳은 붐스틱 → 제압이었습니다. APL sentcleave(쌍둥이 송곳니면 창끝 0일 때 제압 먼저)는 가이드와 같고 표본이 작아 보류했습니다.
  - 파수꾼 오프닝: 6개 중 2개가 붐스틱 직전에 살상 명령을 써서 창끝을 실은 붐스틱을 쐈습니다. 가이드의 "첫 붐스틱은 창끝 없이" 예외 설명과 다릅니다. 공개 가이드 재확인이 필요합니다.
