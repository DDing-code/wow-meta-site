# demonhunter-devourer
- 판정: 고침(일부 보류)
- 고친 것:
  - 두 영웅 오프닝 시작(2부 오프닝 rail 세 줄·영웅 탭 두 개): 영혼 제물(풀링 2초 전) → 흡수(풀링 1초 전) → 흡수(풀링 직전 시작) → 영혼 제물(전투 시작 뒤 몇 초 안). 근거: 상위 레이드 로그 15개 모두 흡수로 시작, 영혼 제물을 쓴 14개 모두 흡수 뒤(전투 시작 0.7~10.7초), 전투 전 5초 안 시전 0개. 예시 https://www.warcraftlogs.com/reports/vA8gdTVNkM1hFxCL#fight=24&source=977 . APL precombat 은 soul_immolation → consume 이지만 로그 우선. 같은 장 한 줄 원리·첫 문단·요점도 맞춤.
  - 궤멸자 오프닝(rail·영웅 탭) 끝부분: 붕괴하는 별 → 도태 → 집어삼키기 → 붕괴하는 별 → 공허 광선 → 집어삼키기 → 도태. 근거: 궤멸자 8개 중 6개가 첫 별 바로 뒤 공허 광선, 별 직후 도태는 1개. 같은 장 둘째 문단 끝 문장도 맞춤.
  - 궤멸자 2부 단일 반복 rail(탈태 안): 집어삼키기 → 공허 광선 → 붕괴하는 별 → 도태 → 공허칼날 → 집어삼키기 → 집어삼키기 → 공허 광선 → 붕괴하는 별 → 집어삼키기 → 도태 → 공허칼날. 근거: 별 159번 중 다음이 집어삼키기 95번, 별 뒤 3회 안 도태 10% / 도태 뒤 3회 안 별 42%. APL annihilator_meta 의 reaps(souls_consumed>=4). 요점·본문과 영웅 탭 도태 설명도 맞춤(행 순서는 그대로).
  - 공허상흔 진입(rail①·영웅 탭): 공허칼날{위 사냥} → 공허 탈태 → 공허칼날 → 복수의 퇴각 → 사냥 → 공허 탈태. 근거: 공허상흔 7개 중 6개가 공허칼날 → 복수의 퇴각 → 사냥, 7개 모두 사냥 뒤 탈태 안 기술. 예시 https://www.warcraftlogs.com/reports/61pJ7F4XkVcAWxmy#fight=2&source=91 . APL voidscarred_hunt_entry(voidblade → vengeful_retreat → the_hunt). 복수의 퇴각은 포식 KB 번호 344866 사용.
  - 공허상흔 첫 탈태 안(rail②·영웅 탭): 공허 광선 → 사신의 대가 → 장막 관통 → 붕괴하는 별 → 포식자의 각성 → 도태 → 공허 광선 → 사신의 대가 → 장막 관통 → 공허 광선 → 붕괴하는 별 → 포식자의 각성 → 사신의 대가 → 도태 → 공허 광선. 근거: 사신의 대가가 첫 광선보다 먼저 6/7, 장막 관통이 첫 광선보다 먼저 5/7, 첫 별 뒤 포식자의 각성 7/7·그 뒤 사신의 대가 7/7. APL 은 void_ray(no_ray_this_window)가 맨 위지만 로그 우선.
  - 공허상흔 단일 우선순위: 사신의 대가 다음에 복수의 퇴각 추가(분당 3.0회, 사신의 대가 다음 42%). 사신의 대가(첫 진입은 광선보다 먼저)·포식자의 각성(보통 별 직후) 설명 보강, 광역 포식자의 각성 설명도 같은 뜻으로. 영웅 탭 소개, 4부 공허상흔 장 둘째 문단·요점, 1부 굶주린 베기 장 셋째 문단의 순서 문장을 맞춤.
- 그대로 둔 것과 이유:
  - 공허 탈태 진입 시점: 공허 탈태 시전이 로그에 한 번도 찍히지 않아(다른 번호도 없음) 첫 별 앞 공허 광선이 탈태 안인지 밖인지 판단 불가. 기존 "탈태 → 공허 광선 → 별" 유지.
  - 공허상흔 우선순위의 포식자의 각성 → 붕괴하는 별 행 순서: 로그에서는 별 98번 중 직후 78번·앞 1번이지만 이유는 쿨다운(진입 직전 사냥)이고, APL(predators_wake,if=buff.collapsing_star.up)과 공개 가이드가 "쓸 수 있으면 별 앞"이라 행 순서는 두고 설명만 보탬.
  - 궤멸자 공허칼날(포식자의 이빨): 로그 8개에서 진입 전 0회(분당 0.2회)지만 선택 특성 조건 행이라 유지, 영웅 탭 설명에 로그 사실을 적음.
  - 광역(박멸) 흐름: 쐐기 광역 풀이 한 개도 판정되지 않아 바꾸지 않음(포식자의 각성 캡션만 "쓸 수 있으면 별 앞"으로).
  - 흡수·수확이 영웅 탭 단일 목록에 없는 것: 목록이 "형상 내부 우선순위"로 범위를 밝히고 있어 그대로 둠.
