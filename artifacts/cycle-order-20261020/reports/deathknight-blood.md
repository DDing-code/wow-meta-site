# deathknight-blood
- 판정: 고침 (죽음의 인도자 쐐기 탱사이클만 로그 없이 APL 기준 참고용)

## 고친 것
- 산레인 오프닝(영웅 탭·2부 오프닝 줄): 죽음의 마수 → 죽음과 부패 → 춤추는 룬 무기 → 시체 되살리기 → 피의 소용돌이 → 흡혈의 일격 → 죽음의 일격 → 골수분쇄 → (후) 죽음의 마수 → 죽음과 부패 → 시체 되살리기 → 춤추는 룬 무기 → 피의 소용돌이 → 흡혈의 일격 → 죽음의 일격 → 흡혈의 일격.
  근거: 시체 되살리기를 쓴 레이드 오프닝 4개 모두 룬 무기 직전·같은 순간. 룬 무기로 시작한 5개(7개 중) 모두 첫 22회에 골수분쇄 없이 흡혈의 일격 4~5번 → 죽음의 일격 → 흡혈의 일격. 예시 https://www.warcraftlogs.com/reports/BnZG9KqvFwYWr286#fight=4&source=31 . APL `high_prio_actions=raise_dead,use_off_gcd=1` → `dancing_rune_weapon`.
- 죽음의 인도자 오프닝: … 사신의 징표 → 시체 되살리기 → 춤추는 룬 무기 → 피의 소용돌이 → 골수분쇄 → 죽음의 일격 → (후) … 시체 되살리기 → 춤추는 룬 무기 → 사신의 징표 → 피의 소용돌이 → 골수분쇄 → 심장 강타 → 죽음의 일격.
  근거: 레이드 8개 중 5개가 룬 무기 → 징표, 시체 되살리기 7개가 룬 무기와 같은 순간, 심장 강타 8개 모두 첫 12회 안. 예시 https://www.warcraftlogs.com/reports/t3PrkC1Lj8cvnyq4#fight=17&source=6 . APL `dancing_rune_weapon,if=!buff.exterminate.up&!debuff.reapers_mark_debuff.up`. 4부 죽음의 인도자 장 본문·요점, 2부 오프닝 본문, 영웅 탭 소개 문장도 같은 순서로 고침.
- 레이드 단일 우선순위(영웅 탭): 두 영웅 모두 피의 소용돌이를 심장 강타 앞에 추가(레이드 분당 산레인 9.2·인도자 8.2회인데 목록에 없었음, APL `blood_boil`). 산레인은 죽음의 마수(뼈 보충)를 골수분쇄 앞에 추가(분당 1.6회, 59%가 연속 글쿨 안 = 근접 중, APL `sanlayn deaths_caress,if=bone_shield.stack<6`가 marrowrend 위). 인도자는 춤추는 룬 무기를 징표 앞에 추가. 2부 단일 본문 우선순위 문장·끼워 넣기 줄, 2부 이동 장의 "근접 중 죽음의 마수" 문장·실수도 맞춤.
- 쐐기 광역: 줄 위 생존기 순서 춤추는 룬 무기 → 흡혈 을 흡혈(풀 시작) → 춤추는 룬 무기(다 모인 뒤) 로. 근거: 큰 풀 43개에서 흡혈 중앙 7초, 룬 무기 중앙 14.5초, 둘 다 쓴 31풀 중 28풀이 흡혈 먼저. 예시 https://www.warcraftlogs.com/reports/GZK1BjwdahFp8bry#fight=31&source=766 . 3부 쐐기 장의 한 줄 원리·본문·요점·예시("첫 몇 초는 춤추는 룬 무기")도 고침. 인도자 쐐기 광역에 몰살 골수분쇄 줄 추가, 룬 무기를 징표 앞으로.
- 탱커 작업: 탭 이름 레이드 단일·쐐기 광역, 2부 타임라인 제목 레이드 네임드(단일)·쐐기 풀(광역). 영웅마다 tankRaid·tankMythic 새로 작성, 3부 쐐기·공격대 장에 kind tank 타임라인 추가.
  - 레이드: 도발 간격 대략 45~65초, 넘겨받고 대략 10~20초 뒤 흡혈+대마법 보호막(교대 72번 중 40번), 얼음같은 인내력 전투당 0~2번. 산레인은 룬 무기를 교대와 따로(도발 5초 안 34번 중 2번), 인도자는 도발 직후 룬 무기 → 징표가 더 잦음(38번 중 8번). 예시 https://www.warcraftlogs.com/reports/XAhZr4DL62KGbNQF#fight=1&source=21
  - 쐐기: 죽음의 진군 → 죽음의 마수 → 피의 소용돌이 → 흡혈 → 손아귀 → 죽음과 부패 → 정신 얼리기 → 룬 무기 → 대마법 보호막 → 풀 끝 룬 마력 보존.
  - 견본 차이: 쐐기 견본은 흡혈의 구 있음, 레이드 견본은 유혈의 폭발·피구더기 있음(코드 해독으로 확인).

## 그대로 둔 것과 이유
- 2부 단일 반복 줄 본체: 피의 소용돌이 → 심장 강타 → 죽음의 일격 흐름이 로그 3연속 상위 패턴과 같음.
- 광역 줄의 죽음과 부패 → 피의 소용돌이 순서: 풀 시작 순서가 58:42로 갈림.
- 인도자 오프닝의 피의 소용돌이·골수분쇄 순서: 4:4로 갈림(줄 note에 "로그마다 다름").
- 섭취: 로그 1개만 쓰고 두 견본에 없음. "골랐다면" 끼워 넣기 그대로.
- 심크 APL 혈기 파일은 8월 11일 수정본(12.1.5 전). 로그와 같은 방향인 조건만 근거로 씀.
