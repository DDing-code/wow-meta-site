- 프리풀: 지옥소환사 유령 출몰을 전투 전·풀링 1초 전으로 표기(심크 우선순위 precombat `haunt,if=active_enemies<2|(hero_tree.hellcaller&active_enemies<3)`, Icy Veins·Method 모두 Precast Haunt, 로그 10개 중 7개가 0.0~0.6초에 출몰로 시작. 기본 1.5초 시전에서 유령 출몰 연마 0.3초 단축). Icy Veins의 어둠의 화살 사전 시전은 심크 우선순위·Method·로그에 없어 넣지 않음. 영혼 수확자 쪽 출몰 단계는 기준이 아니라 그대로 둠.
- 오프닝: 순서는 로그 과반과 같아 유지 — 출몰 → 고통 → 쇠퇴 → 적개심 → 암흑시선 → 불안정한 고통 → 불안정한 고통 → 수확 → 불안정한 고통 → 손아귀 를 출몰 → 고통 → 쇠퇴 → 적개심 → 암흑시선 → 불안정한 고통 ×4~5 → 수확 → 불안정한 고통 → 손아귀 로(두 칸을 한 칸 count 로). 근거: 고통 → 쇠퇴 10/10, 적개심이 암흑시선보다 먼저 7/10, 적개심·암흑시선 뒤 첫 불안정한 고통 묶음 4~5번 6/10(4번 4개·5번 2개, 나머지 2·3·6번), 조각을 먼저 쓰고 수확 6/10, 수확 뒤 불안정한 고통 먼저 4/6. 예 https://www.warcraftlogs.com/reports/c4CVpzBKAkt2vZbL#fight=33&source=192 . 오프닝 장 rail 순서를 지옥소환사 → 영혼 수확자로.
- 단일 반복: 2부 단일 장 반복 흐름 "영혼 수확자 기준"(출몰 → 고통 → 부패 → 불안정한 고통{암흑시선} → 어둠의 화살{수확 2조각 이하} → 불안정한 고통{손아귀} → 어둠의 화살{손아귀}) → "지옥소환사 기준"(출몰 → 고통{적개심} → 불안정한 고통{암흑시선} → 어둠의 화살{수확: 적개심 뒤 조각 쓴 다음} → 불안정한 고통{손아귀: 일몰·종료 임박} → 어둠의 화살{손아귀: 필러 대신}). 근거: 지옥소환사 반복 구간 분당 불안정한 고통 15.6·어둠의 화살 14.0·고통 5.6·출몰 3.3·손아귀 3.3·적개심 0.9·쇠퇴 0.03, 적개심 다음 시전 38번 중 22번이 불안정한 고통, 반복 예시에서 손아귀는 암흑시선 중에만, 심크 우선순위 HC_st. 이어서 누른 횟수는 모두 중앙값 1이라 count 를 달지 않음. 끼워 넣기 rail: 쇠퇴(끊겼을 때)·부패·수확 2조각 이하·4세트 씨앗(영혼 수확자)·영혼 흡수. 영웅 탭 지옥소환사 단일 우선순위는 순서 유지, summary 와 쇠퇴 행 문장만 로그 근거로.
