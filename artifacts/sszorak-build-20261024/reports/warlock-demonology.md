# warlock-demonology
- 판정: 일부 고침(오프닝 횟수·파열 뒤 단계 추가, 단일 반복은 그대로)
- 기준 영웅 특성·기본 탭: 악마학자(스조라크 상위 전체 200행·한국 100행 모두), 기본 탭은 원래 [1] 악마학자 그대로(자동). 글에서 맞춘 곳: 영웅 탭 두 summary("이번 한국 검수" 문장 → 스조라크·님리사·쐐기 행 수), 3부 악마학자 장 한 줄 원리("단일 네임드·레이드·쐐기 모두")·곁글(스조라크 200행 추가), 3부 공격대 장 한 줄 원리("영웅 특성은 순수 단일인지…로 고릅니다" → "단일 네임드도 악마학자가 기준"), 4부 영혼 수확자 장 한 줄 원리(상위 기록엔 없음).
- 프리풀: 사전 악마 화살을 전투 전·풀링 4초 전으로 표기. 근거: 심크 우선순위 precombat `demonbolt,if=!buff.power_siphon.up&(talent.ruination&!talent.grimoire_imp_lord|talent.ruination&!talent.summon_doomguard)`(새 견본은 황폐 있음·파멸수호병 없음 → 해당), Icy Veins "Pre-cast Demonbolt", Method "Pre cast 2x Shadow Bolt / 1x Demonbolt", KB 기본 4.5초 시전, 로그 9개 중 4개 악마 화살·2개 어둠의 화살로 시작. 마력 착취 사전 시전은 새 견본에 없음(파열 300/300).
- 오프닝: 악마 화살 → 공포사냥개 → 흑마법서 → 어둠의 화살 → 폭군 → 굴단의 손 → 굴단의 손 → 어둠의 화살 → 파열 → 굴단의 손 을 악마 화살 → 공포사냥개 → 흑마법서 → 어둠의 화살 → 폭군 → 굴단의 손 ×2 → 어둠의 화살 → 파열 → 어둠의 화살 ×2~4 → 굴단의 손 ×2 로. 근거: 공포사냥개 먼저 9/9, 폭군 앞 어둠의 화살 5/9, 폭군 뒤 굴단의 손 연속 두 번 8/9, 그 뒤 어둠의 화살 5/9(3개는 바로 파열), 파열 다음 어둠의 화살 9/9(2~4번 8/9), 그 뒤 굴단의 손 두 번 6/9. 예 https://www.warcraftlogs.com/reports/4T1z8LyRKPq3HdBt#fight=22&source=23 . 오프닝 장 rail·비교 카드·요점·실수 순서를 악마학자 먼저로.
- 단일 반복: 변경 없음 — 공통 rail 이 로그(분당 굴단의 손 15.8·악마 화살 11.6·어둠의 화살 8.2·파열 3.3·공포사냥개 2.6·황폐 1.8·지옥불 화살 1.7, 굴단의 손 → 악마 화살 41%·악마 화살 → 굴단의 손 62%)·심크 우선순위 diabolist 목록과 맞음. 이어서 누른 횟수는 굴단의 손·악마 화살·어둠의 화살 모두 중앙값 1이라 count 없음. 악마학자 단일 우선순위 summary 에 "단일 견본은 파멸수호병·파멸을 고르지 않음"만 더함(rail 의 파멸수호병 가지는 이미 '고른 빌드').
