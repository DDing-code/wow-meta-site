- 판정: 고침
- 기준 영웅 특성·기본 탭: 숲의 수호자, 기본 탭 [0] 엘룬의 대행자 → [1] 숲의 수호자 (자동 결정 그대로. 스조라크 신화 12.1.5 상위 전 지역 198행 중 193행, 한국 99행 중 97행). 단일 견본도 스조라크 대표 빌드(숲의 수호자, 영혼 소집·천체의 정렬·풍성한 개화·꿈의 통제)로 자동 교체, buildNote 로 선택 칸 설명. 글에서 맞춘 곳: 2부 단일·오프닝 장 전체, 1부 첫 장("현재 기본인 엘룬의 대행자는" → 단일 기준 숲의 수호자·쐐기 기본 엘룬의 대행자), 3부 엘룬의 대행자 장(쐐기 기본·단일 견본은 숲의 수호자·레이드 견본은 예전 엘룬 코드 그대로), 3부 공격대 네임드 장(님리사 1건 문장 → 스조라크·님리사 상위 행 수), 4부 숲의 수호자 장("다른 선택지" → 단일 네임드 기준, 견본 문장), 두 영웅 탭 summary·bullets.
- 프리풀: 숲의 수호자 천벌 ×3·전투 전·풀링 4초 전 (심크 우선순위 precombat wrath·wrath·wrath,if=talent.dream_surge&enemies<=2 — 새 견본에 꿈의 쇄도 433831 있음, Method 숲의 수호자 "Start pressing Wrath at 3-4 seconds", 로그 10개 중 9개가 0~1초에 천벌 적중). 엘룬의 대행자는 순서 그대로, 캡션의 "2~3회"를 count '2~3' 으로만 옮김.
- 오프닝: 천벌(2~3회) → 태양섬광 → 자연의 군대 → 천체의 정렬 → 별빛쇄도/별똥별 → 영혼 소집 → 별빛쇄도 → 천벌 ⇒ 천벌 ×3 → 태양섬광 → 자연의 군대 → 천체의 정렬 → 별빛쇄도 ×3~4 → 영혼 소집 → 별빛쇄도 ×2 → 천벌 → 태양섬광(갱신) → 천벌 → 일월식 (태양) → 별빛쇄도 ×3. 로그 10개: 자연의 군대 바로 뒤 천체의 정렬 10/10, 태양섬광 바로 뒤 자연의 군대 6/10(달빛섬광 끼움 2·일월식 먼저 2), 정렬 뒤 별빛쇄도 3~4번 8/10(4번 5·3번 3 — 과반 단일 수가 없어 범위), 영혼 소집 10/10, 그 뒤 별빛쇄도 2번 6/10, 18~24초 일월식 (태양) 10/10·그 앞 태양섬광 갱신 10/10·마지막 시전 천벌 9/10, 일월식 바로 뒤 별빛쇄도 3번 6/10. 예: https://www.warcraftlogs.com/reports/R9zp3rQZP1kyHxb8#fight=23&source=186 . 오프닝 장 rail 순서를 숲의 수호자 → 엘룬의 대행자로, '(기본)'을 숲의 수호자로 옮김. 사용자 예시(천벌 3회 → 나무 → 정렬 → 쇄도 3번 → 영혼 소집)와 같음.
- 단일 반복: 2부 반복 rail "엘룬의 대행자 기준"(별빛섬광 ×3 → 별빛쇄도 → 일월식 (달) …) ⇒ "숲의 수호자 기준" 천벌[위 태양섬광] → 천벌[위 달빛섬광] → 별빛쇄도[위 우주의 손길 무료] → 천벌[위 자연의 군대] → 일월식 (태양)[위 천체의 정렬] → 별빛쇄도 → 천벌 → 별빛쇄도. 근거: 반복 구간 천벌 다음 천벌 55%·별빛쇄도 18%, 별빛쇄도 다음 천벌 46%·별빛쇄도 38%, 일월식 (태양) 다음 별빛쇄도 78%, 자연의 군대 다음 일월식 39%·천체의 정렬 29%, 심크 우선순위 kotg_st. count 는 달지 않음(천벌 중앙값 2·사분위 1~3, 별빛쇄도 중앙값 1). 끼워 넣기 rail: 숲의 수호자 쪽 일월식 (태양)·천벌·야생 버섯 대신 천체의 정렬·영혼 소집(큰 구간) + 엘룬의 대행자 별빛섬광·일월식 (달)·엘룬의 분노(이름표에 영웅 특성). 숲의 수호자 영웅 탭 단일 우선순위를 심크 우선순위 kotg_st 순서(태양섬광 → 달빛섬광 → 자연의 군대 → 천체의 정렬 → 영혼 소집 → 일월식 (태양) 60 위·2충전 → 별빛쇄도 → 천벌)로 다시 짬.
