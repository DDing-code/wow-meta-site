# monk-windwalker
- 판정: 고침
- 기준 영웅 특성·기본 탭: 천신의 대변자(스조라크 상위 전체 200행 중 170행, 한국 100행 중 88행), 기본 탭 [0] 음영파 → [1] 천신의 대변자, 단일 견본 음영파 → 천신의 대변자 대표 빌드(전체 97위, 소용돌이 용의 주먹·쉬엔의 결속, 호안주 마지막 노드 없음) — 자동 결정 그대로. 글에서 맞춘 곳: 두 영웅 탭 summary·bullets[1], 2부 단일 장 bullets[2], 3부 음영파 장 concept·문단 1·4, 3부 공격대 네임드 장 문단 3, 4부 천신의 대변자 장 concept·문단 5.
- 프리풀: 넣은 것 없음. 심크 우선순위 precombat 은 장신구·변수뿐이고, Icy Veins 의 "전투 전 칼바람 사전 시전"은 심크에 없고 천신의 대변자 로그 9개 모두 0회. 로그 음수 초 시전도 없음.
- 오프닝: 순서는 로그 과반과 같아 유지, 광역 갈래만 뺌. 오프닝 장 rail 순서를 천신의 대변자 ① → ② → 음영파로 바꿈('(기본)' 표시는 원래 없음).
  - 천신의 대변자 ①: 범의 장풍 → 백호 쉬엔의 원령 → 등선 → 분노의 주먹 → 회전 학다리차기(2명+ 박자) → 해오름차기 ⇒ 범의 장풍 → 백호 쉬엔의 원령 → 등선 → 분노의 주먹 → 해오름차기. 로그 9개 모두 앞 네 칸이 같고, 첫 분노의 주먹 뒤 회전 학다리차기를 먼저 쓴 로그는 3개뿐.
  - 천신의 대변자 ②(그대로): 소용돌이 용의 주먹 → 분노의 주먹 → 회전 학다리차기 → 해오름차기 → 분노의 주먹(세 번째) → 해오름차기 → 천신합일 → 분노의 주먹. 9개 중 6개가 해오름차기 → 소용돌이 용의 주먹 → 분노의 주먹 → 회전 학다리차기 → 해오름차기, 9개 모두 천신합일 전 분노의 주먹 3회 이상, 7개는 천신합일 직전에 해오름차기(바로 앞 4개, 사이에 후려차기 하나 3개). 천신합일 11~16초. 지난 노트의 "7개는 해오름차기 바로 뒤"를 사실대로 고침. 예: https://www.warcraftlogs.com/reports/rfCPDgAVbzYanZHN#fight=112&source=950
  - 영웅 탭 opener.steps 도 같은 칸(광역 분기 회전 학다리차기)만 뺌(14 → 13단계). 쉬엔·등선·회전 학다리차기·해오름차기·천신합일 노트를 스조라크 근거로(천신합일 뒤 1초쯤 다시 눌러 내면의 단결 — 9개 중 5개).
  - count: 오프닝에서 같은 스킬을 이어 누른 것은 범의 장풍 ×2 한 로그뿐이라 달지 않음.
- 단일 반복: "반복 흐름 — 단일 (음영파 기준)" 범의 장풍(위 등선) → 분노의 주먹(위 소용돌이) → 해오름차기(위 질풍차기) → 후려차기(위 정점의 발구르기) → 범의 장풍 → 회전 학다리차기 → 후려차기 ⇒ "반복 흐름 — 단일 (천신의 대변자 기준)" 범의 장풍 → 분노의 주먹(위 등선 '쉬엔과 함께') → 회전 학다리차기(위 소용돌이 용의 주먹 '쉬엔이 10초보다 멀면') → 해오름차기 → 범의 장풍 → 후려차기 → 해오름차기(위 질풍차기). 근거: 반복 구간 분당 시전(범의 장풍 12.30·해오름차기 8.55·회전 학다리차기 7.08·후려차기 7.03·분노의 주먹 6.44·질풍차기 2.28 → 분노의 주먹 1회당 범의 장풍 1.9·해오름차기+질풍차기 1.7·회전 학다리차기 1.1·후려차기 1.1), 다음에 누른 스킬(분노의 주먹 → 범의 장풍·회전 학다리차기, 소용돌이 용의 주먹 → 회전 학다리차기, 후려차기 → 질풍차기·해오름차기, 질풍차기 → 해오름차기), 심크 우선순위 default_st 의 spinning_crane_kick(unbroken_rhythm&celestial_conduit)이 rising_sun_kick 앞. 반복 예시 Gerlox 는 "분노 → 범의 장풍 → 회전 학다리차기 → 해오름차기 → 범의 장풍 → 후려차기 → 해오름차기 → 범의 장풍 → 분노"가 그대로 나옴. 이어 누른 횟수는 모든 스킬 중앙값 1이라 count 없음.
  - 끼워 넣기 줄: 천신(백호 쉬엔의 원령 90초마다·천신합일·옥룡의 마음 1초 미만 분노의 주먹) + 음영파(츠지의 춤+박자 회전 학다리차기·호안주 선택 시 정점의 발구르기)로 다시 나눔.
  - 천신의 대변자 단일 우선순위: 순서 그대로(심크 우선순위와 맞음), 정점의 발구르기 행을 뺌(13 → 12행). 후려차기·범의 장풍 행의 "칠흑 나선" 조건(세 견본·새 견본 모두 없음)을 폭발하는 기운(새 견본)·등선 자동 발구르기 기 2로 바꿈.
- 1차 보류 '정점의 발구르기 0회' 정리: 스조라크 상위 천신의 대변자 258행 중 호안주 마지막 노드(1261849)를 고른 행 0행 → 새 단일 견본에도 없음 → 천신의 대변자 단일 rail·우선순위·오프닝에서 정점의 발구르기를 빼고, 견본 설명(buildNote)·등선 단계 노트에 "추가 사용 없음"을 적음. 음영파 쪽(레이드 견본에는 호안주 마지막 노드 있음)은 기준이 아닌 영웅 특성이라 '호안주 선택 시' 그대로 둠(참고: 스조라크 상위 음영파 42행도 0행).
- 뺀 광역기: 첫 분노의 주먹 뒤 "2명 이상 + 끊임없는 박자" 회전 학다리차기(천신의 대변자 ①·음영파 rail, 두 영웅 탭 '광역 분기' 단계), 음영파 오프닝 요약의 "광역 4세트 소비" 문장, 음영파 rail 노트의 "적이 둘 이상" 문장, 천신 오프닝 요약의 "대상 수에 따라".
