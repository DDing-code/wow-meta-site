- 판정: 일부 고침(오프닝은 횟수만, 2부 단일 반복 rail 은 산레인 기준으로 새로)

- 단일 반복: 2부 단일 장 "산레인·종말의 기수 공통"(고름{돌발} → 낫 → 스컬지{군대} → 부패{변신} → 스컬지 → 죽음의 고리{영혼 수확자} → 스컬지 → 죽음의 고리 — 흡혈의 일격은 끼워 넣기에만) → "산레인 기준"(고름{돌발} → 낫 → 스컬지{군대} → 죽음의 고리{변신} → 흡혈의 일격{부패} → 죽음의 고리{영혼 수확자} → 흡혈의 일격{역병내림} → 죽음의 고리). 근거: 산레인 반복 구간 분당 죽음의 고리 14.3·흡혈의 일격 14.0·스컬지의 일격 9.8·괴저 고리 7.2·낫 3.4·고름 3.4·부패 2.8·영혼 수확자 2.1·변신 1.3·역병내림 1.0, 고름 다음 낫 62%, 변신 다음 부패 46%, 역병내림 다음 부패 79%, 지난 rail 의 스컬지 → 부패 이웃은 5%뿐. 끼워 넣기: 흡혈의 일격(정수 만료 직전)·부패(역병내림 뒤 반환)와 종말의 기수 고유(흡혈 자리의 스컬지의 일격·기사단 군대·중간 변신). 이어서 누른 횟수는 모두 중앙값 1이라 count 없음. 영웅 탭 산레인 단일 우선순위는 순서 유지, summary 에 반복 구간 근거만.
