# evoker-augmentation
- 판정: 고침 (오프닝 예지 ×2 묶음, 시간 건너뛰기 뒤 예지 ×2·칠흑의 힘 갱신 추가, 전투 전 비늘 조건)
- 기준 영웅 특성·기본 탭: 시간 감시자, 기본 탭 [0] 그대로(자동 결정). 지원형 구조(강화 부여 흐름) 그대로 따름. 글에서 맞춘 곳: 시간 감시자 탭 요약(스조라크 200행·한국 100행 모두, 영겁 뒤 칠흑 6/10 — "현재 실제 WCL 채택률…확보한 것은 아닙니다. 이번 한국 검수…" 삭제), 비늘사령관 탭 요약(스조라크·님리사 0행), 3부 시간 감시자 장 bullets[4], 4부 비늘사령관 장 bullets[3] 의 "이번 한국 검수" 문장.
- 프리풀: 시간의 불꽃 풀링 1.5초 전 그대로(1차: Icy Veins·심크 우선순위·로그 8/10). 끓어오르는 비늘 — 새 단일 견본에 없어(대표 빌드·지금 견본 모두 미선택, Method "if talented") 순서는 두고 caption·trigger·note·오프닝 장 첫 문단을 "골랐다면"으로 바꿈.
- 오프닝: 비늘 → 시간의 불꽃 → 예지 → 예지 → 영겁의 숨결 → 칠흑의 힘 → 전세역전 → 불의 숨결 → 지각 변동 → 시간 건너뛰기 → 불의 숨결 → 지각 변동 → 분출
  → 비늘(골랐다면) → 시간의 불꽃 → 예지 ×2 → 영겁의 숨결 → 칠흑의 힘 → 전세역전 → 불의 숨결 → 지각 변동 → 시간 건너뛰기 → 예지 ×2 → 불의 숨결{위: 칠흑의 힘 끝나 가면 갱신} → 지각 변동 → 분출.
  근거: 시간 감시자 로그 10개 중 9개가 영겁의 숨결 전 예지 두 번, 8개가 시간 건너뛰기 뒤 분출 전에 예지 두 번(5개가 두 번째 불의 숨결 앞) 과 칠흑의 힘 재시전(두 번째 불의 숨결 앞 4·지각 변동 뒤 4라 rail 은 위쪽 가지, 영웅 탭은 불의 숨결 단계 note 로). Icy Veins 시간 감시자 오프닝(Time Skip → Ebon Might → Fire Breath → Prescience ×2 → Eruption)도 같음. 첫 칠흑의 힘은 6/10 이 영겁 뒤라 그대로. 예: https://www.warcraftlogs.com/reports/1a4vTXr2YJcmBFCW#fight=30&source=4
- 단일 반복: 순서 그대로 — 분출 중앙값 1(사분위 1~2), 시간의 불꽃 1(1~2)로 들쭉날쭉해 count 없음. rail note 에 스조라크 근거, 단일 요약에 "단일 네임드용" 추가.
- 뺀 광역기: 없음(단일 rail·우선순위에 광역 갈래 없음).
- 고친 글: 쿨기와 오프닝 장 · concept("같은 주문을 두 번" → "시작에 칠흑의 힘을 두 번"), 첫 문단(비늘 골랐다면), 둘째 문단(건너뛰기 뒤 예지 두 대상·칠흑의 힘 갱신), bullets[1], rail note / 첫 연습 장 · 시간 감시자 rail note / 시간 감시자 탭 summary·오프닝 summary·단계 / 비늘사령관 탭 summary / 3부·4부 영웅 특성 장 bullets 한 줄씩.
- 그대로 둔 것과 이유: 비늘사령관 오프닝·단일 rail·탭 순서(기준 영웅 특성 아님, 스조라크 로그 0개). 최상위 opener(화면에 안 나옴, 원래 기본 탭 오프닝과 달랐음). 시간 감시자 탭 요약의 Murlok·님리사·쐐기 비율 문장(이전 근거, 범위 밖 판단 아님). 피해 말고 장의 진압·끓어오르는 비늘 유틸 설명.
