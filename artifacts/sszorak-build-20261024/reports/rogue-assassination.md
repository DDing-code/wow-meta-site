- 오프닝: 변경 없음(count 도 없음). 은신 → 목조르기 → 절단 → 파열 → 절단 → 목조르기(위 소멸) → 독살 → 죽음표식 → 왕의 파멸 → 독살. 근거: 로그 11개 모두 목조르기 → 절단 → 파열, 8개가 죽음표식 전 두 번째 목조르기, 10개가 독살 → 죽음표식 → 왕의 파멸 → 독살. bd 의 "절단 ×2·×4"는 절단 한 번에 두 손 타격(1329·27576)이 같은 시각에 찍힌 것이라(다음 시전 1초 뒤) 실제로는 한 번·두 번 — 첫 절단·두 번째 절단 모두 과반이 한 번이라 횟수 표시 없음. rail 노트에 근거 수만 보탬. 예: https://www.warcraftlogs.com/reports/VjkK2JNCZBvYPTyX#fight=36&source=22
- 단일 반복: 공통 rail 순서 그대로(목조르기(위 소멸) → 절단(위 매복) → 파열 → 절단 → 독살 → 절단(위 죽음표식) → 독살(위 왕의 파멸)). 근거: 반복 구간 절단은 한 번 380묶음·두 번 367묶음 뒤 독살(절단 → 독살 21%, 독살 → 절단 59%), 소멸 뒤 목조르기 10/11 — 횟수가 갈려 count 없음. 운명결속 단일 우선순위에 무료 매복과 절단 사이 독칼(독 묻은 스틸레토를 골랐을 때 · 독살·파열 직전 보충) 행 추가: 새 견본에 독 묻은 스틸레토(262행 중 202행), 로그 분당 0.88회, 독칼 다음 독살 63%·파열 19%. 심크 우선순위는 독칼을 죽음추적자(darkest_night)에서만 생성기로 쓰므로 "쿨다운마다 넣지 않는다"를 함께 적음. 끼워 넣기 줄 독칼 칸 설명을 "죽음추적자 · …" → "독 묻은 스틸레토 · 점수 보충"(두 영웅 공통).
