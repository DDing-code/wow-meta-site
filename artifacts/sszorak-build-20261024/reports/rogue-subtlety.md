# rogue-subtlety
- 판정: 일부 고침 (순서는 그대로, 기습 ×2·광역 문장 삭제·단일 견본 관련 글)
- 기준 영웅 특성·기본 탭: 기만자(스조라크 상위 전체 199행·한국 100행 모두, 죽음추적자 0행). 기본 탭은 원래 [1] 기만자 그대로. 단일 견본 죽음추적자 → 기만자 대표 빌드(전체 2위 Parse, 치밀한 처형·기습, 어둠칼날 0/299) — 자동. 글에서 맞춘 곳: "단일 견본은 죽음추적자"를 말하던 레이드 견본 설명, 3부 기만자 장 concept·문단 1·문단 6·요점 2, 4부 죽음추적자 장 concept·문단 4, 두 영웅 탭 summary·bullets[1], 2부 단일 장 문단 1·요점 3, 오프닝 장 concept.
- 프리풀: 은신(풀링 직전) 그대로 — 1차 근거(심크 precombat stealth, Icy·Method 은신 시작) 그대로 기만자에도 맞음. Icy 의 "풀링 20초 전 어둠의 춤"은 심크·로그 창 밖이라 넣지 않음.
- 오프닝: 순서 그대로, 기습에 count 2만 담. 은신 → 그림자 일격 → 절개 → 소멸 → 그림자 일격 → 기습 → 피아귀의 이빨 → 어둠의 칼날 → 어둠의 춤 → 은밀한 기술 → 그림자 일격 → 절개 ⇒ 같은 순서, 기습 ×2. 근거: 로그 11개 모두 그림자 일격 → 절개 → 소멸, 소멸 뒤 그림자 일격 9개, 기습 7개(두 번 5개·한 번 2개), 피아귀의 이빨이 춤 전 8개, 춤 첫 소비 은밀한 기술, 은밀한 기술 뒤 첫 마무리 일격이 최후의 일격 5개. 예: https://www.warcraftlogs.com/reports/A8yxaWCNdrb1wmLh#fight=24&source=19 . 은밀한 기술 ×3·표창 폭풍 ×2 는 같은 시각에 찍힌 분신 기록(다음 시전이 1초 뒤)이라 횟수로 보지 않음.
- 단일 반복: "반복 흐름 — 단일 (두 영웅 특성 공통)" → "(기만자 기준)". 순서 그대로(기습 → 절개 → 피아귀의 이빨 → 어둠의 춤(위 칼날) → 은밀한 기술(위 그림자 일격) → 그림자 일격 → 절개 → 절개). 첫 칸 설명 "춤 밖 · 기습 또는 어둠칼날" → "춤 밖 · 점수 모으기", 일곱째 칸 "6점 이상 · 최후의 일격", 노트에 스조라크 근거. 근거: 반복 구간 다음에 누른 스킬(어둠의 춤 → 은밀한 기술, 은밀한 기술 → 그림자 일격, 그림자 일격 → 절개·최후의 일격), 심크 우선순위 finish(secret_technique(shadow_dance) → coup_de_grace). 이어 누른 횟수는 기습 중앙값 1(1번 200·2번 85·3번 이상 87), 절개 중앙값 1(1번 336·2번 239)로 들쭉날쭉해 count 없음. 기만자 단일 우선순위 순서 그대로, "기습 또는 어둠칼날" 행 이름을 기습으로.
- 뺀 광역기: 단일 오프닝의 광역 전환 문장 — 기만자 rail 노트 "광역이면 생성은 표창 폭풍 … 검은 화약", 기만자 영웅 탭 그림자 일격·절개 단계, 죽음추적자 영웅 탭 피아귀의 이빨·강화 절개 단계의 광역 문장. 단일 rail 에는 원래 광역기 없음.
- 고친 글:
  - 2부 '허수아비 첫 연습: 단일 대상' · 문단 1(기만자 단일 우선순위 요약, 죽음추적자 차이 한 줄), 요점 3, rail 이름·노트
  - 2부 '쿨기와 오프닝: 첫 춤까지…' · concept("레이드·쐐기의 기본" → "단일·레이드·쐐기의 기본"), 기만자 rail 노트
  - 영웅 탭 · 기만자 summary(스조라크 299행)·bullets[1]·단일 summary·오프닝 단계 노트, 죽음추적자 summary("단일 견본은 죽음추적자로 둡니다" → 스조라크 0/299·님리사 3/99·쐐기 1/93라 기만자로 바꿈)·bullets[1]
  - 3부 '기만자: 무형검 네 번…' · concept, 문단 1, 문단 6(근거·단일 견본 결론), 요점 2
  - 4부 '죽음추적자: 징표를 세고…' · concept, 문단 4(스조라크 0행 추가, 낡은 "10월 10일 한국 검수 레이드 1건·쐐기 1건" 삭제)
  - 레이드 견본 설명 끝 문장(코드 그대로)
- 그대로 둔 것과 이유: 죽음추적자 오프닝·단일 순서(기준 아닌 영웅 특성, 스조라크 로그 0개), 표창 폭풍(광역기라 단일 순서에 넣지 않음 — 아래 보류), 쐐기 견본 설명("죽음추적자 견본에서 바꿨습니다"는 쐐기 견본 이력이라 guard 상 못 고침, 틀린 말도 아님), 3부 쐐기 장·공격대 네임드 장의 영웅 특성별 설명(선택이 아니라 운용 설명).
