# rogue-outlaw
- 판정: 일부 고침 (순서 그대로, 광역 갈래·질풍 칼날 삭제, 사악한 일격 ×2, 근거 문장)
- 기준 영웅 특성·기본 탭: 기만자(스조라크 상위 전체 74행 중 73행, 한국 6행 모두), 기본 탭 [0] 기만자 그대로. 단일 견본은 기만자 그대로, 고요한 장막 → 어둠질주인 대표 빌드(전체 4위 Tomelvis)로 — 자동. 레이드 견본 "같은 견본" 설명 자동 수정. 글에서 맞춘 곳: 두 영웅 탭 summary·bullets[1], 3부 기만자 장 concept·문단 4·요점 2, 4부 운명결속 장 문단 4, 2부 단일 장 요점 3.
- 프리풀: 은신·아드레날린 촉진·난도질·뼈주사위 그대로(1차 근거: 심크 precombat stealth·adrenaline_rush·slice_and_dice·roll_the_bones, Icy "AR, RtB, SnD immediately before the pull"). 로그에서 아드레날린 촉진은 0.1~0.9초(전투 시작 직후), 난도질을 전투 시작 뒤 손으로 켠 로그는 11개 중 4개 — 노트에 "이미 켜져 있으면 건너뜀"과 함께 적음.
- 오프닝: 순서 그대로. 기만자: 은신 → 아드레날린 촉진 → 난도질 → 뼈주사위 → 도박의 연속 → 폭풍의 칼날(2명+) → 질풍 칼날 → 사악한 일격 → 미간 적중 → 광기의 학살자 → 마음가짐 → 아드레날린 촉진 → 광기의 학살자 ⇒ 폭풍의 칼날·질풍 칼날 칸을 빼고 사악한 일격에 ×2. 근거(로그 11개): 아드레날린 촉진 → 뼈주사위로 시작 7개, 초반 도박의 연속 9~10개, 첫 미간 적중 → 광기의 학살자 10개, 첫 미간 적중 전 사악한 일격 6개(두 번 5개·세 번 1개, 나머지 5개는 촉진 연마 점수로 바로 미간 적중), 두 번째 아드레날린 촉진 → 광기의 학살자 13~17초 9개, 폭풍의 칼날·질풍 칼날 0개. 예: https://www.warcraftlogs.com/reports/CJYmKbRDB9a7rA3M#fight=29&source=38 . 운명결속 줄·탭은 폭풍의 칼날 칸만 뺌. bd 의 "권총 사격 ×3"은 한 번 눌렀을 때 탄환이 함께 찍힌 기록(다음 시전 0.8초 뒤)이라 횟수로 보지 않음.
- 단일 반복: 공통 rail·기만자 단일 우선순위 순서 그대로. 노트·요약에 스조라크 근거(사악한 일격 뒤 속결·미간 적중, 속결 뒤 권총 사격·사악한 일격, 아드레날린 촉진 뒤 광기의 학살자 54%). 이어 누른 횟수: 사악한 일격 중앙값 1(1~2), 미간 적중 1(1~2), 속결 1 — 들쭉날쭉해 count 없음. 질풍 칼날 행은 "골랐다면" 그대로 두고 "단일 견본에는 없음(79행 중 13행)"을 적음. 2부 단일 장 문단 1·3부 기만자 장 요점 2의 우선순위 요약에 "질풍 칼날(골랐다면)".
- 뺀 광역기: 폭풍의 칼날 "적 2명 이상일 때만"(두 영웅 특성 오프닝 rail·영웅 탭 단계), 오프닝 장 문단 2의 "적이 둘 이상 모였다면 폭풍의 칼날 … 날렵한 몸놀림" 문장, 기만자 rail 노트의 "단일·광역 우선순위"를 "단일 우선순위"로.
