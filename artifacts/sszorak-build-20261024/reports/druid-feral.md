# druid-feral
- 판정: 고침
- 기준 영웅 특성·기본 탭: 야생추적자, 기본 탭 [0] 발톱의 드루이드 → [1] 야생추적자 (자동 결정 그대로. 스조라크 신화 12.1.5 상위 전 지역 200행 중 187행, 한국 17행 중 16행). 단일 견본은 스조라크 대표 빌드(야생추적자, 전체 9위)로 자동 교체, buildNote 로 영혼 소집·달 바라기·집중된 광란 선택을 적음. 글에서 맞춘 곳: 오프닝 장 rail 순서·'(기본 · 영혼 소집)' 이름표, 2부 단일 장 우선순위 요약(야생추적자 기준 + 발톱의 드루이드 추가분), 3부 공격대 네임드 장·4부 야생추적자 장(스조라크 근거·단일 기준·처음 열리는 탭), 두 영웅 탭 summary(낡은 "이번 한국 검수: 레이드 1건·쐐기 0건 / 레이드 0건·쐐기 1건" → 스조라크·님리사·쐐기 상위 행 수).
- 프리풀: 숨기 '전투 전' 그대로(심크 우선순위 precombat prowl, Icy Veins "Cast Prowl before combat starts", Method "Prowl"). 호랑이의 분노는 첫 갈퀴 발톱 직전 그대로(로그 9/10 이 0.4~1.1초, Method "Tiger's Fury (pre-pull)").
- 오프닝: 숨기 → 호랑이의 분노 → 갈퀴 발톱 → 광폭화 → 야성의 광기 → 도려내기[위 달빛섬광 "달 바라기 · 그 앞에"] → 흉포한 이빨 → 영혼 소집 → 흉포한 이빨 ⇒ … → 야성의 광기 → 도려내기 → 달빛섬광(칸) → 흉포한 이빨 → 영혼 소집 → 흉포한 이빨. 영웅 탭은 야성의 광기 → 달빛섬광 → 도려내기(로그 0개 순서)를 도려내기 → 달빛섬광으로 바로잡음. 근거: 로그 10개 중 8개가 오프닝에 달빛섬광(새 견본 달 바라기 198/203행이라 위쪽 가지 → 칸) — 갈퀴 발톱 바로 뒤 5개(이때 야성의 광기는 도려내기 뒤), 도려내기 뒤 3개로 정확히 갈려 과반 순서가 없음 → 심크 우선순위(feral_frenzy → rip → builder moonfire_cat)·Icy Veins(Berserk → Feral Frenzy → Rip → Convoke)·Method("Lunar Inspiration … use it after you Rip … Bite … before Convoke")가 같은 도려내기 뒤를 따름. 영혼 소집 직전 흉포한 이빨 8/10, 영혼 소집 뒤 흉포한 이빨 8/10. 예: https://www.warcraftlogs.com/reports/DBHcPxdmYFTCtywJ#fight=26&source=33 . 같은 스킬 이어 누르기는 흉포한 이빨 ×2 가 1개 기록뿐이라 count 없음. 호랑이의 분노 캡션 "식재 덩굴 조건도"(식재 27/203행) → "첫 갈퀴 발톱 직전".
- 단일 반복: "두 영웅 특성 공통"(갈퀴 발톱 → 칼날 발톱(기습 공격이면 먼저) → 칼날 발톱 → 도려내기 → 칼날 발톱 ×2 → 흉포한 이빨 → 칼날 발톱) ⇒ "야생추적자 기준" 갈퀴 발톱[위 호랑이의 분노] → 칼날 발톱[위 달빛섬광] → 흉포한 이빨[위 무료 이빨] → 칼날 발톱[위 야성의 광기] → 도려내기 → 칼날 발톱[위 광폭화] → 흉포한 이빨 → 칼날 발톱[위 영혼 소집]. 근거: 반복 구간 흉포한 이빨 다음 칼날 발톱 52%, 칼날 발톱 다음 칼날 발톱·흉포한 이빨 31%씩, 도려내기 다음 칼날 발톱 39%, 갈퀴 발톱 다음 칼날 발톱 50%, 분당 칼날 발톱 20.1·흉포한 이빨 12.4·갈퀴 발톱 5.0·달빛섬광 4.6. 기습 공격 칼날 발톱 우선은 심크 우선순위에서 발톱의 드루이드 전용(shred,if=buff.sudden_ambush.up&hero_tree.druid_of_the_claw)이라 끼워 넣기 rail 의 발톱 칸으로 옮김. count 없음(칼날 발톱 중앙값 1·사분위 1~2). 끼워 넣기에서 식재 호랑이의 분노 칸은 뺌. 야생추적자 탭 단일 우선순위는 심크 우선순위와 같아 순서 그대로, 달빛섬광 행만 "달 바라기 선택 시" → "없음 / 팬데믹".
- 뺀 광역기: 발톱의 드루이드 영웅 탭 오프닝 요약의 "광역의 첫 전투 중 호랑이의 분노 조건" 문장. 단일 오프닝·반복에 광역기 칸은 원래 없음.
- 고친 글: 2부 "허수아비 첫 연습" 장(우선순위 요약 문단, 손 순서 문단의 기습 공격 문장 → 달빛섬광 + 스조라크 근거, 실수 1개), 2부 "쿨기와 오프닝" 장(달빛섬광 위치 문장), 3부 "공격대 네임드" 장(스조라크 187/200행·처음 열리는 탭), 4부 "야생추적자" 장 한 줄 원리(단일 네임드 기준), 두 영웅 탭 summary·오프닝 요약·단일 요약.
- 그대로 둔 것과 이유: 발톱의 드루이드 오프닝·단일 우선순위(기준 영웅 특성이 아니고 광역 갈래 없음). 영웅 탭 bullets(형식 그대로 맞음 — 발톱 1번 bullet 의 광역 첫 교전 설명은 영웅 특성 카드 설명이라 둠). 3부 발톱의 드루이드 장(이미 "레이드·적은 대상 수는 야생추적자, 쐐기는 발톱의 드루이드"). 재생은 포식자의 신속함 즉시 치유라 넣지 않음(1차 판단 그대로).
