# paladin-retribution
- 판정: 일부 고침(순서는 그대로, 오프닝 횟수 합치기·광역 갈래 삭제·근거 문장)
- 기준 영웅 특성·기본 탭: 태양의 사자(스조라크 상위 전 지역 200행 중 193행, 한국 100행 중 97행), 기본 탭 [0] 그대로(자동 결정). 글에서 맞춘 곳: 태양의 사자 탭 요약(단일 네임드 기준·스조라크 근거), 기사단 탭 요약(스조라크 200행 중 7행), 3부 태양의 사자 장 마지막 문단에 스조라크 근거 한 문장.
- 프리풀: 추가 없음(1차와 같음). 심크 우선순위 precombat 은 준비 항목뿐, Icy Veins·Method 모두 심판의 칼날로 시작, 로그 음수 초 시전 0/9.
- 오프닝: (전) 심판의 칼날 → 응징의 격노 → 사형 선고 → 파멸의 재 → 최후의 선고 → 최후의 선고 → 천상의 종 / (후) 심판의 칼날 → 응징의 격노 → 사형 선고 → 파멸의 재 → 최후의 선고 ×2 → 천상의 종(2부 줄·영웅 탭 같게). 근거: 9개 중 7개가 심판의 칼날로 시작, 6개가 응징의 격노 → 사형 선고 → 파멸의 재, 파멸의 재 뒤 최후의 선고 두 번 6개·세 번 2개, 그사이 4세트 천상의 폭풍 3개. 성전의 강타(자동 공격)를 빼고 센 값. 예: https://www.warcraftlogs.com/reports/m29DbtXLyBF3qGcM#fight=24&source=1
- 단일 반복: 줄 순서 그대로(심판의 칼날 → 파멸의 재 → 최후의 선고 → 천상의 종 → 최후의 선고 → 심판 → 심판의 칼날 → 최후의 선고, 위 가지 응징의 격노·사형 선고·천상의 폭풍·천벌의 망치). 근거 문장만 추가: 생성기 하나 뒤 최후의 선고 하나 교대, 날개 중 천벌의 망치와 최후의 선고 교대(최후의 선고를 이어 쓴 묶음 940개 중 54개라 count 없음). 단일 우선순위 그대로.
- 뺀 광역기: 단일 오프닝의 "2대상 이상이면 천상의 폭풍" 갈래 — 2부 오프닝 줄 캡션("단일 기본 · 광역은 폭풍")·줄 근거 문장·본문 둘째 문단, 태양의 사자 영웅 탭 오프닝 6단계 메모, 확인 문제("첫 최후의 선고를 광역이라 폭풍으로")를 단일 문제(파멸의 재 뒤 최후의 선고 몇 번)로 바꿈. 기사단 줄 마지막 캡션의 "광역은 폭풍"도 "후속 자원 소비"로(순서는 그대로).
- 고친 글: 2부 "허수아비 첫 연습" 반복 줄 근거 / 2부 "쿨기와 오프닝" 본문 1·2문단, 확인 문제 1개, 두 줄 캡션·태양의 사자 줄 근거 / 3부 "태양의 사자" 마지막 문단 / 태양의 사자 탭 요약·오프닝 5단계(두 칸 → 한 칸 ×2) / 기사단 탭 요약("12.1.5 적용 전 한국 검수: 레이드 0건·쐐기 0건" 삭제, 행 수로).
- 그대로 둔 것과 이유: 기사단 오프닝 단계(검사기가 4·5단계 파멸의 재 → 빛의 망치를 고정, 기준 아닌 영웅 특성), 광역 장·광역 탭, 3부 공격대 네임드 장의 님리사 횟수 사례(단일 순서 문장 아님), 4부 기사단 장. 영웅 탭 요점(bullets)은 1차 내용과 어긋나지 않아 그대로.
