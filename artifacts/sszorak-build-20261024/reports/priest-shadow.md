# priest-shadow
- 판정: 고침
- 기준 영웅 특성·기본 탭: 공허술사(자동 결정 그대로, 기본 탭 집정관 → 공허술사, 단일 견본 집정관 → 스조라크 대표 공허술사 빌드). 근거 행 수: 스조라크 신화 상위 199행 중 154행(한국 99행 중 74행).
  - 글에서 맞춘 곳: 2부 단일 장(concept·첫 문단·요점 1·확인 문제), 2부 오프닝 장(concept·둘째 문단·확인 문제), 3부 집정관 장(제목·concept·요점 2·3), 3부 쐐기 장 셋째 문단, 4부 공허술사 장(제목·concept·셋째 문단), 영웅 탭 두 개의 summary·bullets[0~1], 공허술사 오프닝·단일 탭 summary.
  - 장 제목: 3부 "레이드는 집정관: …" → "쫄이 섞이는 레이드·쐐기는 집정관: …"(님리사 신화 상위 100행 중 99행, 쐐기 상위 32행 중 24행 집정관), 4부 "쐐기는 공허술사: …" → "단일 네임드는 공허술사: …"(스조라크 199행 중 154행). 장 위치·순서는 그대로.
- 프리풀: 정신 분열 '풀링 직전' 그대로. 근거: 심크 우선순위 precombat `mind_blast,if=set_bonus.mid2_4pc`, Icy Veins "Pre-Cast Mind Blast", Method 공허술사 4세트 오프닝 첫 단계 Mind Blast, 공허술사 로그 10개 중 9개가 0.1~0.6초에 적중.
- 오프닝: 순서는 로그 과반과 같아 그대로 두고 횟수만 달았습니다. 정신 분열 → 촉수 격돌 → 고통 → 공허 연사 → 공허의 형상 → 마력 주입 → 공허의 격류 → 공허의 폭발 ×2 → 광기.
  - 근거(공허술사 로그 10개): 첫 정신 분열 9/10, 격돌 → 고통 7/10, 형상 전 공허 연사 10/10, 광기보다 격류 먼저 7/10, 균열 안 공허의 폭발 두 번 연속 6/10(나머지 4개는 한 번 쓰고 다른 스킬 뒤 다시). Method 공허술사 4세트 오프닝도 격류 → 공허의 폭발 → 공허의 폭발. 예: https://www.warcraftlogs.com/reports/CRBwpKLmyrFnA6QG#fight=29&source=7
  - 2부 오프닝 장: 공허술사 rail 을 맨 앞으로 옮기고 이름표를 '오프닝 — 공허술사 (기본)'으로, 공허의 폭발 칸에 count 2. 집정관 rail 은 그대로(두 번째로).
  - 공허술사 영웅 탭: 격류 다음에 공허의 폭발 ×2 단계를 새로 넣었습니다(전에는 격류 설명 속에만 있었음). 격류 단계 설명에서 폭발 문장을 뺐습니다. 검사기의 오프닝 단계 수 제한은 없어서(Shadow 는 6단계 이상만) 막히지 않았습니다.
  - 마력 주입은 로그에 같은 초에 두 번 찍히지만(18개 전부) 2분 쿨다운이라 한 번 누른 것입니다. 새 견본에 태양 여사제의 쌍둥이가 있어 자신에게도 걸린 기록으로 보고 count 를 달지 않았고, rail note 에 적었습니다.
- 단일 반복: '반복 흐름 — 단일 (두 영웅 공통)' 촉수 격돌 → 공허 연사 → 광기 → 정신의 채찍 → 정신 분열 → 광기 → 정신의 채찍 ⇒ '반복 흐름 — 단일 (공허술사 기준)' 공허의 격류 → 공허의 폭발 → 광기{위 형상} → 공허의 폭발 → 촉수 격돌{위 고통} → 공허 연사 → 광기 → 정신 분열 → 정신의 채찍{위 죽음 '처형·보호막이면'}.
  - 근거: 공허술사 10개 반복 구간(풀 25초 뒤, 사잇단계 제외, 원혼 자동·생존기 제외) 격류 87번 중 바로 다음 공허의 폭발 48·광기 21, 격류 뒤 12초 안 폭발 2~3번 77/87·광기 1~2번 75/87, 촉수 격돌 다음 공허 연사 48%, 공허 연사 다음 광기 27%, 정신 분열 다음 채찍 29%, 흡혈의 손길 직접 시전 0회. 이어서 누른 횟수 중앙값이 모두 1이라 반복 줄에는 count 없음.
  - 끼워 넣기 줄: '영웅 특성별로 끼워 넣는 것'(집정관 3·공허술사 3) ⇒ '집정관이면 끼워 넣는 것' 후광 → 정신의 채찍: 광기 → 공허 연사(형상 끝나기 전). 공허술사 것(격류·폭발·보호막 죽음)은 반복 줄로 옮겼습니다.
  - 공허술사 영웅 탭 단일 우선순위: 줄 순서는 심크 우선순위 main·Method 공허술사 우선순위와 같아 그대로. 흡혈의 손길 줄 설명만 "촉수 격돌이 걸어 주니 충전이 없을 때만 직접, 기록 10개 직접 시전 0회"로 고쳤습니다.
- 뺀 광역기: 없음(단일 줄·단일 오프닝에 광역 갈래가 없었음).

- 그대로 둔 것과 이유: 집정관 오프닝 rail·영웅 탭 오프닝·단일 우선순위(기준 영웅 특성이 아니고 1차 대조 결과 유지), 광역 장·광역 탭, 공격대 장(님리사 형상·후광 횟수 문장은 순서 근거가 아님), 2부 단일 장 제목(':' 뒤 "지속 피해 → 광기 → 생성기"는 개념 순서라 공허술사에도 맞음).
