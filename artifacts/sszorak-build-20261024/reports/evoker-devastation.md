- 기준 영웅 특성·기본 탭: 비늘사령관, 기본 탭 [0] 그대로(자동 결정과 같음). 스조라크 상위 전 지역 199행 중 159행·한국 21행 모두 비늘사령관. 단일 견본은 스조라크 대표 빌드(전체 7위)로 자동 교체(레이드 견본 설명도 자동으로 "지난 단일 견본과 같은 코드"로 바뀜). 글에서 맞춘 곳: 비늘사령관 영웅 탭 summary(스조라크 근거·단일 네임드 기준, 님리사 100행·쐐기 34행 중 31행), 요점 1번, 오프닝·단일 탭 summary, 3부 "비늘사령관:" 장 P0, 4부 "불꽃형성자:" 장 P0.
- 프리풀: 부양 ×2(풀링 약 3초 전) 추가 — 조건 특성 Slipstream(441257)이 새 단일 견본과 상위 180행 모두에 있음(지난 단일·쐐기·레이드 견본에도 있음). 심크 우선순위 precombat `hover,if=talent.slipstream` 2줄 + Method 비늘사령관 오프닝 "Precast 2x Hover". 로그는 풀 전 시전이 남지 않아 확인 불가. 특성이 KB 에 없어 글에는 이름 없이 "단일 견본에 든 비늘사령관 특성이 조건"으로 씀. 살아있는 불꽃 풀링 약 2초 전은 그대로.
- 오프닝: 살아있는 불꽃 → 깊은 숨결 → 용의 분노 → 전세역전 → 불의 숨결 → 영원의 쇄도 → 파열 → 깊은 숨결 → 영원의 쇄도 → 불의 숨결 → 파열 ⇒ 부양 ×2 → 살아있는 불꽃 → 깊은 숨결 → 용의 분노 → 전세역전 → 불의 숨결 → 영원의 쇄도 → 파열 ×3~5 → 살아있는 불꽃 → 파열 → 깊은 숨결 → 영원의 쇄도 → 불의 숨결 → 파열 ×3~5 (2부 rail·영웅 탭 단계 모두). 근거: 강화 주문 두 개 뒤 파열 연속 5·4·4·4·3·5·5·4·2·3 → 3~5가 11개 중 9개(부양은 이동기라 세지 않음), 그 뒤 살아있는 불꽃 11개 중 10개, 두 번째 강화 주문 뒤 파열 3~5가 11개 중 8개. 예: https://www.warcraftlogs.com/reports/jpMK7W6vtqzNmYCr#fight=40&source=71
  - 불꽃형성자(다른 영웅 특성): 순서 그대로, 첫 불의 숨결 뒤 파열에 ×3(1차 자료 로그 8개 모두 3번), "두세 번" 문장을 "세 번"으로.
