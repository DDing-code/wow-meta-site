# demonhunter-havoc
- 판정: 고침
- 기준 영웅 특성·기본 탭: 알드라치 파괴자(스조라크 상위 전 지역 200행 중 185행, 한국 100행 중 86행), 기본 탭 [0] 지옥상흔 → [1] 알드라치 파괴자(자동 결정 그대로). 글에서 맞춘 곳: 2부 오프닝 장 줄 순서·이름표 "(기본)"·본문 첫 문단, 2부 단일 장 한 줄 원리·본문, 두 영웅 탭 요약·요점(선택 기준), 3부 공격대 네임드 장 단일 순서 문장, 4부 알드라치 장 단일 요점·확인 문제.
- 프리풀: 제물의 오라 풀링 1초 전 그대로(심크 우선순위 precombat `immolation_aura`, Icy Veins "1 second before the pull", Method 알드라치 "1 second before pull"). 알드라치 영웅 탭 단계를 phase '전투 전'·trigger '풀링 1초 전'으로, 2부 줄 캡션을 '풀링 1초 전'으로 바꿈. 로그 풀 전 시전은 0/9(로그 창 밖).
- 오프닝:
  - 2부 오프닝 장 알드라치 줄: 순서 그대로(제물의 오라 → 사냥 → 파괴자의 글레이브 → 안광 → 정수 파쇄 → 죽음의 휩쓸기 → 파멸 → 죽음의 휩쓸기 / 복수의 퇴각 → 탈태 → 죽음의 휩쓸기 → 안광). 맨 앞으로 옮기고 근거 문장에서 광역 갈래("두 대상 이상이면 파멸 먼저")를 뺌.
  - 알드라치 영웅 탭 오프닝: 광역 순서(… 안광 → 파멸 → 정수 파쇄 → 죽음의 휩쓸기 ×2 …) → 단일 순서(제물의 오라 → 사냥 → 파괴자의 글레이브 → 안광 → 정수 파쇄 → 죽음의 휩쓸기 → 파멸 → 죽음의 휩쓸기 → 복수의 퇴각 → 탈태 → 죽음의 휩쓸기 → 안광). 근거: 9개 중 8개가 사냥 → 글레이브 → 안광(Mortex만 안광 먼저), 9개 모두 정수 파쇄 뒤 휩쓸기 → 파멸 → 휩쓸기(Hawkerton은 사이에 복수의 퇴각), 9개 모두 탈태 바로 뒤 휩쓸기. 심크 우선순위 `annihilation,if=buff.rending_strike.up&buff.glaive_flurry.down`(칼춤 계열 먼저), Icy Veins 단일 오프닝도 같은 순서. 예: https://www.warcraftlogs.com/reports/z2Wc7PNJAMDZ1KkC#fight=44&source=33
  - count: 달지 않음. 로그의 사냥 ×2·지옥칼 ×2는 한 번 누를 때 시전 기록이 두 줄 남는 것(반복 구간 지옥칼 175묶음 중 171개가 2, 사냥 32묶음 중 25개가 2)이라 반복 횟수가 아니다. 두 번째 안광 뒤 파멸은 5개가 3번, 4개가 1번(지옥칼·글레이브가 끼어듦)이라 줄에 넣지 않고 note에만 적음.
- 단일 반복: 두 영웅 특성 공통(안광 → 휩쓸기 → 파멸 → 휩쓸기 → 칼춤 → 혼돈의 일격 → 지옥칼 → 혼돈의 일격, 지옥상흔 로그 기준) → 알드라치 파괴자 기준(안광 → 파괴자의 글레이브 → 죽음의 휩쓸기 → 파멸 → 죽음의 휩쓸기 → 파멸 → 지옥칼 → 파괴자의 글레이브 → 칼춤 → 혼돈의 일격, 위 가지 사냥·정수 파쇄·탈태·제물의 오라·복수의 퇴각). 근거: 반복 구간(25초 뒤, 사잇단계 제외) 글레이브 뒤 칼춤 계열을 먼저 쓴 경우 306번 중 196번, 분당 글레이브 8.8·안광 2.9·지옥칼 9.5·복수의 퇴각 2.5, 안광 사이 구간 실제 예(안광 → 글레이브 → 휩쓸기 → 파멸 → 휩쓸기 → 파멸… → 지옥칼 → 글레이브 → 칼춤 → 혼돈의 일격)가 Grape·Mortex·킷사·Akchung에서 반복. 심크 우선순위 reavers_glaive(두 강화 없을 때) → annihilation(전투검 소비 뒤). count는 파멸 중앙값 1(1~2)·휩쓸기 1이라 달지 않음. 끼워 넣기 줄은 "지옥상흔이면 끼워 넣는 것"(심연의 응시·집어삼키는 불길)으로 바꾸고 지옥상흔 반복 순서를 note로 옮김. 알드라치 영웅 탭 단일 우선순위는 순서 그대로, 요약과 글레이브 메모만 단일 기준으로.
- 뺀 광역기: 단일 오프닝·반복에 광역 전용 버튼은 없었음. 대신 알드라치 영웅 탭 오프닝의 광역 순서(파멸 먼저)와 2부 오프닝 장의 "두 대상 이상이면 파멸 먼저" 문장 2곳을 뺌(광역 장·광역 탭은 그대로).
- 고친 글: 2부 "허수아비 첫 연습: 단일 대상" 한 줄 원리·본문 3문단·요점·실수 / 2부 "쿨기와 오프닝" 본문(알드라치 두 문단을 앞에 새로 쓰고 지옥상흔 두 문단은 뒤로)·확인 문제(알드라치 1문항 추가) / 3부 "공격대 네임드" 단일 순서 문장 / 4부 "알드라치 파괴자" 순수 단일 요점·확인 문제 답 / 알드라치 탭 요약·요점 1·2번·오프닝 제목·요약·단계 메모·단일 요약 / 지옥상흔 탭 요약(단일은 알드라치 탭 기준)·요점 1번(사냥으로 첫 안광 강화 — 1차에 고친 오프닝과 어긋나던 "사냥 강화는 심연의 응시에" 문장)·2번.
- 그대로 둔 것과 이유: 지옥상흔 오프닝·단일 우선순위(기준 아닌 영웅 특성, 1차 판정 유지), 광역 장·광역 탭, 쐐기 견본, 4부 알드라치 장 그림(두 순서 모두 설명), 최상위 opener(화면에 안 나오고 지난 판도 기본 탭 오프닝과 달라 자동 맞춤 대상이 아님).
