Although both trees are listed as "best" choices, in practice you will want to play both Hero Talents in all types of PvE content depending on the specific damage profile you need. In general,  Templar is better at short window burst damage on both single target and AoE, as well as having stronger defensives.  Herald of the Sun has better sustained cleave and AoE damage, and has stronger burst over longer windows. For Mythic+, this means that  Templar is stronger when you are fighting enemies that die very quickly or when you need extra survivability to live oneshots, and  Herald of the Sun is stronger for longer pulls.

For more specific recommended builds for each Raid encounter, see the guide below.


Retribution Paladin Raid Guide
BEST RETRIBUTION PALADIN RAID TALENT BUILD
The Raid build simply takes all of the single target options available in the tree. For situations where additional enemies will be present, the Mythic+ build can be used instead, as the difference in single target damage is extremely minimal.
Templar
Herald of the Sun
This is the standard single target build. It takes all the default single target choices, and will have strong 1 minute burst windows. Because of the tier set bonus,  빛의 수호자의 폭풍우 is a talent that becomes worth using on single target as well. For more passive cleave,  천상의 강권 and  촉진된 기원 can be taken instead.

BEST RETRIBUTION PALADIN MYTHIC+ TALENT BUILD
The Mythic+ build is very similar to the raid build for damage talents, just swapping the least impactful talents to more valuable AoE options. The build recommended here takes all regularly used utility abilities you should need, but feel free to swap them around in the class tree if you want alternative options.
Templar
Herald of the Sun
To improve AoE damage, this build takes  빛의 수호자의 폭풍우,  복수의 칼날, and  축복받은 용사 instead of two points in  성전사의 심장 and  정의의 심판. If further AoE damage is required,  신성화 can be taken over  심판권.  찬란한 영광 is also a reasonable option instead of  사형 선고, to reduce the number of active abilities and minimize cooldown descync.

BEST RETRIBUTION PALADIN DELVE TALENT BUILD
The Delve build recommended here is based around frequent, short duration encounters, so the talents are quite different to the regular builds. If you want to use a more familiar build across all content types, or are doing higher level Delves with a longer average fight duration, the regular Mythic+ build is a fine alternative option to use.
Templar
This build will allow you to use most major cooldowns every 30s instead of 60s, which makes it a lot easier to burst down higher health enemies more often.
