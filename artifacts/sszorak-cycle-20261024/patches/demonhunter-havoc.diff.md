### 지옥상흔.opener — 지옥상흔 첫 전투 흐름
- summary: 영원한 사냥 마지막 노드·혼돈의 변신 기준입니다. 사냥으로 붙어 첫 안광을 강화하고, 정수 파쇄 뒤 죽음의 휩쓸기 → 파멸 → 죽음의 휩쓸기로 짧은 형상을 씁니다. 오라 준비는 내면의 화염·격렬한 변신, 강화 주문은 악마의 격화 선택 시 적용합니다. 소비기 수는 실제 격노와 남은 정수 파쇄 시간에 맞춥니다.
  1. 제물의 오라(258920) — 오라를 사용하는 빌드라면 충전을 준비합니다. 내면의 화염·격렬한 변신을 선택했다면 탈태 전에 사용할 충전까지 계획합니다. / 풀 직전 준비
  2. 사냥(370965) — 사냥으로 붙어 그 강화를 첫 안광에 씁니다. 스조라크 신화 상위 로그 10개 중 8개가 이렇게 열었습니다. 실제 대상과 돌진 경로를 확인합니다. / 풀링·대상 지정
  3. 지옥칼(232893) — 근접 위치와 격노를 맞춥니다. 격노 15 생성만으로 안광 비용이 항상 충족되지는 않으므로 실제 자원을 확인합니다. / 사냥 뒤 격노 보충
  4. 안광(198013) — 사냥으로 강화된 첫 안광입니다. 끝까지 정신 집중해 영원한 사냥 마지막 노드의 다음 칼춤 초기화 보상을 얻습니다. / 격노 30 이상
  5. 정수 파쇄(258860) — 4세트면 6초, 없으면 4초입니다. 뒤에 들어갈 소비기와 자원을 먼저 확인하고 사용합니다. / 안광 완주 직후
  6. 죽음의 휩쓸기(210152) — 첫 사용의 악마쇄도와 영원한 사냥의 쿨다운 초기화를 함께 회수합니다. / 완주 보상 보유
  7. 파멸(201427) — 짧은 형상의 파멸 첫 악마쇄도를 두 죽음의 휩쓸기 사이에 소비합니다. 상위 로그 10개 중 6개가 이 자리였습니다. / 첫 보상 미소비
  8. 죽음의 휩쓸기(210152) — 초기화된 두 번째 사용입니다. 자원이 모자라면 입력만 반복하지 말고 실제 수급을 확인합니다. / 초기화·격노 확인
  9. 복수의 퇴각(198793) — 선택한 자주성·전략적 후퇴·갈무리한 기운을 활용합니다. 위험한 위치라면 억지로 사용하지 않습니다. / 뒤쪽 안전 확보
  10. 탈태(191427) — 안광·칼춤 계열과 기존 첫 보상을 사용한 뒤 새 구간을 엽니다. 퇴각 후 착지 위치도 안전하게 잡습니다. / 초기화할 주문 소모
  11. 죽음의 휩쓸기(210152) — 직접 탈태가 초기화한 소비기를 사용하고 새 악마쇄도 첫 사용을 확인합니다. / 탈태 초기화
  12. 파멸(201427) — 새 형상의 파멸 보상을 회수합니다. 다음 안광 비용과 소비기 자원을 함께 살핍니다. / 격노와 발동 확인
  13. 집어삼키는 불길(456640) — 초기화된 오라 자리를 사용합니다. 오라 특성이 없는 구성에 충전 소모를 억지로 추가하지 않습니다. / 악마의 격화 선택
  14. 심연의 응시(452497) — 직접 탈태 동안 안광 자리에 나오는 강화판입니다. 끝까지 정신 집중합니다. 일반 안광과 별개의 공짜 시전은 아닙니다. / 강화·전방 적중
  15. 파멸(201427) — 상위 로그 10개 모두 심연의 응시 뒤 파멸을 한두 번 먼저 썼습니다. / 심연의 응시 완주
  16. 죽음의 휩쓸기(210152) — 완주 후 다시 연속 사용할 기회를 확인합니다. 이후 남은 자원과 쿨다운에 따른 우선순위로 돌아갑니다. / 새 완주 보상
### 지옥상흔.singleTarget — 지옥상흔 단일 조건

  6. 파멸(201427) — 첫 악마쇄도, 정수 파쇄, 알드라치 강화 소비 조건을 먼저 확인합니다. 다음 죽음의 휩쓸기에 필요한 격노를 전부 써 버리지 않습니다.
  7. 집어삼키는 불길(456640) — 악마의 격화를 골랐다면 직접 탈태 동안 제물의 오라 자리에 나옵니다. 새 형상의 죽음의 휩쓸기·파멸 다음, 심연의 응시 앞에 씁니다(스조라크 상위 로그 10개 중 7개).
