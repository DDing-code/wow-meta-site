# druid-balance
- 판정: 고침
- 프리풀: 첫 천벌을 전투 전·'풀링 4초 전'으로 표기(두 영웅 rail·영웅 탭) — 근거: 심크 우선순위 precombat wrath ×2(+dream_surge 면 ×3), Icy Veins "At approximately 4-seconds on the pull timer, precast two Wrath", Method "Start pressing Wrath at 3-4 seconds", 로그 엘룬의 대행자 3/6·숲의 수호자 9/10 이 0~1초에 천벌 적중(엘룬의 대행자 2/6 은 별빛섬광 사전 시전 — 심크 precombat starfire,if=hero_tree.elunes_chosen 과 같으나 공개 가이드와 갈려 노드로 넣지 않음).
- 오프닝(풀링 뒤):
  - 엘룬의 대행자: … 화신/일월식 (달) → 별빛섬광(구간 첫 즉시 시전) → 별빛쇄도 … ⇒ … 화신/일월식 (달) → 별빛쇄도 → 별똥별(광역) → 영혼 소집(골랐을 때) → 별빛섬광(즉시 시전부터) → 별빛쇄도. 근거: 6개 중 5개가 화신 바로 뒤 별빛쇄도. 예: https://www.warcraftlogs.com/reports/t8C9BWZPhKHm4TNV#fight=74&source=1600 . 오프닝 장 셋째 문단·rail note·영웅 탭 요약 맞춤.
  - 숲의 수호자: 천벌 → 달빛섬광 → 태양섬광 → 일월식 (태양) → 천벌 → 자연의 군대 → 화신 → 천벌 → 별빛쇄도 ⇒ 천벌(풀링 4초 전) → 태양섬광 → 자연의 군대 → 천체의 정렬 → 별빛쇄도 → 영혼 소집 → 별빛쇄도 → 천벌. 근거: 10개 모두 천체의 정렬(194223)·영혼 소집 사용(화신 0회), 7개가 태양섬광(·달빛섬광) 뒤 바로 자연의 군대 → 천체의 정렬 → 별빛쇄도 2~4번 → 영혼 소집. 심크 opener 가 영혼 소집 특성이면 moonfire·eclipse·wrath 를 건너뛰고 force_of_nature → celestial_alignment, Method 숲의 수호자 오프닝도 "Convoke 면 건너뜀·Celestial Alignment". 예: https://www.warcraftlogs.com/reports/VwzAqghML8mF4YDd#fight=19&source=1 . 화신 빌드 순서(달빛섬광 → 태양섬광 → 일월식 (태양) → 천벌 → 자연의 군대 → 화신)는 rail note·영웅 탭 요약에 남김. 님리사 근거 note 를 스조라크 근거로 교체. 2부 단일 장 숲의 수호자 문단, 오프닝 장 요점, 4부 숲의 수호자 장 첫 문단 맞춤.
- 단일 반복: 공통 rail 변경 없음(별빛섬광 다음 별빛섬광 39%·별빛쇄도 34%, 별빛쇄도 다음 별빛섬광 52%, 일월식 (달) — WCL 1233272 Lunar Eclipse — 다음 별빛쇄도 49%). 숲의 수호자 영웅 탭 단일 우선순위의 화신 줄을 천체의 정렬(화신을 골랐다면 화신)로 바꾸고 영혼 소집 줄(숲의 조화 중·천공의 힘 40 아래, 심크 kotg_st)을 추가.
- 그대로 둔 것과 이유: 엘룬의 대행자 영웅 탭 단일 우선순위·끼워 넣기 rail. 야생의 돌진은 이동기. 야생 버섯은 숲의 수호자 로그 0회지만 선택 특성 조건이라 유지. 일월식 버튼은 로그에서 KB 와 다른 번호(1233346·1233272)로 찍혀 0회가 아님.
- KB 추가 필요: 없음 (일월식 WCL 번호 1233346 Solar Eclipse·1233272 Lunar Eclipse 는 KB 48517·48518 버튼과 같은 것으로 보고 따로 추가하지 않음)
- 보류·사용자 확인 필요: 특성 견본은 모두 엘룬의 대행자이고 숲의 수호자 견본이 없음. 숲의 수호자 오프닝을 상위 로그 빌드(영혼 소집·천체의 정렬) 기준으로 바꿨으니, 견본을 따로 둘지는 사용자 결정. 4부 숲의 수호자 장의 꿈의 폭발 요점은 특성 설명이라 그대로 둠.
