# shaman-enhancement
- 판정: 고침 (폭풍인도자만, 토템술사는 로그 없음)
- 프리풀: 폭풍인도자 오프닝의 "사전 낙뢰"를 뺐다 — 심크 우선순위 precombat 은 무기 강화·번개 보호막·물약뿐, Icy Veins만 "Pre-cast Crash Lightning", Method는 전격의 불길 → 승천 → 낙뢰. 로그 풀 전 시전 0/10, 풀링 0.4~1.2초에 전격의 불길보다 먼저 쓴 로그 3/10.
- 오프닝(풀링 뒤): 낙뢰(사전) → 전격의 불길 → 세계의 분리 → 용암 채찍 → 승천 → 바람의 일격 → 낙뢰 → **전격의 불길 → 낙뢰 → 승천 → 바람의 일격 → 낙뢰**. 근거: 10개 중 7개가 전격의 불길로 시작, 6개가 승천 전 낙뢰, 10개 모두 세계의 분리·용암 채찍 없이 풀링 뒤 1.5~4.8초에 승천. 예: https://www.warcraftlogs.com/reports/g1HG8nXjBcTZ46NR#fight=57&source=16. 세계의 분리·채찍 화염은 "골랐다면 승천 앞에"로 note·영웅 탭 승천 메모에 남김(심크 우선순위 sundering·lava_lash 조건, Icy Veins).
- 단일 반복: 변경 없음 (전격의 불길 → 낙뢰 49%, 낙뢰 → 폭풍의 일격 71%, 폭풍의 일격 ↔ 번개 화살 약 6할).
- 함께 고친 문장: 2부 오프닝 장 한 줄 원리·첫 문단·요점(예전 "상위 로그 한 건" 문장)·확인 문제.
- 그대로 둔 것과 이유: 파멸의 바람 8.45/분은 승천 중 자동으로 나가는 469270(바람의 일격과 같은 시각에 찍힘)이라 버튼으로 넣지 않음(영웅 탭에 "파멸의 바람을 따로 누르지 않습니다" 문장 있음). 번개 화살·폭풍이 바람의 일격과 같은 시각에 찍힌 것은 토림의 기원 자동 시전. 영웅 탭 단일 우선순위의 태고의 폭풍·세계의 분리(로그 0회)는 선택 특성 조건부라 유지. 토템술사는 스조라크 로그 0개라 순서·프리풀 모두 그대로.
