# priest-shadow
- 판정: 고침
- 프리풀: 첫 정신 분열을 전투 전·'풀링 직전'으로 표기(rail caption '풀링 직전 시전', 영웅 탭 두 분기) — 근거: 심크 우선순위 precombat `mind_blast,if=set_bonus.mid2_4pc`, Icy Veins "Pre-Cast Mind Blast", Method 4세트 오프닝 첫 단계 Mind Blast, 로그 15/18 이 0.1~0.6초에 정신 분열 적중. 초 수는 근거가 없어 '풀링 직전'.
- 오프닝(풀링 뒤):
  - 집정관: 분열 → 격돌 → 고통 → 공허 연사 → 후광 → 형상 ⇒ 분열 → 격돌 → 고통 → 후광 → 공허 연사 → 형상 → 마력 주입 → 광기. 근거: 후광을 쓴 7개 중 4개가 후광 먼저(3개 연사 먼저 — rail note 에 "로그마다 다름"), 심크 우선순위 cds 의 halo 가 void_volley 보다 먼저, Icy Veins·Method 집정관 오프닝도 Halo → Void Volley. 예: https://www.warcraftlogs.com/reports/f7vhCg28Km3TrYcj#fight=37&source=6
  - 공허술사: … 형상 → 마력 주입 → 광기 → 공허의 격류 ⇒ … 형상 → 마력 주입 → 공허의 격류 → 공허의 폭발 → 광기. 근거: 10개 중 7개가 격류를 광기보다 먼저, 그중 6개가 격류 바로 뒤 공허의 폭발. 예: https://www.warcraftlogs.com/reports/z8xk37dcRABTH614#fight=15&source=17 . Icy·Method·심크는 형상 안 광기를 먼저 둬서 rail note 에 함께 적음. 영웅 탭은 검사기(오프닝 8단계)에 맞춰 공허의 폭발을 격류 단계 설명에 넣음.
  - 오프닝 장 둘째 문단, 영웅 탭 오프닝 요약·단계 설명, 4부 공허술사 장 첫 문단(격류 준비 문장)을 맞춤. 화면에 안 나오는 상단 opener 는 검사기 "Default Shadow flow must match Archon" 때문에 집정관 오프닝과 같게 맞춤.
- 단일 반복(공통 rail): 흡혈의 손길 → 광기 → 촉수 격돌{위 공허 연사} → 정신 분열 → 정신의 채찍 → 광기 → 정신 분열 → 정신의 채찍 ⇒ 촉수 격돌(손길 갱신){위 고통} → 공허 연사 → 광기{위 형상} → 정신의 채찍{위 죽음} → 정신 분열 → 광기 → 정신의 채찍. 근거: 반복 구간 흡혈의 손길 직접 시전 18개 모두 0회(촉수 격돌이 손길을 걺 — 심크 main 도 tentacle_slam 이 vampiric_touch 위), 원혼 자동 발동을 뺀 다음 시전 표에서 격돌 → 공허 연사 집정관 65%·공허술사 48%, 연사 → 광기 31%·27%, 광기 → 정신의 채찍 34%·18%, 채찍 → 분열·광기, 분열 → 광기·채찍. rail note 에 흡혈의 손길은 격돌 충전이 없을 때만 직접 쓴다고 적음.
- 그대로 둔 것과 이유: 영웅 탭 단일 우선순위(심크 main 순서와 같고 흡혈의 손길 줄도 조건부라 유지), 끼워 넣기 rail. 소실·신의 권능: 보호막은 생존·위협 관리. 공격대 장의 님리사 횟수 문장은 순서 근거가 아니라 그대로.
