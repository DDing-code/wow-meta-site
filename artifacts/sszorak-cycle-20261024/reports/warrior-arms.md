# warrior-arms
- 판정: 고침 (학살자만, 거신은 로그 없음)
- 프리풀: 추가 없음. 심크 우선순위 precombat 은 전투 태세(상시)뿐, Icy Veins·Method 모두 "돌진으로 시작", 로그 음수 초 시전 0/8. 오프닝 intro 의 전투의 외침 확인 문장은 그대로.
- 오프닝(풀링 뒤, 학살자): 돌진 → 회전베기 → 투신 → 거인의 강타 → 마무리 일격 → 칼날폭풍 → 필사의 일격
  → 돌진 → 회전베기 → 거인의 강타 → 투신 → 마무리 일격 → 칼날폭풍 → 폭풍망치(칼날폭풍 중) → 필사의 일격
  - 근거: 8개 중 7개가 거인의 강타 다음 투신(투신은 글쿨 없이 0.3~0.6초 뒤), 8개 중 5개가 칼날폭풍 중 폭풍망치. 심크 우선순위 slayer_st `avatar,if=debuff.colossus_smash.up|…`, `storm_bolt,if=buff.bladestorm.up`(붉은돌격대의 무자비함). Method 학살자 오프닝도 Colossus Smash → Avatar + Execute → Bladestorm.
  - 예시: https://www.warcraftlogs.com/reports/CRBwpKLmyrFnA6QG#fight=29&source=6
  - 함께 맞춘 곳: 오프닝 장 한 줄 원리·본문 두 문단·rail note, 영웅 탭 opener summary·steps(폭풍망치 단계 추가), 단일 우선순위(거인의 강타 → 투신 순, 칼날폭풍 뒤 폭풍망치 행 추가), 단일 연습 장 끼워 넣기 rail(학살자 · 칼날폭풍 중 폭풍망치).
- 단일 반복: 반복 흐름 rail 순서는 그대로(필사의 일격 쿨마다 + 마무리 일격·제압·영웅의 일격·격돌 채우기, 이웃 쌍이 갈려 꾸준한 역순 없음). rail note 근거만 님리사 2건 → 스조라크 8개(분쇄 직접 사용 0회, 회전베기 분당 약 2.8회)로 교체.
- 그대로 둔 것과 이유: 거신(로그 0개). 반복 rail 위 투신/거인의 강타 위치(반복 구간은 앞뒤가 23%/20%로 갈림). 돌진 2회·주문 반사(이동기·생존기).
- KB 추가 필요: 없음
- 보류·사용자 확인 필요: 폭풍망치는 붉은돌격대의 무자비함(학살자 영웅 특성)이 있어야 칼날폭풍 중 쓸 수 있어 문장에 그 조건을 달았음. 분당 0.96회라 반복 rail 본줄에는 넣지 않음.
