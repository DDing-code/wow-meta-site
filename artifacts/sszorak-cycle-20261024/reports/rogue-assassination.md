# rogue-assassination
- 판정: 고침 (죽음추적자 오프닝은 일부 보류)
- 프리풀: 두 영웅 특성 오프닝 맨 앞에 은신(1784) '풀링 직전' 추가 — 연습 장 rail 노드·영웅 탭 opener.steps(phase '전투 전'). 근거: 심크 우선순위 `actions.precombat+=/stealth`, Icy Veins "Always make sure to open from Stealth", Method 오프닝도 은신 목조르기로 시작. 로그 음수 초 0/14(은신은 시전 기록 창 밖), 14개 모두 첫 공격이 목조르기. 심크의 난도질 사전 시전(slice_and_dice,precombat_seconds=1)은 Icy·Method에 없어 넣지 않음.
- 오프닝(풀링 뒤):
  - 운명결속: 목조르기 → 절단 → 파열 → 절단 → 독살 → 죽음표식 → 왕의 파멸 → 독살 → 소멸 → 목조르기 ⇒ 은신 → 목조르기 → 절단 → 파열 → 절단 → 목조르기(강화 시간 안, 위 가지: 소멸 "로그 일부 · 바로 앞에") → 독살 → 죽음표식 → 왕의 파멸 → 독살. 근거: 운명결속 로그 11개 중 8개가 죽음표식 전에 두 번째 목조르기(5개는 두 번째 절단 뒤, 3개는 파열 바로 뒤, 3개는 직전 소멸), 죽음표식 뒤 소멸 → 목조르기는 2개뿐. Icy 오프닝도 파열 뒤 목조르기로 강화 목조르기 연장. 예: https://www.warcraftlogs.com/reports/VjkK2JNCZBvYPTyX#fight=36&source=22
  - 오프닝 장 한 줄 원리·둘째·셋째 문단·확인 문제 1번, 영웅 탭 운명결속 요약·노트를 같은 순서로 맞춤. 검사기(Default Assassination opener must match Fatebound) 때문에 상단 opener 도 운명결속 오프닝과 같게 맞춤.
- 단일 반복: 공통 rail 변경 없음(절단 → 독살 반복, 독살 → 죽음표식 → 왕의 파멸 → 독살, 소멸 뒤 목조르기 91% — 로그와 같음). 죽음추적자 단일 우선순위·끼워 넣기 rail 에 칼날 부채(51723) "어둡고 어두운 밤 · 최대 점수까지 1점 모자랄 때" 추가(독칼 다음). 근거: 죽음추적자 로그 분당 1.21회·뒤 79% 독살, 심크 `fan_of_knives,if=buff.darkest_night.up&combo_points.deficit=1`, Icy "exactly 6 CP → Shiv or Fan of Knives". 2부 단일 장 죽음추적자 문단에 한 문장 추가.
- 그대로 둔 것과 이유: 운명결속 단일 우선순위(로그와 맞음, 그림자 밟기 1.03/분은 이동기), 죽음추적자 교란 2.07/분(생존기).
