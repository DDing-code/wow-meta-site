# warlock-affliction
- 판정: 고침
- 프리풀: 그대로 둠 — 두 영웅 특성 모두 유령 출몰 사전 시전(심크 우선순위 precombat `haunt,if=active_enemies<2|…`, Icy·Method 모두 Precast Haunt, 로그 첫 시전 영혼 수확자 6/10·지옥소환사 7/10). Icy의 어둠의 화살 사전 시전은 심크 우선순위·Method·로그에 없어 넣지 않음. 흑마법서: 희생·소환수는 요약 문장에만 있음(노드 없음).
- 오프닝(풀링 뒤):
  - 영혼 수확자: … → 암흑의 수확 → 불안정한 고통 ×2 → 어둠의 화살 → … → 암흑의 수확 → 불안정한 고통 ×2(조각 다 쓸 때까지) → 재앙의 손아귀. 근거: 로그 10/10이 첫 24회 안에 재앙의 손아귀, 어둠의 화살 0/10, 수확 뒤 불안정한 고통 4~5회 7/10. Icy·Method 오프닝도 조각 소비 뒤 Malefic Grasp. 암흑시선 → 수확(8/10)은 이미 맞아 유지. 예 https://www.warcraftlogs.com/reports/QMAvZTHYRC9XgLKa#fight=50&source=271
  - 지옥소환사: 적개심 → 암흑시선 → 수확 → 불안정한 고통 ×2 → 손아귀 → 불안정한 고통 → 적개심 → 암흑시선 → 불안정한 고통 ×2 → 수확 → 불안정한 고통 → 손아귀. 근거: 수확이 나온 9개 중 6개가 적개심·암흑시선 뒤 불안정한 고통 2~5회 다음 수확(바로 수확 3개). 적개심 → 암흑시선 7/10은 유지. 예 https://www.warcraftlogs.com/reports/c4CVpzBKAkt2vZbL#fight=33&source=192
- 단일 반복:
  - 지옥소환사 영웅 탭 단일 우선순위: 불안정한 고통(적개심·암흑시선 중) 행을 암흑의 수확 위로 이동, 적개심·수확 행 문장 수정. 근거: 반복 구간 적개심 다음 시전 불안정한 고통 58%·수확 11%, 적개심 4~10초 뒤 수확 6/10명(직후 2명, 수확 먼저 1명, 엇갈림 1명). 심크 우선순위 HC_st 는 dark_harvest 가 malevolence 위지만(9월 19일 수정) 로그를 따름.
  - 영혼 수확자 반복 rail·단일 우선순위는 그대로(분당 불안정한 고통 13.3·어둠의 화살 8.5·고통 5.7·출몰 2.9·손아귀 2.1 — 모두 이미 있음).
  - 함께 고친 문장: 연습 장 단일 본문 1문장·끼워 넣기 캡션, 오프닝 장 한 줄 원리·본문 2단락·두 rail note, 지옥소환사 장 본문 1문장·요점 1줄. 님리사 근거 문장(6개 중 4개, 손아귀 미사용)을 스조라크 근거로 교체.
- 그대로 둔 것과 이유: 영혼 수확자 단일 반복(로그·심크 우선순위와 어긋남 없음), 암흑시선 앞 불안정한 고통 개수(로그마다 0~3회 — note에 '로그마다 다름' 유지), 불타는 돌진(이동기라 제외), 영혼 흡수(필러 대체 선택 — 끼워 넣기 rail에 이미 있음), 광역·쐐기 문장.
