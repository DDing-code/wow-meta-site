# shaman-elemental
- 판정: 일부 고침 (순서 변경 없음, 근거·화염 충격 보탬)
- 프리풀: 폭풍수호자(풀링 약 3초 전) 그대로 — 심크 우선순위 precombat `stormkeeper`, Icy Veins·Method "Stormkeeper ~3 seconds before the pull", 첫 폭풍수호자가 35~44초에 다시 찍힌 로그 9/11(풀 전 사용 흔적). 풀링 1.5초 전 용암 폭발은 Icy Veins·Method에만 있고 심크 우선순위 precombat 에 없으며 로그도 2/11(0.1·0.3초)이라 넣지 않음.
- 오프닝(풀링 뒤): 변경 없음 — 11개 중 6개가 강화 번개 화살 2회 → (선조의 신속함) → 승천 → 용암 폭발 → 정기 작렬 → 용암 폭발 → 정기 작렬로 가이드와 같고, 4개는 풀링 직후 승천을 열어 용암 폭발·번개 화살을 번갈아 씀. rail note 에 로그마다 다름을 적음. 예: https://www.warcraftlogs.com/reports/mBPad8fFDJCLtykR#fight=21&source=20
- 단일 반복: 순서 변경 없음(화염 충격 → 용암 폭발 74%, 정기 작렬 → 번개 화살 70%, 번개 화살 ↔ 용암 폭발 약 7할). rail note 의 님리사 근거(전격의 불길 2건)를 스조라크 근거(11개 모두 전격의 불길 0회, 화염 충격 직접 12~22회)로 교체. 선견자 영웅 탭 단일 우선순위에 화염 충격 추가(전격의 불길 앞, 심크 우선순위 flame_shock refreshable), 2부 단일 장 우선순위 요약 문장도 맞춤.
- 그대로 둔 것과 이유: 승천 0.02/분(전투 초·2분마다라 정상), 전격의 불길 0/분(선택 특성 조건부 행 유지). 폭풍인도자는 스조라크 로그 0개라 그대로.
