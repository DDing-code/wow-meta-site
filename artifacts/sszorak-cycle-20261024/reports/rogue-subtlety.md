# rogue-subtlety
- 판정: 고침(기만자), 죽음추적자는 프리풀만
- 프리풀: 두 영웅 특성 오프닝 맨 앞에 은신(1784) '풀링 직전' 추가 — rail 노드·영웅 탭 steps(phase '전투 전'). 근거: 심크 `actions.precombat+=/stealth`, Icy "Always start the fight in Stealth", Method "Start from Stealth"(두 영웅 특성 공통). Icy 의 "풀링 20초 이상 전에 어둠의 춤 한 번(과충전기)"은 심크 precombat 에 없고 로그 창 밖이라 넣지 않음.
- 오프닝(풀링 뒤) 기만자: 그림자 일격 → 절개 → 소멸 → 그림자 일격 → 피아귀의 이빨 → 어둠의 칼날 → 어둠의 춤 → 은밀한 기술 → 그림자 일격 → 절개 ⇒ 소멸 → 그림자 일격 뒤에 기습(53) '6점까지 채우기' 단계 추가(나머지 순서 그대로). 근거: 로그 11개 중 7개가 소멸 뒤 기습 1~2번(2개는 절개, 2개는 바로 피아귀의 이빨), Icy·Method 오프닝도 이 자리에서 점수를 채움. 피아귀의 이빨은 8개 춤 직전·3개 춤 첫 행동, 첫 춤 전 절개·소멸 11/11, 은밀한 기술 바로 뒤 그림자 일격 6/11 — 영웅 탭 노트·rail note 의 지난 근거(상위 레이드 로그 8개 등)를 이 숫자로 바꿈. 예: https://www.warcraftlogs.com/reports/A8yxaWCNdrb1wmLh#fight=24&source=19
- 단일 반복: 공통 rail 변경 없음(기습 → 절개, 피아귀의 이빨 → 춤 53% → 은밀한 기술 80% → 그림자 일격 → 절개). 기만자 영웅 탭 단일 우선순위 맨 앞에 피아귀의 이빨 → 어둠의 춤 추가(분당 1.09·2.81회, 심크 cds 의 goremaws_bite·shadow_dance(unseen_blade·은밀한 기술 준비), Icy·Method "칼날 10초 안이면 춤 아끼기"), 요약 문장 맞춤.
- 그대로 둔 것과 이유: 죽음추적자 오프닝·단일(스조라크 상위 로그 0개), 표창 폭풍 1.27/분(춤 안 사전계획 광역 생성 — 단일 순서로 보기 애매), 최후의 일격(절개 강화로 이미 다룸).
