# warrior-fury
- 판정: 고침
- 프리풀: 추가 없음. 심크 우선순위 precombat 은 광전사 태세(상시)뿐, Icy Veins·Method 모두 돌진으로 시작, 로그 음수 초 시전 0(학살자 11·산왕 4).
- 오프닝(풀링 뒤):
  - 학살자: 돌진 → 오딘의 격노 → 무모한 희생 → 광란 → 칼날폭풍 → 광란 → 분쇄의 타격 → 광란
    → 돌진 → 무모한 희생 → 광란 → 칼날폭풍 → 광란 → 오딘의 격노 → 분쇄의 타격 → 광란
    근거: 11개 모두 무모한 희생 → 광란 → 칼날폭풍. 오딘의 격노를 쓴 7개 중 무모한 희생 앞은 1개뿐(무모한 희생~칼날폭풍 사이 3, 칼날폭풍 뒤 3으로 갈림) → 심크 우선순위 slayer(odyns_fury 가 bladestorm·crushing_blow 아래)·Icy Veins 쿨기 중 우선순위(칼날폭풍 → … → 오딘의 격노)를 따라 칼날폭풍 뒤에 두고 rail note·영웅 탭에 "로그마다 다름". 예시: https://www.warcraftlogs.com/reports/2ANxb7rfdawjFKT1#fight=31&source=17
  - 산왕: 돌진 → 무모한 희생 → 투신 → 광란 → 우레 작렬 → … → 돌진 → 무모한 희생 → 투신 → 우레 작렬 → 광란 → 피범벅 → 분쇄의 타격 → 광란
    근거: 4개 중 3개가 투신 직후 우레 작렬, 심크 우선순위 thane 의 thunder_blast(2중첩). 예시: https://www.warcraftlogs.com/reports/zg41hAHdaRvGXKqk#fight=30&source=11
  - 함께 맞춘 곳: 오프닝 장 한 줄 원리·본문 세 문단(학살자 근거 문장을 스조라크 11개로), 두 rail note, 영웅 탭 두 opener summary·steps.
- 단일 반복: 반복 흐름 rail 순서는 그대로. 단일 연습 장 공통 우선순위 문장에서 오딘의 격노를 무모한 희생 앞 → 피범벅·분쇄의 타격 뒤로(심크 우선순위와 같게), 생성기 순서 근거 문장을 스조라크 로그로 교체(학살자 분노의 강타 분당 12.5·피의 갈증 2.7, 산왕은 광란 뒤 피의 갈증이 가장 많음). 영웅 탭 단일 우선순위에 무모한 희생(두 영웅 특성 맨 위), 산왕에 투신·마무리 일격 추가(분당 1.06·1.06·1.96회, 심크 우선순위 recklessness·avatar·execute).
- 그대로 둔 것과 이유: 공통 오프닝 뼈대 rail(로그와 맞음), 소용돌이(학살자 단일 분당 1.24회지만 심크 우선순위 맨 아래 채우기라 핵심 버튼 아님), 칼날폭풍 중 폭풍망치(학살자 11개 중 4개라 과반 아님), 주문 반사·돌진(생존기·이동기).

- 보류·사용자 확인 필요: 산왕 로그가 4개뿐이라(상위 200행 중 산왕 4행) 산왕 오프닝 변경은 표본이 작음. 학살자 오딘의 격노 위치는 로그가 3:3으로 갈려 심크 우선순위 쪽을 기본으로 둠.
