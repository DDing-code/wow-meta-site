# demonhunter-havoc
- 판정: 고침 (알드라치 영웅 탭 오프닝은 보류)
- 프리풀: 제물의 오라(풀링 1초 전) 그대로 — 심크 우선순위 precombat `immolation_aura`, Icy Veins "Immolation Aura 1 second before the pull", Method 지옥상흔 "2-3 seconds pre-pull"·알드라치 "1 second before pull". 로그 풀 전 시전 0/19(로그 창 밖).
- 오프닝(풀링 뒤):
  - 지옥상흔: 제물의 오라 → 지옥칼 → 안광 → 사냥 → 정수 파쇄 → 휩쓸기 → 휩쓸기 → 파멸 → **제물의 오라 → 사냥 → 지옥칼 → 안광 → 정수 파쇄 → 휩쓸기 → 파멸 → 휩쓸기**. 근거: 10개 중 8개가 사냥으로 시작해 첫 안광 강화, 6개가 정수 파쇄 뒤 휩쓸기 → 파멸 → 휩쓸기(2개 휩·휩·파멸, 2개 파멸 먼저). 예: https://www.warcraftlogs.com/reports/RKGJQxPnbF2HDZ16#fight=31&source=14
  - 지옥상흔 직접 탈태 구간: … 집어삼키는 불길 → 심연의 응시 → 휩쓸기 → **… 집어삼키는 불길 → 심연의 응시 → 파멸 → 휩쓸기** (10개 모두 응시 뒤 파멸 먼저). 응시 캡션 "사냥 강화"는 사냥을 앞으로 옮겨 "탈태 중 안광"으로.
  - 알드라치 2부 레이드 단일 오프닝: 순서 그대로(9개 중 8개 일치), 근거 문장만 님리사 → 스조라크.
- 단일 반복(공통 rail): 안광 → 휩쓸기 → 휩쓸기 → 파멸 → **안광 → 휩쓸기 → 파멸 → 휩쓸기**. 근거: 지옥상흔 반복 구간 안광 뒤 다음 소비 순서 약 42:19:5(휩·파·휩 : 휩·휩·파 : 파·휩·휩), 알드라치 오프닝 9개 모두 정수 파쇄 뒤 휩·파·휩. 지옥상흔 영웅 탭 단일 우선순위에 집어삼키는 불길 추가(분당 1회 이상, 직접 탈태 중 응시보다 먼저 10개 중 7개).
- 함께 고친 문장: 1부 안광 장 요점(짧은 형상 순서), 1부 사냥 장(지옥상흔도 사냥 먼저), 2부 단일 장 한 줄 원리·본문, 2부 오프닝 장 본문·확인 문제, 영웅 탭 복수의 퇴각·탈태 메모의 근거.
- 그대로 둔 것과 이유: 알드라치 반복 순서(글레이브 자동 투척이 섞여 휩·파 앞뒤가 갈림), 알드라치 탈태 뒤 안광 앞 파멸(9개 중 5개만, note 에만 적음), 글레이브 투척 69.85/분(337819·393035 자동 투척)과 활공·흐릿해지기는 버튼으로 넣지 않음.

- 보류·사용자 확인 필요: 알드라치 영웅 탭 오프닝은 광역 순서(파멸 먼저)라 스조라크 단일 순서(휩쓸기 먼저, 9개 중 8개)와 다르다. 공용 검사기 `validate-guide-manuscripts.js`가 "Aldrachi AoE flow must consume Rending Strike before Glaive Flurry"로 이 탭의 파멸 → 휩쓸기 순서를 고정하고 있어 바꾸지 않았다. 단일 순서로 바꾸려면 검사기 수정이 먼저 필요하다.
