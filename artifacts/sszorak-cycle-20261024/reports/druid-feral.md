# druid-feral
- 판정: 고침
- 프리풀: 이미 있는 숨기(5215) '전투 전'이 심크 `actions.precombat+=/prowl`·Icy "Cast Prowl before combat starts"·Method "Prowl" 과 맞아 그대로 둠. 호랑이의 분노 사전 사용은 Method만(심크 precombat 에 없음, 로그 0.2~1.2초) — 지금처럼 '첫 갈퀴 발톱 직전'으로 둠.
- 오프닝(풀링 뒤):
  - 야생추적자: … 도려내기 → 영혼 소집 → 흉포한 이빨 ⇒ … 도려내기(위 가지: 달빛섬광 '달 바라기 · 그 앞에') → 흉포한 이빨(소집 직전) → 영혼 소집 → 흉포한 이빨. 근거: 로그 10개 중 8개가 영혼 소집 직전 흉포한 이빨, 8개가 오프닝에 달빛섬광, 심크 `convoke_the_spirits … prev_gcd.1.ferocious_bite`. 예: https://www.warcraftlogs.com/reports/DfKRGP7jknFcTZg3#fight=28&source=10
  - 발톱의 드루이드: … 도려내기 → 영혼 소집 → 흉포한 이빨 ⇒ … 도려내기 → 찢어발기기(위 가지: 칼날 발톱 '점수 모자라면 먼저') → 영혼 소집 → 흉포한 이빨. 근거: 로그 8개 중 6개가 영혼 소집 전 찢어발기기(4개는 그 앞에 칼날 발톱). 예: https://www.warcraftlogs.com/reports/vL2w9zQdb4j7MG6P#fight=9&source=14
  - 오프닝 장 한 줄 원리·둘째 문단, 두 rail note, 영웅 탭 요약·노트를 같은 순서로 맞춤.
- 단일 반복: 공통 rail 의 영혼 소집 위 가지를 흉포한 이빨 노드에서 다음 칼날 발톱 노드로('이빨 직후 · 출혈 남음'), note 에 한 문장. 근거: 반복 구간 영혼 소집 55회 중 바로 앞이 흉포한 이빨·찢어발기기 32회. 야생추적자 단일 우선순위의 달빛섬광을 칼날 발톱(기습 공격) 위로(심크 builder rake → moonfire_cat → shred, 기습 공격 칼날 발톱 우선은 발톱의 드루이드 전용; 로그 4.6/분), 2부 단일 장 첫 문단 맞춤.
- 그대로 둔 것과 이유: 호랑이의 분노 → 갈퀴 발톱 → 광폭화 → 야성의 광기 → 도려내기(발톱 5/8 같은 순서, 야생추적자는 야성의 광기가 도려내기 앞뒤 5:5 — rail note 에 "반반"으로 적음).
- KB 추가 필요: 없음
- 보류·사용자 확인 필요: 재생(8936) 분당 1.5~2회 — 포식자의 신속함 즉시 치유로 보이고 심크 우선순위는 variable.regrowth=0 으로 쓰지 않아 딜사이클에 넣지 않음. 상단 opener(화면에 안 나오는 예전 필드)는 원래 발톱 오프닝과 같았지만 지침대로 건드리지 않음.
