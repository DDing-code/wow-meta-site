# mage-arcane
- 판정: 고침 (성난태양만, 주문술사는 로그 없음)
- 프리풀: 성난태양 비전 쇄도를 영웅 탭 `전투 전`·`풀링 직전`, 연습 장 rail 캡션 '풀링 직전 미리 시전'으로 표시(근거: 심크 우선순위 precombat `arcane_surge,if=talent.spellfire_spheres`, Icy Veins "pre-cast Arcane Surge", Method 성난태양 오프닝 "Precast Arcane Surge", 로그 7/10이 풀 0.1~1.8초에 쇄도 완료). 그대로 둔 것: 비전 보주 '충전물이 모자랄 때만 준비'(로그 3/10이 풀 직후 작렬·보주로 시작한 뒤 쇄도 — 조건부 단계라 근거와 어긋나지 않음). 주문술사 쇄도는 심크 우선순위 precombat 에 사전 시전이 없어(공개 가이드와 갈림) 그대로 둠.
- 오프닝(풀링 뒤): 성난태양 … 여파 → 신비한 화살 → **오색 화살** → 비전 탄막 → … 여파 → 신비한 화살 → **비전 작렬(오색 화살 없으면 채우기)** → 비전 탄막. 오색 화살은 발동했을 때 작렬 대신 탄막 앞에 쓰는 갈래로 note·본문·요점에 남김. 근거: 여파 → 화살 뒤 두 번째 탄막 전에 오색 화살 3/10, 비전 작렬로 채운 뒤 탄막 4/10, 작렬 없이 탄막 3/10(예: https://www.warcraftlogs.com/reports/g97C1GjtB2TqAb4r#fight=9&source=4). 쇄도 → 화살 → 탄막 → 여파 → 화살 부분은 8/10이 같아 그대로.
- 단일 반복: 순서 변경 없음(화살 → 오색 화살 → 탄막, 오색 화살 다음 탄막 85%, 심크 우선순위 sunfury 목록과 맞음). 평시 rail note·비전의 영혼 rail note·성난태양 장 본문의 님리사/12.1.5 레이드 근거를 스조라크(영혼 구간 33번 모두 탄막 4~6번 연속)로 바꿈.
- 그대로 둔 것과 이유: 일렁임(이동기)·시간 왜곡(공대 배정) 제외. 비전의 여파(1.23/분)는 반복 rail 위 가지에 이미 있어 영웅 탭 단일 우선순위에 따로 넣지 않음. 주문술사 전체(로그 0개). 공격대 장의 님리사 여파·쇄도 횟수 문장은 순서 문장이 아니라 그대로.
