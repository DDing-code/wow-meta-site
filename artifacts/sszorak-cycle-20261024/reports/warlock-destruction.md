# warlock-destruction
- 판정: 고침(악마학자 오프닝·두 영웅 특성 프리풀 표시) / 지옥소환사 풀링 뒤 순서는 변경 없음
- 프리풀: 영혼의 불꽃 사전 시전을 두 영웅 특성 오프닝 맨 앞에 '전투 전 · 풀링 4초 전'으로 둠. 근거: 심크 우선순위 precombat `soul_fire`, Icy Pre-cast Soul Fire, Method 두 오프닝 모두 'Pre-cast Soulfire at 4 seconds on the pull timer'. 로그 첫 시전은 지옥소환사 5/10(나머지 5개는 첫 영혼의 불꽃을 약 48초에 씀)·악마학자 2/2. 지옥소환사는 이미 있던 단계라 단계·캡션 표시만 맞춤. Icy의 소각·제물·대재앙 사전 시전은 심크 우선순위(단일 조건)·Method·로그와 맞지 않아 넣지 않음.
- 오프닝(풀링 뒤): 악마학자 제물 → 점화 → 지옥불정령 소환 → 혼돈의 화살 … 을 영혼의 불꽃(풀링 4초 전) → 지옥불정령 소환 → 점화 → 혼돈의 화살 … 로(rail 이름 '제물 시작' → '영혼의 불꽃 빌드'). 근거: 로그 2/2가 영혼의 불꽃 → 정령 → 점화, Method 악마학자 오프닝 Soulfire → Summon Infernal → Conflagrate, 영웅 탭 단일 요약도 영혼의 불꽃 빌드. 예 https://www.warcraftlogs.com/reports/rTqXg7ZyWtCH4dkL#fight=21&source=14
  - 함께 고친 곳: 영웅 탭 두 opener summary·행 문장, 연습 장 오프닝 한 줄 원리·본문 2단락·요점 1줄·두 rail note. 님리사 근거 문장(악마학자 4개 중 3개 제물 시작, 무료 어둠의 연소 7개 중 2개)을 스조라크 근거(어둠의 연소 첫 24회 안 8/10, 지옥불 화살·황폐 0/2)로 교체.
- 단일 반복: 변경 없음 — 분당 소각 18.7·점화 8.6·어둠의 연소 8.5·혼돈의 화살 7.6·쇠퇴 2.7·영혼의 불꽃 1.2, 영혼의 불꽃 → 점화·점화 → 혼돈의 화살·혼돈의 화살 → 소각 흐름이 공통 rail과 같음. 어둠의 연소는 rail 위 가지·영웅 탭 5번 행에 이미 있고 사용의 71%가 적개심·정령 구간(영웅 탭 문장과 일치).
- 그대로 둔 것과 이유: 지옥소환사 오프닝 순서 — 정령 직후 적개심 8/9로 맞음, 첫 점화는 정령 앞 4개·뒤 5개, 적개심 뒤 첫 소비도 '점화 → 혼돈의 화살 ×2' 3개·'혼돈의 화살 → 점화 → 혼돈의 화살' 3개·'혼돈의 화살 ×2' 3개로 갈려 고치지 않고 note에 근거 수만 적음. 광역·쐐기 문장.
