# evoker-devastation
- 판정: 고침
- 프리풀: 살아있는 불꽃 '풀링 약 2초 전'은 그대로(심크 우선순위 precombat `living_flame`, Icy Veins·Method "Precast Living Flame", 툴팁 시전 2초). 
- 오프닝(풀링 뒤):
  - 비늘사령관: 깊은 숨결 → 용의 분노 → 전세역전 → 영원의 쇄도 → 불의 숨결 → 파열 … ⇒ 깊은 숨결 → 용의 분노 → 전세역전 → **불의 숨결 → 영원의 쇄도** → 파열 …(두 번째 회전 쇄도 → 숨결은 10/11이 같아 그대로). 근거: 첫 회전에 불의 숨결 먼저 9/11, 전세역전 31번 중 24번이 바로 다음 불의 숨결에, 심크 우선순위 sc 목록 `tip_the_scales,if=action.fire_breath.ready`(예: https://www.warcraftlogs.com/reports/kqAhr1mwGBNT9ZDL#fight=15&source=29). Icy Veins 오프닝은 영원의 쇄도 먼저라 로그와 갈림. 두 번째 깊은 숨결 간격 근거 10~17초 → 13~17초, 두 번째 깊은 숨결과 강화 주문 앞뒤는 '로그마다 다름'(깊은 숨결 먼저 6·뒤 4) note 추가. 영웅 탭·연습 장 본문·요점·확인 문제·심화 장 문장 함께 맞춤.
  - 불꽃형성자: 용의 분노 → 불의 숨결 → 영원의 쇄도 → 파열 두 번 → 불의 숨결 → 파열 → 하늘빛 휩쓸기 ⇒ 용의 분노 → **전세역전 → 영원의 쇄도 → 불의 숨결** → 파열 두세 번 → 불의 숨결 → 파열 → **살아있는 불꽃**. 근거: 쇄도 먼저 6/8, 전세역전 5/8(21번 중 20번이 쇄도에), 첫 숨결 뒤 파열 3회 8/8, 하늘빛 휩쓸기 0/8, 두 번째 숨결 뒤 살아있는 불꽃 7/8, 심크 우선순위 fs 목록(전세역전 → es → fb_fs)(예: https://www.warcraftlogs.com/reports/cvqaW9bDYxy2LRgr#fight=15&source=99).
- 단일 반복: 비늘사령관 반복 rail·우선순위 순서 그대로(둘이 4초 안에 이어질 때 쇄도 먼저 64·숨결 먼저 54로 갈림), 전세역전 note 만 '주로 영원의 쇄도' → '주로 불의 숨결'. 불꽃형성자 영웅 탭 단일 우선순위: 용의 분노 → 불의 숨결 → 영원의 쇄도 → 전세역전 ⇒ 용의 분노 → 전세역전 → 영원의 쇄도 → 불의 숨결(쇄도 먼저 53·숨결 먼저 28, 심크 우선순위 fs). 1부 강화 주문 장 요점은 영웅 특성별로 나눔.
- 그대로 둔 것과 이유: 부양·흑요석 비늘·활공(이동·생존) 제외, 쌍둥이 불길은 파열과 같은 시각에 찍히는 자동 효과라 제외. 첫 깊은 숨결 진입(8/11, 3개는 용의 분노로 열고 14~16초에 깊은 숨결). 용의 분노 반복 통계 0.08/분은 2분 쿨기가 사잇단계 제외 구간에 걸린 탓이라 그대로. 연습 장 단일 요약 문장(쇄도 → 숨결 우선순위)은 반복 로그가 갈려 그대로.
- KB 추가 필요: (보류 항목 관련) Slipstream(Hover 관련 황폐 특성, 공식 한국어 이름 미확인) — 확인 필요 시 KB 노트 추가.
- 보류·사용자 확인 필요: 부양 2회 미리 시전 — 심크 우선순위 precombat `hover,if=talent.slipstream` 2줄과 Method 비늘사령관 오프닝 "Precast 2x Hover"가 같지만, 조건 특성 Slipstream 이 KB 에 없어 견본에 들어 있는지 확인하지 못해 넣지 않음.
