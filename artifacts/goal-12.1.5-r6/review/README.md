# 120화면 눈 검수 기준

- 대상: `shots/<가이드 ID>-<폭>.png` 120장(40개 가이드 × 320·390·1440px). 한 장은 그 폭의 실제 화면을 여섯 조각(첫 화면, 목차, 0부 스킬, 흐름도, 타임라인, '네임드' 문구 또는 보조 상자)으로 모은 것이다. 분홍 테두리와 노란 조각 이름은 캡처 도구가 그린 것이다.
- 조각 위·아래가 잘린 것은 캡처 높이 제한(1440px 1000, 모바일 1300) 때문이라 문제로 보지 않는다.
- 페이지 전체는 `ui-check.json`이 따로 센다: 가로 넘침, 깨진 그림, 겹침(타임라인 아이콘·흐름도 노드·스킬 묶음 링크), 빈칸(빈 상자·장·목차·이름 없는 스킬 링크), 꺾인 상자 제목, '보스' 문구, 화면 오류.

판정 항목(각 장마다 0/1):

| 항목 | 문제로 보는 것 |
|---|---|
| 넘침 | 글자·아이콘·상자가 화면 오른쪽 밖으로 나가거나 잘림 |
| 깨진 아이콘 | 빈 네모, 깨진 그림 표시, 아이콘 자리에 아무것도 없음 |
| 겹침 | 글자끼리, 아이콘과 글자, 상자끼리 포개짐 |
| 빈칸 | 내용이 있어야 할 상자·칸이 비어 있음, 제목만 있고 본문 없음, 한 글자씩 세로로 꺾인 제목 |
