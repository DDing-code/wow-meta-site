# WoW 가이드 용어 지침

> **목적**: 한국 WoW 커뮤니티에서 실제로 사용하는 용어로 가이드를 작성하기 위한 표준 지침
> **최종 수정**: 2025-11-28

---

## 1. 용어 변환 규칙

### ✅ 변경해야 할 용어

| 영어/직역 | 한국 커뮤니티 용어 | 비고 |
|-----------|-------------------|------|
| Funnel damage, 퍼널 딜, 피해 집중 | **깔때기 딜** | 우선순위 대상에 피해 집중 |
| Burst damage, 버스트 피해/구간 | **극딜** | 쿨다운 몰아서 피해 집중 구간 |
| AoE damage, 광역 피해 | **광딜** | 다수 대상 피해 |
| Single Target | **ST** | 단일 대상 (영어 약어 그대로 사용) |

### ✅ 유지할 용어

| 용어 | 설명 |
|------|------|
| 업타임 | 버프/디버프 유지 시간 비율 |
| 캡 방지 | 자원/충전 상한선 도달 방지 |
| 필러 스킬 | 우선순위 스킬 쿨다운 중 사용하는 스킬 |
| 분노 축적 | 분노 자원 모으기 |
| 더블딥 | 버프가 두 번 적용되는 효과 |
| 동기화 | 쿨다운을 맞춰서 사용 |
| 스펜더 | 자원 소비 스킬 |
| 빌더 | 자원 생성 스킬 |
| 프리풀 | 전투 시작 전 스킬 사용 |
| 쿨마다 | 쿨다운마다 즉시 사용 |

### ❌ 사용하지 않을 표현

| 피해야 할 표현 | 이유 |
|---------------|------|
| 스킬 줄임말 (정파, 복퇴, 죽휩 등) | JSON 데이터에서는 풀네임 사용 |
| 지나친 영어 표현 | 한국어 대체어가 있으면 한국어 사용 |

## 2. 스킬명 규칙

### 스킬명은 게임 내 공식 한국어 번역 사용

```json
// ✅ 올바른 예시
"skillName": "정수파쇄"
"skillName": "죽음의휩쓸기"
"skillName": "복수의퇴각"

// ❌ 잘못된 예시
"skillName": "정파"
"skillName": "죽휩"
"skillName": "복퇴"
```

### 영웅 특성명

| 영어 | 한국어 |
|------|--------|
| Aldrachi Reaver | 알드라치 파괴자 |
| Fel-Scarred | 지옥상흔 |

## 3. 문장 스타일

### 설명문 작성 시

```
// ✅ 좋은 예시
"description": "정수파쇄 윈도우에 폭발적 피해"
"description": "부상당한사냥감으로 우선순위 대상에 깔때기 딜"
"description": "탈태 극딜 구간에 피해 집중"

// ❌ 피해야 할 예시
"description": "Essence Break window에서 burst damage 발생"
"description": "퍼널링으로 priority target에 damage focus"
```

### 조건문 작성 시

```
// ✅ 좋은 예시
"condition": "정수파쇄 디버프 중"
"condition": "탈태 밖에서. 악마쇄도 proc 예정이면 탈태 중에도"
"condition": "2충전 예정 (3초 내)"

// ❌ 피해야 할 예시  
"condition": "during Essence Break debuff"
"condition": "outside of Meta, also in Meta if Demonsurge will proc"
```

## 4. 숫자/단위 표기

| 항목 | 표기법 | 예시 |
|------|--------|------|
| 시간 | 초 단위 | "4초", "3초 내" |
| 퍼센트 | % 기호 | "80%", "15%" |
| 분노 | 숫자만 | "80분노", "40분노 미만" |
| 스택 | 스택 | "4스택", "1스택 이상" |
| 충전 | 충전 | "2충전", "0충전까지" |

## 5. 자주 사용되는 표현

### 우선순위 설명

```
"reason": "극딜 시작"
"reason": "버프 활용"
"reason": "분노 생성"
"reason": "분노 소비"
"reason": "캡 방지"
"reason": "필러"
"reason": "스펜더"
"reason": "악마화"
```

### 조건 설명

```
"condition": "쿨마다"
"condition": "-" (무조건)
"condition": "버프 시"
"condition": "디버프 중"
"condition": "X분노 미만"
"condition": "X초 내"
"condition": "다른 스킬 없을 때"
```
