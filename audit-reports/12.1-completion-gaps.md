# 12.1 전체 전문화 완료 검수

기준: 2026-09-22, 사이트 커밋 330e18e8의 guideManuscripts.js 및 kb-skills.json.
판정: **전체 완료 아님**. 앞선 복원 수정은 부분 진행이며 전체 전문화 검수를 대체하지 않는다.

## 확인된 누락

- 실행 시점의 최종 guideManuscripts 객체는 40개다. 파일 끝의 전문화별 재할당까지 평가했다.
- 원고 35개는 patch=12.1, 5개는 patch=12.0.5다.
- 구버전 원고: warrior-protection, warrior-arms, warrior-fury, shaman-enhancement, shaman-restoration.
- 전사 3개는 researchedAt=2026-06-06이다. 고양·복원은 12.1 전환 검수 중으로 표시되어 있다.
- DB 고유 항목 2,977개 중 patch=12.1은 2,277개, patch=12.0.5는 700개다.
- DB description이 #으로 시작하는 제목형 항목은 535개다. 이는 설명의 내용 검증 통과가 아니라 미완성 또는 추출 실패 후보다.
- 한 공용 항목은 여러 전문화에 포함될 수 있으므로 전문화별 개수를 더해 고유 항목 수로 보고하지 않는다.
- 야수 전문화 값에는 BeastMastery와 Beast Mastery가 함께 존재한다. 별개 전문화로 세지 않는다.

## 우선순위

1. 전사 3개 원고의 12.1 변경점, 빌드별 운용과 세트 효과를 조사하고 정본 KB와 DB를 함께 갱신한다. 숫자만 12.1로 치환하지 않는다.
2. 고양·복원의 최신 로그와 남은 공용 특성을 검수한 뒤 원고의 전환 상태를 판단한다.
3. 이미 12.1로 표기된 전문화도 제목형 DB 설명과 공용 노트를 재검수한다. 특히 정기, 회복 드루이드, 신성 사제·성기사, 운무, 보존·황폐, 비전·조화의 누락을 놓치지 않는다.
4. 설명 누락은 원문 KB를 읽고 구분한다. 사실이 있는 노트의 추출 문제와 내용 자체가 빈 노트를 같은 방식으로 처리하지 않는다.

## 완료 근거로 인정하지 않는 것

- patch 문자열, 문서 길이, 단순 테스트 통과, 새 배포만으로 사실 검증 완료를 선언하지 않는다.
- 일반 툴팁의 기본값을 랭크·전문화·세트 보정 후 최종값으로 쓰지 않는다.
- 로그 미확보와 출처 충돌은 각각 남은 항목이다. 출처를 못 읽었으면 읽었다고 표시하지 않는다.
- 이 기록은 현재 누락 목록이지 35개 전문화의 완료 인증서가 아니다.
