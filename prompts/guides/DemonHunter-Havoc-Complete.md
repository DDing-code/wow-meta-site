## 🎨 디자인 요구사항

### 색상 팔레트
```javascript
// 악마사냥꾼 테마
primary: '#A330C9'      // 메인 보라색
secondary: '#6B1D84'    // 어두운 보라
accent: '#FF6B6B'       // 강조 레드

// 배경
background: {
  primary: '#0D0D14',   // 최상위 배경
  secondary: '#1A1A2E', // 카드 배경
  card: '#1E1E32'       // 컴포넌트 배경
}

// 텍스트
text: {
  primary: '#FFFFFF',   // 제목
  secondary: '#B8B8D0', // 본문
  muted: '#6B7280'      // 보조
}
```

### 공통 스타일 요소
- 카드 테두리: 1px solid 보라색
- 모서리: 8px ~ 12px 둥글게
- 호버: 글로우 이펙트 + 살짝 올라감
- 아이콘 테두리: 2px 보라색 + 그림자 글로우
