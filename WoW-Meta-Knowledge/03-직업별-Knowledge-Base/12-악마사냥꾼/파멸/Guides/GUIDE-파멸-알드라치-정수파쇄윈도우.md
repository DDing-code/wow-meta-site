# 정수 파쇄 윈도우 (알드라치)

## 개요
정수 파쇄 윈도우는 파멸 악마사냥꾼 피해의 대부분이 발생하는 핵심 윈도우입니다. [[정수-파쇄]], [[안광]], [[복수의-퇴각]]을 항상 함께 사용하여 피해를 극대화합니다.

## 기본 콤보 시퀀스
1. [[파괴자의-글레이브]] (충전이 있다면)
2. [[혼돈의-일격]] ([[안광]] 쿨다운 올 때까지)
3. [[복수의-퇴각]] + [[안광]] (동시 사용)
4. [[지옥칼]] ([[타성]] 사용 중이면 여기서 사용하지 말 것)
5. [[정수-파쇄]]
6. [[죽음의-휩쓸기]]
7. [[칼춤]]
8. [[칼춤]]

## 사전 요구사항

### 알드라치 파괴자
- 콤보 전 최소 1스택 [[파괴자의-징표]] 필요
- 이상적으로는 [[전투의-전율]] 버프로 윈도우 강화
- [[타성]] 사용 시 [[지옥칼]] 사용하지 말 것

### 충전 관리
- [[파괴자의-글레이브]] 충전이 없으면 [[안광]]이나 [[정수-파쇄]] 홀드하지 말 것
- 쿨다운마다 사용하여 DPS 손실 방지

## 핵심 포인트
- [[정수-파쇄]]와 [[안광]]을 항상 함께 사용
- [[복수의-퇴각]]을 [[안광]]과 동기화
- [[파괴자의-징표]] 1스택 이상 유지
- [[전투의-전율]] 버프 중에 윈도우 실행이 이상적

## 주의사항
- [[갈무리한-기운]] 사용 시 [[지옥칼]] 생략
- 충전 없이 홀드하지 말 것
- [[정수-파쇄]]와 [[탈태]] 윈도우 마스터하는 것이 알드라치에서 매우 중요
